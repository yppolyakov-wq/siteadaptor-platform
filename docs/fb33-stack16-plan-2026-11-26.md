### T4: ИИ-перевод частями (клиент)
- `trRun` делит собранные поля на части: ≤ `MAX_ITEMS` текстов и ≤ `TOTAL_MAX` знаков (длина `trim`-текста по `String.length` — UTF-16, не меньше `len` Python: клиент строже сервера); текст длиннее `ITEM_MAX` в часть не идёт — «übersprungen: zu lang für die automatische Übersetzung».
- Потолки клиент берёт из сервера, не числами в JS: `i18n_translate_ctx` отдаёт `limits` из констант `i18n_translate`, клиент читает их с кнопки (`data-limits`) или из JSON, отрисованного тем же тегом в `_i18n_translate_js.html` — исполнитель выбирает один путь; второго списка чисел нет (замок).
- Части — по очереди (следующая — после `done` предыдущей; сервер держит одну задачу на пользователя). Результат части применяется сразу (те же проверки «поле пустое, база та же, язык тот же»); `change` окна — один раз в конце (иначе `aufbau.js` подменит панель, и поля следующих частей отвалятся).
- Статус: «Wird übersetzt … Teil N von M» на каждую часть (одна часть — как сейчас, без «Teil»). Итог — прежний текст с числом заполненных; ошибка части k (код `quota`, `error`, `slow`, `busy`, `forbidden`) — остановка, уже применённое остаётся, к итогу «· Teil k von M: <прежнее сообщение>». Кнопку подменили (панель перерисована) — остановка без записи.
