# DL-15 — неполный ряд: «по центру + широкая одиночная карточка» (решение владельца 2026-09-02)

**Фидбэк:** «2 и 1 выглядит не очень» (spread DL-14 на /aktionen/: две карточки разъезжаются,
одна висит по центру). Показаны 5 вариантов (A сейчас · B по центру · C слева · D широкие
карточки · E плитка-подсказка DL-11). **Решение: B + D; E остаётся режимом `fill`.**
Дополнение той же датой: «пересей демо, чтоб всё было по ширине; то, что заканчивается
сегодня — в 2 колонки с растянутым фото; скидку в карточках чуть больше; проверь адаптацию
на мобильном». Продолжение DL-14 (`dl14-spread-autocols-plan-2026-09-02.md`), БЕЗ миграций.

## 1. Механика

| Слой | Что | Где |
|---|---|---|
| **B · по центру** | `tail="spread"`: `justify-content: center` вместо `space-evenly` — остаток ряда центрируется с обычным зазором сетки; полные ряды байт-в-байт. | генератор |
| **D · широкая одиночная** | Когда в последнем ряду ровно ОДНА карточка (планшет/десктоп, n ≥ 2): она занимает всю ширину и меняет форму — фото слева 38 % (3:2), текст справа. Определяется чистым CSS: `:nth-child(Nn+1):last-child` (сетка с кнопкой `.sf-more` — `:nth-last-child(2)`); форма меняется ТОЛЬКО у карточек с известной структурой `a > [data-sf-media-box] + div` (guard `:has()`, блок под `@supports selector(a:has(> b))` — старый браузер остаётся на B). На телефоне — B (одна колонка/две — узко для горизонтальной). | генератор (`solo_selectors`/`wide_rules`) |
| **E · плитка** | Без изменений: `.sf-filler` только при `tail="fill"` раскладки страницы (DL-11). | — |
| **«Endet bald» в 2 колонки** | Лента 4 × w-56 → `grid sm:grid-cols-2`, карточки с классом `sf-wide` = та же горизонтальная форма, что D (одни правила, второй потребитель). | promotions_list.html · _promo_card.html (`wide`) |
| **Бейдж скидки крупнее** | Карточный бейдж `text-xs px-2.5` → `text-sm px-3` (акции и промо-бейдж товара); детальная (`size="lg"`) не тронута; per-Look CSS бейджей размер не задаёт — наследует. | _discount_display.html · _product_card.html |
| **Демо «по ширине»** | Группы /aktionen/ кита aktionsmarkt кратны 3 (Anti-Food-Waste 4→6, Räumung 2→3); «Endet bald» — чётное число (2-колоночная сетка). Замок в тестах кита. | demo_kits.py |
| **Studio** | Подпись режима «Reihen: verteilen» → «Reihen: zentrieren» (ключ `spread` не меняется — хранение). | site_home.html + 5 .po |
