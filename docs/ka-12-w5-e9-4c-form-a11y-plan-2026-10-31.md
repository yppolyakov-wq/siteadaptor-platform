# KA-12 W5 · E9.4c — ошибки и подсказки полей связаны с виджетом (2026-10-31)

## Факты (разведка)
- `label for` у полей кабинета уже есть (общие партиалы `catalog/_pf_field`, `tenant/_settings_field`,
  `crm/_form_field` и формы событий/акций/ваучеров).
- Django 5.1 сам ставит виджету `aria-invalid="true"` при ошибке и
  `aria-describedby="<auto_id>_helptext"` при подсказке — но наши шаблоны НЕ давали абзацу подсказки
  этот id → ссылка висела в пустоту (скринридер не читал подсказку).
- Текст ошибки ни в одной форме не связан с полем: скринридер говорит «ungültig», но не «почему».

## Что делаем
1. Фильтр `form_a11y.a11y` (`apps/core/templatetags/form_a11y.py`): при ошибке пишет в
   `aria-describedby` виджета `<auto_id>_helptext` (если подсказка) + `<auto_id>_errors`.
   Без ошибки ничего не трогает (подсказку связывает Django). Пишется в attrs виджета экземпляра
   формы (поля формы — копии), соседние формы не задеваются.
2. Шаблоны: подсказка — `id="{{ field.auto_id }}_helptext"`, ошибки — блок
   `id="{{ field.auto_id }}_errors"` вокруг цикла (`data-field-error` у строк сохранён — его
   ищет раскрытие вкладки при Save); виджет — `render_field field|a11y …` / `field|a11y|add_class`.
3. Рукописные поля (ассистент акции `promotion_quick`, `_city_category_fields`, радио-группа
   режима налога в лёгком «Geschäft») — `aria-invalid` + `aria-describedby` вручную.

## Объём
Партиалы кабинета + category_form, lite_business, _i18n_group, event/teacher/tour forms, vouchers,
loyalty, promotion_quick, _city_category_fields.

**Дальше (осознанно вне батча, список `_LEGACY` в замке):** публичные одноразовые формы —
онбординг, быстрая регистрация `/aktion-starten/`, мастер импорта (своя раскладка ошибок);
account/* (allauth) и витрина — не кабинет.

## Замки (`apps/core/tests/test_form_a11y.py`)
- Фильтр: ошибка + подсказка → оба id; валидное поле не трогает.
- Рендер общих партиалов с ошибкой: каждый id из `aria-describedby` существует на странице.
- Скан: каждый цикл ошибок поля в кабинетном шаблоне обёрнут в блок с id `…_errors`.

## ECC-прогоны
- До кода: скилл `accessibility` (WCAG 3.3.1 Error Identification, 1.3.1, 4.1.2).
- После кода: `a11y-architect` на дифф; стенд Playwright — форма товара с ошибкой: у поля
  `aria-invalid` и `aria-describedby`, все id существуют, вкладка с ошибкой раскрывается.
- Гейт: ruff, `template_comments`, `i18n_quickcheck` (новых строк нет).

## Батч 2 (2026-10-31) — публичные формы
Онбординг (`tenants/onboarding.html`: общий конвертер + карточки типа бизнеса как `radiogroup`
с подписью и ошибкой), быстрая регистрация `/aktion-starten/` (`tenants/quick_start.html`:
рукописные поля — `aria-invalid`/`aria-describedby` + блоки `id_<поле>_errors`; цены — один
блок ошибок `qs-price_errors`; радиогруппы — через `<fieldset aria-describedby>`), мастер
импорта (у поля файла не было видимой подписи — добавлена; подсказка и ошибка — один блок
`imp-file-hint`). `_LEGACY` сократился до двух не-полевых списков ошибок. Новый замок: каждый
литеральный id из `aria-describedby` объявлен в том же шаблоне.
