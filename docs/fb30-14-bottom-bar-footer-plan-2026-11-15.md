# FB-30.14 — нижняя панель: пункты-функции; подвал аккордеоном на телефоне

Фидбэк владельца 2026-11-15 (скрин haanerteeladen): «Меню внизу — это не меню ресторана, а
вызывает меню сайта как сверху. Добавить настройку и управление в разделе меню в админке:
вызывать меню, открывать предложения или другие функции, которые обычно выводят в меню. Футер
сайта сделать выпадающим аккордеоном».

## Причина
Авто-панель (`core/context._storefront_bottom_nav`) ставила первым пункт «Menü 🍽» — ссылку на
ассортимент (`storefront-products`): у магазина это читается как «меню ресторана». Своя панель
(`menus.bottom`) умела только ссылки — открыть меню сайта было нечем.

## Решение
- Новый тип узла меню `action` (только нижняя панель): цели `menu` (открыть меню сайта),
  `search`, `cart`, `deals` (акции), `call` (позвонить), `account`. Реестр — `menu.ACTIONS`,
  нормализация — `siteconfig` (неизвестная цель → узел выпадает).
- Витрина: `menu` — кнопка `☰ Menü` (aria-controls/expanded), открывает то же мобильное меню
  шапки и прокручивает к нему; остальные — ссылки по существующим маршрутам/гейтам модулей.
- Авто-панель: первым — `☰ Menü` (открыть меню сайта) вместо ссылки на ассортимент.
- Кабинет «Menü → Untere Leiste»: вид пункта «Funktion» со списком функций.
- Подвал: колонки на телефоне — `<details>` (свёрнуты), на ≥sm — всегда раскрыты.

## Замки
нормализация `action` (мусор → выпал; только известные цели); авто-панель начинается с
`menu`-действия; своя панель рисует кнопку для `menu` и ссылку для `cart`; подвал на телефоне
— `<details>`, без JS ссылки доступны (details раскрывается нативно).
