# T-8.10g — «✨ Antwort vorschlagen»: черновик ответа клиенту в «Nachrichten» (2026-10-19)

Родитель: `docs/t8-10-rest-plan-2026-10-19.md §2`. Разведка и план — агент planner. **Миграций нет.**
Отправляет только человек: черновик лишь заполняет поле ответа.

## 2. Факты — `apps/inbox/ai_facts.py::facts_for(conversation, tenant)`

1. **Сделка** (код, затем UUID). Гейт: `conversation.customer_id` == `obj.customer_id`, иначе фактов
   сделки нет. Берём: название, статус, дата/срок, сумма, строки состава. **Не берём:** контакты/адрес
   доставки клиента, оплату, `cost_price`, `JobLine.cost_rate`.
2. **Сущность** через `sellable.display_fields` + своё: товар — «Verfügbar ja/nein», аллергены (пустой
   список = **неизвестно**), диеты, активная акция (mystery — без цены); событие — дата/место/места;
   номер — «ab N €/Nacht», вместимость; неактивная — «nicht mehr im Angebot».
3. **Всегда:** имя бизнеса, адрес, город, часы, «Heute: Montag 19.10., Jahr 2026», своя абсолютная ссылка
   на сущность (allowlist ссылок).
4. Не идут: имя и контакты клиента, имена сотрудников, телефон/e-mail бизнеса.

## 3. Язык клиента

Источника нет → модель отвечает на языке последнего сообщения клиента, в схеме поле `language`.
Постпроверка по письменности (кириллица ↔ латиница). de/tr/en между собой не различаем (v1).

## 4. Постпроверка — `ai_reply.check_reply(draft, facts, messages)`

Разрешённое множество — из сырых строк фактов и тел сообщений. По порядку, первый сработавший код:
`pii` (маркеры scrub) · `link` (любая ссылка/голый домен/markdown, кроме точного совпадения со своей) ·
`contact` (e-mail/телефон) · `price` (сумма вне фактов/сообщений) · `percent` · `number` (каждая
целочисленная компонента токена `\d+([.,:]\d+)*` должна встречаться в фактах/сообщениях — покрывает
de/en цены, даты d.m., время, годы) · `discount` (gratis/kostenlos/Rabatt без основания) · `claim`
(vegan/bio/glutenfrei… только из фактов — вопрос клиента основанием не считается) · `allergen` (термин
аллергена при необъявленной декларации) · `language`. Отказ → владельцу общее «Vorschlag verworfen»,
код только в `logger.info` (замер доли отказов).

Ограничения v1: числа словами, смысл отрицаний при полной декларации.

  AIUsage).
- **G-2** кнопка в треде: `POST <uuid>/entwurf/` + `GET entwurf/<job>/`; `@login_required`+`@require_POST`

  сообщения не вставляется). Стенд Playwright.
- **G-3** карточка сделки: та же кнопка у существующего треда.

## 6. Решения владельца

- **О-1** факты сделки — только если клиент треда совпадает с клиентом сделки; без адреса/оплаты.
- **О-2** Datenschutz тенанта: при включённом ИИ и inbox генерированный текст получает абзац про
  черновики через ИИ-сервисы в ЕС (Art. 28); свой текст владельца не трогаем.
- **О-3** аллергены: пустой список = неизвестно → «bitte im Geschäft nachfragen».
- **О-4** кнопка доступна всей команде с доступом к «Nachrichten».

**Решения приняты владельцем 2026-10-19: О-1…О-4 — все по рекомендации.**
