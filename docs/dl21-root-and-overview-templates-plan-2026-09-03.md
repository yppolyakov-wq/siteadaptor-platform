# DL-21 — шаблоны корневой `/sortiment/` и обзорной `/aktionen/` + идеи Too Good To Go

**Запрос владельца (2026-09-03, после DL-20):** «можно ли эти 6 стилей, которые есть в
категориях, так же к акциям применить? У категории так же, а главную категории
sortiment нужно сделать с макетами, если нет. И посмотри togotogo — там есть что
интересное посмотреть.»

Три части: **21.1** корневая `/sortiment/` · **21.2** обзорная `/aktionen/` · **21.3**
разбор Too Good To Go (предложение, код — по решению владельца).

---

## 1. Что показала разведка

### 1.1 Корневая `/sortiment/` (агент, факты с путями)

* Та же вьюха `product_list(slug=None)`, `path_mode=False`. Шаблон страницы **не считается
  вовсе**: `cat_style = … if category is not None else ""` — единственная точка, где дефолт
  отсекается от корня (`public_views.py:927`).
* Только у корня: верхний список корневых категорий (плитки/чипы), `combos_teaser`,
  `catalog_title/catalog_intro`, `page_blocks "catalog"`. Только у категории (все под
  `if path_mode`): `shelves`, `category_tabs`, `show_category_header`, крошки, `_STYLE_PRESET`,
  `category_side_nav`, `subcats_hidden`.
* Ось «плотность/прайс-вид» на корне УЖЕ занята `catalog_layout.preset` (вкл. восемь
  `preisliste_*`) — редактируется в Studio «Landing pages → Katalog» и на странице «Pages».
  Свободна ось **композиции страницы** (шапка / боковая колонка / полки / герой / индекс).
* Замок `test_site_default_does_not_leak_into_the_full_catalog` осознанно запрещает
  ЛЮБОЙ `data-cat-layout` на корне — при своём ключе корня переписывается: дефолт
  КАТЕГОРИИ по-прежнему не течёт, свой ключ корня — действует.

### 1.2 Обзорная `/aktionen/`

* Секции по группам (порог 2), либо «по времени» (`promo_grouping="time"`), либо ленты
  (`promo_layout="slider"`); «Endet bald», Vorschau; таблица `?ansicht=liste`.
  Заголовка/интро страницы в настройках нет (у каталога есть `catalog_title/intro`).
* «Подкатегории» этой страницы — **группы**, «товары» — акции. Именно так шесть стилей
  категории ложатся на акции: не на страницу группы (у неё нет под-сущностей — там уже
  пятёрка DL-20), а на **обзор**.

### 1.3 Too Good To Go (обзоры + B2B-страница; сам сайт отдаёт 429)

Механики, которых у нас нет или есть частично — §4.

## 2. Решения

| # | Развилка | Решение | Почему |
|---|---|---|---|
| Р-1 | Ключ корня | top-level `catalog_page_style`, presence-minimal, в `PAGE_CONFIG_KEYS["listing"]` | это ОДНА страница, а не дефолт для многих; живёт рядом с `catalog_preset` в строке «Katalog» Studio; golden целы |
| Р-2 | Наследовать ли корню дефолт категорий | **Нет** | «поставил категориям Navigator — и корень стал Navigator» — сюрприз; замок DL-20 это уже фиксирует |
| Р-3 | Реестр корня | тот же `CATEGORY_PAGE_STYLES` минус `preisliste` | прайс-вид на корне уже даёт `catalog_preset` в той же строке Studio — второй переключатель того же (урок DL-9) |
| Р-4 | Под-сущности корня | корневые категории (`categories`) вместо `subcategories` | Regale = полки по корневым направлениям, Tabs = «Alle» + направления, Navigator/Kompakt — список/указатель направлений |
| Р-5 | Ключ обзора акций | top-level `promo_page_style`, presence-minimal (как `promo_layout`) | одна страница; панель в списке акций + плитка в Studio рядом с `promo_group_style` |
| Р-6 | Реестр обзора | НОВЫЙ `PROMO_PAGE_STYLES` в `group_styles.py` | семантика иная (группы как под-сущности); `Sets` не переносим — у акций нет наборов |
| Р-7 | `promo_layout=slider` vs Regale | Regale = «группы лентами со стрелками» — включает ту же ленту; `promo_layout` остаётся для обратной совместимости и панели | одна семантика — один шаблон |
| Р-8 | Кopfbild обзора без текстов | v1: фото сайта (`hero_image`) + H1 + «N Angebote · M Gruppen»; свои тексты — v2 | `TEXT_FIELDS` материализуются → правка golden ради двух строк не стоит |
| Р-9 | Too Good To Go | предложение владельцу (§4), код — по решению | часть идей — модель (окно выдачи у акции) и внешние каналы (уведомления) |

## 3. Шаблоны

### 3.1 Корень `/sortiment/` (10: все, кроме preisliste)

| Ключ | На корне |
|---|---|
| kopfbild | шапка `catalog_title/intro` + фото (hero сайта), корневые категории плитками |
| sets | полоса наборов (`combos_teaser`) НАД сеткой |
| regale | корневые направления — полками-лентами (товары поддерева, ≤ 8), сетка ниже только для товаров без категории |
| tabs | «Alle» + корневые направления табами |
| schaufenster | первый товар широкой картой |
| navigator | боковая колонка: корневые направления + фасеты |
| magazin | обложка + по 2 карточки с тизером |
| mosaik | бенто |
| kompakt | указатель направлений колонками + сетка по 6 |

### 3.2 Обзор `/aktionen/` (9)

| Ключ | Композиция |
|---|---|
| "" | как сейчас: секции групп (порог 2) / по времени / ленты |
| kopfbild | фото-баннер + H1 + «N Angebote · M Gruppen», дальше секции как сейчас |
| preisliste | таблица (`?ansicht=liste`) как вид ВЛАДЕЛЬЦА; посетитель может вернуть карточки |
| regale | группы лентами со стрелками (= slider) — независимо от порога 2 |
| tabs | «Alle» + группы табами (`?gruppe=` — переход на страницу группы, KAT-5 своп) |
| schaufenster | главный дил широкой картой + «Endet bald» + секции |
| navigator | боковая колонка: группы + системные чипы + поиск; справа плоская сетка |
| magazin | обложка + по 2 в ряд с условиями |
| kompakt | указатель групп колонками + плотная сетка по 5 без секций |

`mosaik` для акций не берём: у карточки акции цена/бейдж/срок обязательны, а бенто их
режет на малых плитках — честнее не обещать.

## 4. Too Good To Go — что перенять (предложение)

Что у них есть и что у нас (проверено по коду):

| Механика TGTG | У нас | Предложение |
|---|---|---|
| Фикс-цена ≈ ⅓ стоимости, «Wert der Tüte» | `compare_at_price` + «Sie sparen» ✅ | подпись «Warenwert ca. X €» у Überraschungstüte (часть `_discount_display`) |
| **Окно выдачи** «Abholung heute 18:00–18:30» | ❌ у акции нет окна, только `reservation_ttl_hours` | `Promotion.pickup_from/pickup_to` (время дня) → на карточке/детали/в письме; ⚠️ миграция |
| «Nur noch X verfügbar» | `available_quantity` ✅ | — |
| Публикация в фиксированное время дня | `starts_at` ✅ (Vorschau) | шаблон «ежедневно в 17:00» — повторяющаяся акция (v2) |
| Отмена посетителем до 2 ч | ❌ | ссылка «Stornieren» в письме резерва до `pickup_from − N h` |
| Оценка после выдачи (Menge/Qualität) | generic-отзывы ✅ | post-redeem письмо «Wie war die Tüte?» → отзыв на акцию (класс LS-5) |
| Избранное + уведомление о новых тютах | Merkzettel ✅, подписки ❌ | «Bescheid geben, wenn es wieder Tüten gibt» — e-mail/Telegram на группу (UWG-DOI есть) |
| Impact «€ gespart / CO₂» | ❌ | счётчик в ЛК: «Sie haben N Tüten gerettet, X € gespart» — из `deal_counts` |
| «Inhalt nicht garantiert» — согласие | mystery-стиль ✅ | чекбокс-согласие в форме резерва mystery/Tüte |
| Карта/список/фильтры | агрегатор ✅ | — |

**Рекомендация порядка:** окно выдачи (модель) → отмена до N ч → уведомление «снова есть»
→ post-pickup оценка → Impact. Всё, кроме первого, без миграций.
