# FB-25 — схема сайта (как Layouts в CS-Cart): блоки каждого типа страницы + уменьшенная живая страница

Фидбэк владельца 2026-11-07: «схема сайта в шаблонах — добавить тип, источник данных, вид
вывода и рядом уменьшенная реальная страница». Разбор батча — `fb-feedback-batch-2026-11-07.md`.
**Статус: план на согласование, кода нет.**

## 1. Что уже есть (разведка)

| Нужно | Где уже есть |
|---|---|
| блоки на каждом типе страницы | `page_blocks[<хост>]` — 26 хостов (`siteconfig.PAGE_BLOCK_HOSTS`), главная — `sections` |
| «＋ блок» с источником и видом | блок «Liste» (LB-1…LB-4): 10 источников × фильтр × сортировка × лимит × вид (сетка/лента, колонки, ряды, форма карточки) |
| основной список страницы среди блоков | маркер «★ Hauptliste» (LB-2) |
| шаблон/сетка/карточка страницы | кабинет «Website › Seitenvorlagen» (STU-19), 30 типов страниц |
| живое превью | канва Студии (двойная буферизация) и превью `?preview=1&tpl=` в «Seitenvorlagen» |

Чего НЕТ — **одного экрана-схемы**: сегодня владелец видит блоки ТОЛЬКО той страницы, что открыта
на канве, и чтобы понять, что стоит на «Termine» или «Über uns», надо переходить туда. CS-Cart
показывает все «Layouts» списком; Shopify — схему секций слева и страницу справа.

## 2. Решение (на согласование)

Экран **«Website › Seitenaufbau»** (кабинет, не Студия):
- слева — **список типов страниц** (из реестра `studio_pages`) с числом блоков у каждого;
- по центру — **схема выбранной страницы**: шапка · блоки над списком · ★ Hauptliste · блоки под
  ним · подвал; у блока — тип, источник/фильтр («Aktionen · Endet heute»), вид («Slider ·
  4 Spalten»), 👁, ↑↓, ✕; «＋ Block» с библиотекой (тот же реестр, что инсертер Студии);
- справа — **уменьшенная живая страница** (iframe `?preview=1`, scale по ширине колонки),
  клик по блоку в схеме прокручивает превью к нему (`data-cb-id` уже есть на витрине);
- «In Studio bearbeiten» открывает канву на той же странице (`?page=`).
Запись — те же писатели, что у Студии (`page_blocks`/`sections` через normalize), без нового
хранения. Тонкие настройки блока — его строка (`_cb_row.html`, тот же партиал).
