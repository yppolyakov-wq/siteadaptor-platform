# KA-12 GA-4 · «Tisch reservieren» с автоподбором стола (2026-10-26)

Продолжение плана `ka-12-w4-gastro-plan-2026-10-26.md`. Без миграций (поля из `booking/0041`).

## 1. Сегодня
Витрина ресторана показывает список ресурсов: гость выбирает «Tisch 4» сам, хотя ему важны
только время и число гостей. При отдельных столах (GA-3, `seats`) это ломает картину: стол 2-местный
занят — слот «пропал», хотя свободен 4-местный.

## 2. Решение
- `table_rules.fitting_tables(party)` — единственная точка «какие столы годятся онлайн»: активный,
  тип table, `seats` задан, не пул (`counts_party_size`), `bookable_online`, `min_seats ≤ party ≤ seats`;
  порядок — наименьший подходящий (`seats`, `sort_order`, `name`).
- `availability.table_slots(day, party)` — объединение свободных слотов годных столов
  `{(start, end): [tables…]}`.
- Витрина `/termin/tisch/` (селектор даты + «Gäste» GET-параметром, слоты объединённые) и POST
  `/termin/tisch/buchen/`. Ядро `termin_book` выносится в общий хелпер (ресурс-кандидаты +
  куда возвращать); для автоподбора кандидаты = годные столы, у которых слот свободен; `book()`
  пробуется по очереди, `SlotTaken` → следующий (гонка: каждая попытка — своя блокировка строки
  ресурса, проигравший уходит на следующий стол). Все исчерпаны — «слот недоступен».
- `termin_index`: при ≥1 годном онлайн-столе — карточка «Tisch reservieren» вместо списка
  отдельных столов; ресурсы прочих типов остаются.
- `bookable_online=False` — стол только для стойки: `termin_slots`/`termin_book` по его pk → 404,
  из списка скрыт. `min_seats` пишется в форме ресурсов (кламп `min_seats ≤ seats`).
- Депозит/правило GA-1 считаются по назначенному столу (решение `decide` — по типу table,
  одинаково для всех кандидатов); `no_show` гейт — по максимальному депозиту кандидатов.

## 3. Замки (до кода)
fitting_tables порядок/фильтры; table_slots объединяет; бронь при занятом наименьшем столе уходит
на следующий; все заняты → нет брони; стол не-онлайн 404; termin_index показывает карточку;
гонка (две брони на последний стол в одном слоте — вторая уходит на другой или отказ).
