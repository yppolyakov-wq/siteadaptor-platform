# План DS-1/DS-2 «Дизайн-шаблоны архетипов» — пилот catering + pranasy (2026-08-12)

Решение владельца: «давай начнём с кетринга и pranasy… для каждого архетипа
несколько готовых дизайнов на выбор, но вначале по одному». Механика Look'ов
(ST-1) уже делает шаблон = данные; пробел — у семейств нет ХАРАКТЕРА: все три
(Klar/Warm/Nacht) — вариации одной вёрстки на системных шрифтах, страница
всегда на bg-gray-50.

## Разведка (факты кода)

- `LOOK_FAMILIES` несёт: font/typography/site_defaults/nav_style/hero_style/theme;
  акцент — `ARCHETYPE_LOOK_ACCENTS[type][idx_семейства]` (кортеж ИНДЕКСИРУЕТСЯ
  позицией семейства → новое семейство = +1 колонка во всех 15 кортежах).
- Шрифты — ТОЛЬКО системные стеки (`FONTS`: system/serif/rounded); комментарий
  в коде: «self-host WOFF2 — отдельно, когда будут файлы». Заголовки уже идут
  через `--font-head` (h1–h4 + hero) → веб-шрифт перекрасит и фото-hero.
- Фон страницы захардкожен `bg-gray-50` на `<body>` — главный недостающий рычаг
  «тёплой» атмосферы.
- hero_style не виден у обоих пилотов (фото-слайдер побеждает) → НЕ трогаем.
- Пилоты: catering «Grüne Tafel» (jobs-primary, GK-15-структура), pranasy
  «Vegan & Ayurveda» (business_type=restaurant, зелёный акцент).
- fontsource CDN доступен через прокси (проверено 200) — OFL-файлы.

## DS-1 — механика (3 рычага, generic)

1. **Self-hosted шрифты заголовков** (OFL, subsets latin+latin-ext+cyrillic —
   демо живут на de/en/tr/ru/uk): Playfair Display 600 (элегантный serif-дисплей)
   и Nunito 800 (округлый дружелюбный). Файлы `static/fonts/*.woff2` (~20 КБ
   каждый), `@font-face` с unicode-range в `static/src/app.css` (пересобрать
   app.css). Провенанс — `static/fonts/SOURCES.md`. `FONTS` += `editorial`
   (Playfair-головы + sans-тело) и `organic` (Nunito-головы + sans-тело);
   грузится шрифт ТОЛЬКО при использовании (lazy по @font-face).
2. **Фон страницы**: `site_defaults.page_bg` (hex, presence-minimal — golden
   целы) → context-processor → инлайн style на `<body>`. При `theme=dark` НЕ
   применяется (тёмная тема красит сама).
3. **Два новых Look-семейства** (доступны ВСЕМ архетипам — это и есть «несколько
   дизайнов на выбор», мастер/Studio подхватят карточки автоматически):
   - **«Fein»** (editorial): font=editorial, вес 600, lh 1.65, карточки r20+тень,
     page_bg кремовый `#faf7f2`, nav centered.
   - **«Natur»** (organic): font=organic, вес 800, lh 1.6, карточки r24+тень,
     page_bg тёплый песок `#f6f2e7`, nav classic.
   - Акценты: +2 курированные колонки во все 15 кортежей (fein — глубокие
     благородные тона, natur — травяные/земляные).

## DS-2 — пилот

- Кит catering → `look="fein"` (акцент fein/catering `#166534` глубокий лес).
- Кит pranasy → `look="natur"` (акцент natur/restaurant `#4d7c0f` листовой).
- Пересев, Playwright-скриншоты (desktop+mobile: главная/каталог/деталь) —
  владельцу на выбор/фидбэк.

## Замки

- `test_looks`: счётчики 3→5 семейств (45→75 Look'ов) — осознанная переписка;
  идемпотентность apply→normalize уже гоняется циклом по семействам — покроет
  новые бесплатно. Golden: page_bg presence-minimal, без ключа = байт-в-байт.
- Новые: page_bg (валидация hex/дефолт), FONTS-ключи в normalize, семейства
  в looks_for, kit-применение look (акцент из реестра).
- Слайд «Stil» мастера/билдер: карточек Look'ов становится 5 — проверить замки
  на количество (переписать осознанно).
