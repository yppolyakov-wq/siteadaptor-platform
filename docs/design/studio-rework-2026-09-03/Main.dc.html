Studio v2 — два уровня настройки

«Есть 2 уровня: настройка дизайна сайта общая и настройка макета каждого типа страниц… Если я нахожусь на странице товара, то показывает настройки именно этого типа… применить для всех или изменить только для этого товара или категории… а то сейчас там каша».

Диагноз

Данные УЖЕ трёхуровневые, а интерфейс плоский:

УровеньЧто в нём живётГде настраивается сегодня
СайтLook, цвет, шрифт, форма карточек, фон, хром Студия → «Тема» · плюс те же Look/сборки ещё на 2 экранах
Тип страницысекции главной, шаблон каталога/категории/акций, раскладки листингов, секции деталей, блоки страницы размазано: часть в «Тема», часть в «Landing», часть на /site/pages/, часть в списке акций
Объектсвоя форма карточки у товара/акции, свой шаблон у категории и группы акцийв Студии недоступно вообще — только формы кабинета

Плюс две несогласованные навигации (рейка уровней поверх вкладок областей), мёртвый код и дубли — отсюда ощущение каши.

Три варианта (артборды справа)

  • V1 «Две полки» — уровень слева в рейке, охват одним переключателем вверху панели.
  • V2 «Один инспектор» — без рейки уровней, охват сегментом Весь сайт | Тип | Этот.
  • V3 гибрид — уровень в рейке + охват пилюлей у КАЖДОЙ настройки, переопределённые помечены точкой. рекомендация

Дальше — как второй уровень выглядит на разных типах: главная · категория · акции · текстовая. Клик по области канвы открывает ровно эту панель — на ЛЮБОМ типе страницы.

Что предлагается убрать

КандидатПочему
Экран /dashboard/design/третье место с теми же Look/сборками
Экран /dashboard/site/pages/второй писатель раскладок листингов
Область «Layout-Vorlagen» (quickstart)переписывает секции, конфликтует со сборкой
Пустая область «Footer», дубль nav_style, мёртвый JSничего не делают
