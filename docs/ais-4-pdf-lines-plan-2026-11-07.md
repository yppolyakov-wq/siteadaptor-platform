# AIS-4 «Speisekarte/Preisliste als PDF → Zeilen» — план (2026-11-07)

Источник: анализ AIS (строка AIS-4), план агента `planner`, сверен с кодом. Продолжение W4-4
(фото → строки, `apps/core/offer_photo.py`).

## Решения
- Библиотека **`pypdf`** (BSD, чистый Python) — только текстовый слой. pymupdf (AGPL) и
  pdf2image (poppler) отвергнуты; отрисовка сканов (pypdfium2) — v2 по спросу.
- Весь разбор PDF — в Celery: ≤ 5 МБ и сигнатура `%PDF-` проверяются в веб-воркере, страницы
  ≤ 10, зашифрованные — отказ, потолок распаковки, ≤ 20 000 знаков, любое исключение → код.
  PDF не сохраняется: байты в кэше задачи с TTL, удаляются при любом исходе.
- **Сначала правила (работают без ИИ):** строка с ценой в хвосте → «Name — Preis»; строки без
  цены (заголовки, адреса, часы) отбрасываются; контакты режутся. ИИ (задача `offer_pdf_lines`,
  P3) — поверх, с дословной проверкой цены и имени по извлечённому тексту; при сбое — правила.
- Скан без текстового слоя → честное «bitte als Foto hochladen oder von Hand eintragen».
- Механика задачи W4-4 общая (замок, опрос, перенос, сессия); `source="pdf"` у черновика.

## Интерфейс
Тот же блок «Foto der Speisekarte», `accept` += PDF; без ИИ блок принимает только PDF.
Фото и PDF вместе — отказ. Плашка про ИИ — только когда ИИ действительно работает.

## Инкременты (без миграций)
P1 зависимость + извлечение + правила · P2 задача/вьюха/шаблон/i18n (путь без ИИ целиком) ·
P3 ИИ-задача поверх · P4 стенд, ревью, документация.

## ECC-прогоны
Скиллы: django-security, django-tdd, django-celery, error-handling. Агенты: django-reviewer,
security-reviewer (загрузка файла, недоверенные данные), silent-failure-hunter (фон, запасной
путь), a11y-architect (поле ввода), стенд Playwright.

## Риски
Многоколоночные меню склеивают строки (видно в таблице «Prüfen»); CID-шрифты без ToUnicode →
`no_text`; байты PDF в Redis до 5 МБ на 5 минут; новая зависимость — следить за CVE pypdf.
