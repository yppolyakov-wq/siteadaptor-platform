## 2. Одно расширение реестра (P0)
В `apps/core/detail_sections.py:27-46` — без второго списка:
```python
@dataclass(frozen=True)
class ContentSource:
    kind: str                 # "field" | "setting" | "page" | "auto"
    shows: object = ""        # «Dieser Block zeigt: …» (gettext_lazy); "" — summary/подпись строки (G2)
    woher: object = ""        # после «Woher:»; у "field" — из field_label и OBJECT_WORDS
    field_label: object = ""  # «Beschreibung» — как на форме объекта (замок)
    fields: tuple = ()        # что считать «ausgefüllt»: ("description",), ("details.idea",)
    query: str = ""           # «?tab=lieferung»
    sub: object = ""          # «Lieferung» → «Zahlarten & Lieferung › Lieferung»
    note: object = ""         # «Hierhin führt „zzgl. Versandkosten“ …», «Gilt für …»
    only_if: object = ""      # «Erscheint nur, wenn …» (тип)
# DetailSection: + source: ContentSource | None = None
```
- `content_nav` остаётся ЕДИНСТВЕННЫМ полем «куда ссылка»: экран для `setting` или СПИСОК объектов для `field`. G2 = `content_nav` без `source` (читается как `setting` с `summary`).
- Слова вида объекта (род в немецком) — `OBJECT_WORDS[kind] = {"every", "this", "all"}`, ключ — `OBJECT_KINDS` плюс `combo` и `post`. Пример: «bei jedem Produkt» / «dieses Produkts» / «bei allen Produkten». Это словарь по видам, не по разделам. Все подписи — `gettext_lazy`.
- **Правило ссылки** (`window_parts.content_part(selected, host, request, *, code, back=None, obj=None, page_label="")`):
  - `setting` — запись `entry_by_url(content_nav)` + `query`, подпись `entry.label[ › sub]`.
  - `field` на типе — запись списка (`content_nav`).
  - `field` на объекте (`detail_parts.object_kind(host)`) — `back.url` / `back.label` и плашка «nur hier». `back` и `obj` — из ОДНОГО `detail_parts.object_for_host(host)` во вьюхе; `object_back(code, obj=None)` принимает готовый объект (тот же `back` — в `render`, `:814`). Запросов в сумме не больше.
  - `page` — `content_pages.edit_url_for_code(code)` (1 запрос, `content_pages.py:583-606`), подпись «Seiten › {current.label}».
  - `auto` — без ссылки.
- **Права:** `nav_registry.screen_closed(request, url_name, target="")`. Видимость модуля — по записи `url_name`; пакет и `can_open` — по `target or url_name`. Цели: `_OBJECT_EDIT_URLS[kind]`; у `page` — `content-page-edit` или `content-page-system`. Записи нет — `logger.error` и ни ссылки, ни причины, как в D1.
- **Модель части:** `{summary, woher, filled, visibility, actions, fixed, note, link{label,url,only_here}, reason}`.
  - `fixed = selected.pinned` — фраза «Er gehört fest…» (у G2 вывод байт-в-байт прежний).
  - `visibility`: тип — «sichtbar — {all}.» / «ausgeblendet.»; объект — `selected.summary`.
  - `actions` — по флагам: «Ausblenden und Verschieben über „⋯“ in der Liste.» / «Ausblenden über „⋯“ in der Liste.» / «Einblenden — Knopf „Einblenden“ in der Liste.»
  - `filled` — только на объекте: «— ausgefüllt.» / «— leer.»
- **Шаблон `_bw_inhalt.html`:** строки «Woher:» и «Auf der Seite:» — подпись жирным плюс текст. Ссылка — имя равно видимому тексту, 44 px (правило `app.css` уже есть). «nur hier» — `ui-badge` внутри ссылки, видимый текст. Без «Platz», «Vorschau» и галочки.
