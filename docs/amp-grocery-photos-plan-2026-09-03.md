# Волна AMP — фотографии демо «Aktionsmarkt Sparfuchs» под продуктовый магазин

Дата: 2026-09-03. Запрос владельца: «Переделай фотографии в акциях под продуктовый
магазин и сгенерируй для него все изображения заново товаров, чтоб был хороший
продаваемый сайт» (https://aktionsmarkt.siteadaptor.de/).

## 1. Что не так сегодня (снято с резолвера, 69 ключей → 41 файл)

Кит `aktionsmarkt` собран из ОБЩЕЙ библиотеки `static/demo/photos/`. Библиотека росла
под другие киты, поэтому у продуктового дискаунтера половина кадров — чужие:

| слот | файл | дефект |
|---|---|---|
| Spülmittel 500 ml + плитка «Haushalt» | `dish-soap.webp` | розово-фиолетовый **пульверизатор**, не средство для посуды |
| Mineralwasser 1,5 L | `water-bottle.webp` | **стакан** воды, а не бутылка |
| Limonade 1,5 L (2-й кадр) | `lemonade.webp` | кружка **травяного чая** с лаймом |
| Tomaten 500 g (2-й кадр) | `cucumber-tomato.webp` | салат с **авокадо** в миске |
| Orangensaft (2-й кадр) | `apple-juice.webp` | тёмно-**красный** сок в банке |
| Gouda 400 g + плитка «Molkerei» | `cheese.webp` | ресторанная сырная тарелка **с бокалами вина** |
| Gemahlener Kaffee (2/3 кадры) и акция | `coffee.webp` / `espresso.webp` / `coffee-cafe.webp` | латте-арт, эспрессо, **интерьер кофейни** — не молотый кофе |
| Backwaren-Tüte | `bakery-bag.webp` | рука с **пончиком** у голубой стены |
| Toilettenpapier 10er | `toilet-paper.webp` | рулоны на **держателе в санузле**, не упаковка |
| Bananen (2-й кадр) | `grocery-shelf.webp` | полка **консервированного горошка** (англ. этикетки) |
| Überraschungskiste (3-й кадр) | `market-stall.webp` | пустой рынок под дождём в плёнке |
| галерея / акция | `shopping-cart.webp` | зелёная тележка на грязной парковке |
| hero-слайд «Überraschungstüten» | `food-box.webp` | корзина с **горькой тыквой** (азиатский набор) |

## 2. Ограничение, определяющее решение

27 из 41 файла ОБЩИЕ с другими китами (`cheese.webp` — bakery/catering/shop,
`lemonade.webp` — cafe/catering/restaurant и т. д.). Перезапись файла чинит
дискаунтер и ломает чужие демо.

**Решение: собственное пространство ключей `markt-*` для всего кита.** Каждый слот
получает своё фото, снятое (сгенерированное) под немецкий продуктовый дискаунтер.
Чужие киты не трогаются ни одним байтом.

## 2b. Фидбэк владельца по ходу волны (2026-09-03)

1. **«Убери туалетную бумагу и бытовую химию»** — продуктовый магазин торгует едой.
   Полка `Haushalt` (Spülmittel/Toilettenpapier/Waschmittel) заменена на `Vorratskammer`
   (Nudeln/Basmatireis/Sonnenblumenöl) **позиция в позицию**: число товаров и порядок
   обхода прежние, поэтому индексы `promotions_spec.product` остались целы (замок
   `test_promotion_targets_still_match_their_products` фиксирует таблицу «акция → товар»).
   Направление переименовано «Vorrat & Haushalt» → «Getränke & Vorrat»; три акции на
   химию переписаны на продукты, носитель Mystery-Deal переведён на Bergkäse (4,99 €),
   чтобы «половина цены» сходилась с прайсом.
2. **«На сгенерированном много пальцев и неестественно»** — AI-генерация для этого
   набора ОТМЕНЕНА целиком. Доступная в среде модель (`image.pollinations.ai`, sana)
   уверенно рисует еду крупным планом, но на сценах даёт пластиковые овощи, оплывшие
   формы и лишние пальцы. Итог: **только реальные фото** (CC0/PDM, Openverse).

## 3. Чем снимали (ревизия после фидбэка)

**Канал 1 — CC0/PDM (единственный, что дошёл до витрины).** `scripts/fetch_cc0_photos.py`
(Openverse, жёсткий фильтр `license=cc0,pdm`, мин. сторона 640 px, провенанс в
`sources.json`). Грабля API: поиск идёт по И, поэтому запрос из 3+ слов даёт 0 —
работают КОРОТКИЕ (1–2 слова) запросы, и лучше списком альтернатив, включая немецкие.

**Канал 2 — AI (`scripts/gen_demo_photos.py`, `image.pollinations.ai`).** Пайплайн
рабочий и оставлен в репозитории, но **в этой волне его результаты не приняты**
(см. §2b п.2). Замеры на будущее: HTTP 200, ~6–10 с на кадр, лимит «1 запрос на IP
в очереди» (при 4 параллельных — `Queue full for IP`; 2 воркера проходят), модель
рисует псевдотекст на любой упаковке с этикеткой.

## 4. Пайплайн

1. `scripts/gen_demo_photos.py` — последовательный генератор по JSON-спеке
   (ретраи с backoff, конверт в webp ≤150 KB, пропуск уже готовых).
2. По 2 кандидата на слот (разные seed).
3. **Визуальная приёмка**: каждый кадр СМОТРИТСЯ (агенты-приёмщики в первых раундах,
   дальше — контактные листы) по рубрике: тот ли сюжет · нет ли текста/ценников/
   логотипов · не пластик ли · та ли культура (не американский ценник, не азиатский
   овощ) · переживёт ли узкий ВЕРТИКАЛЬНЫЙ кроп карточки «Regal».
4. Отбракованные слоты — новый запрос с другими словами, до чистого набора.
5. Установка в `static/demo/photos/markt-*.webp` (cover-кроп 4:3 / 16:9, webp ≤150 KB,
   дедуп по md5 — один кадр не может занять два слота) + провенанс в `SOURCES.md`.
6. Кит переводится на ключи `markt-*` (товары, акции, плитки, hero, галерея).
7. Замок: у каждого слота кита — СВОЙ файл (класс `test_catering_dish_keys_never_
   borrow_another_dishs_photo`), плюс «ни один общий файл библиотеки не изменён».
8. Пересев `seed_demo_tenants --kit aktionsmarkt --recreate` + стенд Playwright.

## 5. Карта слотов (итог)

**32 собственных файла `markt-*`** (все CC0/PDM, провенанс в `SOURCES.md`):

`farm-vegetables`, `orange,juice`.

## 6. Границы

- Другие киты и общие файлы библиотеки не трогаются (замок).
- Индексы `promotions_spec.product` не сдвигаются — товары не добавляются/не
  переставляются, меняются только ключи фото.
- Модель/миграции не нужны.
