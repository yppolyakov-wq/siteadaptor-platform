# Внедрение редизайна кабинета — стиль B «Karten & Luft» (план волн)

Дата: 2026-08-24. Дизайн утверждён владельцем (структура — ок; стиль — B;
финальное «ок» по экранам). Макеты: артефакт «SiteAdaptor Kabinett-Redesign»,
исходники — `docs/design/kabinett-redesign-2026-08-24/`.

## Инварианты всех волн

- FSM/вьюхи/URL/реестр навигации НЕ трогаем — меняется только РЕНДЕР
  (шаблоны, классы, CSS). Мораторий X7 на состав якорей цел по построению.
- W0: скрытие только CSS, поля в DOM.
- Замки держат данные (url_names, sb-min-инвариант SH-17) — сохраняются.
- Новые Tailwind-классы → пересборка app.css в том же коммите (CI-замок).
- Каждая волна — свой коммит(ы), локальные гейты, зелёный CI → main.

## Волны

- **R1 — каркас стиля B** (эта волна): фон кабинета #F2F4F7; сайдбар —
  «парящая» карточка на md+ (скруглённая, тень, без border-r; sb-min-полоса
  работает); активный якорь — залитая индиго-пилюля; мобильный таб-бар —
  плавающая пилюля с SVG-иконками (спрайт ST-4a += ic-nav-*; подписи — в
  title/aria-label); шапка сливается с фоном. + ru.po: Erweitert→
  «Дополнительно», Care-Zyklus→«Цикл заботы» (остальное со скриншота
  владельца — авто-перевод браузера, не наш каталог).
- **R2 — навигация без дублей**: ящик «Erweitert» уходит из рендера
  hub_tabs (состав уже живёт подпунктами сайдбара SM-4 + палитра);
  на страницах остаются только контентные вкладки. Замки hub_tabs —
  осознанная переписка.
- **R3 — Verkäufe**: вкладки-пилюли, карточки списка со статус-пилюлями,
  FAB «+», поиск/чипы в стиле B (мобайл-first; вид Board/Kalender целы).
- **R4 — главная**: карта Umsatz + цветные плитки + «Erfordert
  Aufmerksamkeit» + «Als Nächstes» (данные уже есть: home_widgets/
  dashboard_tiles/Heute-свод X3).
- **R5 — формы и карточки**: форма товара (машинка Ф1-табов цела, стиль B),
  карточка заказа (действие сверху), свод Einstellungen в «один экран
  секциями» — отдельным план-доком (13 табов W9, большой объём).
- **R6 — десктоп-доводка**: master-detail на Verkäufe (список + карточка
  рядом) — по спросу после обкатки R1–R5.

Каждая волна закрывается скриншотами стенда (Playwright, mobile 390 +
desktop 1440); развилки, которых нет в макетах, — вопросом владельцу.
