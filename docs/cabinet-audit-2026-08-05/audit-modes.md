## PROBLEMS

### [high] Простой режим НЕ влияет на меню в новом (дефолтном) кабинете — главное обещание режима не выполняется
`modules.sidebar_nav()` (apps/core/modules.py:653-712) — резолвер компактного сайдбара ST-4b — гейтит якоря ТОЛЬКО по `is_module_active`, фильтра `simple_hidden_modules()` в нём нет. Фильтр живёт исключительно в `grouped_active_modules()` (modules.py:778-797), а эта функция рендерится только в else-ветке шаблона (`templates/tenant/_base_dashboard.html:65-110`), т.е. когда `nav_compact` пуст — а он пуст ТОЛЬКО при classic_ui (modules.py:656). Итог: у тенанта с новым видом (дефолт!) нажатие «Einfach» в шапке не убирает из меню ничего. При этом план ST-4b прямо требовал обратного: docs/st4b-sidebar-plan-2026-07-19.md:45-46 «Простой режим (ui_mode=simple) и simple_hidden_modules — сохранить семантику (скрытие хабов у архетипов) в новом резолвере». Требование потеряно при реализации, и ни один тест этого не ловит. Тултип тумблера (_base_dashboard.html:124) при этом обещает конкретный список скрываемого.
Files: apps/core/modules.py, templates/tenant/_base_dashboard.html, docs/st4b-sidebar-plan-2026-07-19.md

### [high] Разделы Finanzen / Auswertungen / Blog / Abo&Zahlung недостижимы из навигации нового кабинета; Простой добивает последний вход в Finanzen
`NavItem`-ы реестра (modules.py:304 analytics, :363 blog, :432 finance, :513 billing) рендерятся только классическим сайдбаром. В новом виде: `sidebar_nav()` — 7 хардкод-якорей без них; `HUB_TABS["settings"]` (cabinet.py:117-131) содержит settings/payments/notifications/legal/extras/languages/media/domains/modules/support — finance, analytics, blog, billing там НЕТ. Проверено grep'ом: во всём templates/ ссылка `{% url 'finance:journal' %}` есть только на finance/invoices.html:6, `{% url 'billing' %}` — только на billing/payments.html:6, `blog-list` — только на events/blog_edit.html:6. Единственный вход в Finanzen из нового кабинета — виджет «Umsatz heute» на главной (apps/core/dashboard.py:127-155), а он гейтится `"finance" not in hidden` → включённый (оплаченный, включённый вручную) модуль finance в Простом режиме становится доступен ТОЛЬКО по прямому URL. Страница подписки /dashboard/billing/ не линкуется вообще ниоткуда в новом хроме (шапка _base_dashboard.html:121-146 её не содержит).
