# AI-CFG — настройки ИИ в админке платформы (2026-10-23)

**Запрос владельца:** «предупреждение ai.W004 надоедает при каждом деплое; настройки ИИ
вынести в мою админку, чтобы просто выбрать».

## Решение
- **ai.W004** глушится из `.env`: `SILENCED_SYSTEM_CHECKS=ai.W004` (общая настройка Django,
  читается из окружения).
- **Резолвер `apps/ai/config.py`** — единственная точка чтения настроек ИИ:
  `override` (тесты, `ai_smoke`) → строка `AIConfig` (id=1, public) → `settings` (`.env`).
  Реестр `SPECS` задаёт тип каждой настройки; мусор в JSON отбрасывается к значению `.env`.
  Кэш процесса 15 с; база недоступна → значения `.env` (fail-safe).
- **«Nur EU» — пол из `.env`:** админка может включить, но не ослабить. Все проверки
  (маршруты, system checks, текст Datenschutz) читают `config.require_eu()`.
- **Экран** «KI-Einstellungen» (`/admin/ai/einstellungen/`, только суперпользователь):
  выключатель, маршруты fast/strong с резервами, модели, задачи, лимиты, цены; пустое поле =
  «как в .env». Проверка теми же правилами, что system checks; ошибка — не сохраняет.
  Ключи провайдеров здесь не хранятся и не показываются (Plattform → Geheimnisse).
  Каждое сохранение — запись в журнал аудита с диффом.
- Потребители переведены на `config.get`: `api`, `routing`, `budget`, `pricing`, `checks`,
  `disclosure`, поиск ИИ портала, модерация каталога, `ai_smoke`.

## Попутно (фидбэк «сладости»)
- Фолбэк опечаток для кириллицы: порог `word_similarity` 0.5 (было 0.3 — «сладости» ≈
  «кости», «лояльности» по окончанию «-ости»).
- Подсказка ИИ под выдачей срабатывает и на ОДНО слово, если точных совпадений нет
  (режим «ähnliche»/пусто), и без потолка числа похожих — они не ответ на запрос.

## Ops
1. Деплой (миграция `ai/0002_ai_config`, SHARED, новая таблица).
2. В `.env.prod`: `SILENCED_SYSTEM_CHECKS=ai.W004`; убрать дубль строки `AI_TASKS_ENABLED`.
3. Админка → «AI settings»: проверить значения, при необходимости выставить.
