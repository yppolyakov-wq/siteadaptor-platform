# UX-D D7 — узкие страницы кабинета → ширина экрана по делу (2026-11-04)

Последняя волна UX-D (`ux-declutter-analysis-2026-11-03.md` §4, правило **П6**: «на широком
экране — две колонки (содержание + сводка), а не узкая колонка»). Без миграций.

## 0. Замер (стенд, 1600 × 900, hotel/friseur/werkstatt/restaurant)

Скрипт обхода всех пунктов меню: доля пустоты справа = 1 − (ширина блоков, взвешенная по их
высоте) / ширина `#main`. Шапка страницы (заголовок + кнопки во всю ширину) в расчёт не входит —
первая версия замера считала её «занятой» и показывала 0 % там, где контент узкий.

| Пусто справа | Экран |
|---|---|
| 60 % | Einlösen (сканер) |
| 55 % | Betriebsferien, запасные страницы шторок (`termin/neu`, `stays/neu`) |
| 45–50 % | Beiträge, Sprachen, Blog, Kanäle |
| 36–40 % | Hilfe, SEO, Weiterleitungen |
| 25–33 % | Importieren, Ergebnis, Abo & Rechnung, Unterkunft, Berichte, Kombi, Kurtaxe-Meldung, Kollektionen, Preise & Regeln, Zusatzleistungen |
| 20–22 % | Team, Offene Posten, Tage blockieren, Design, Recht & Steuern, Aktionstypen, Produktion |

Плюс страницы объектов (не в меню): услуга, ресурс, номер — `max-w-3xl`, справа ~45 % пусто;
у номера фото лежат ПОД карточкой формы.

## 1. Классы страниц и решение

**А. Секции, сложенные стопкой, но независимые** → `xl:grid-cols-2` (на телефоне и до xl —
одна колонка, порядок прежний):
- Unterkunft (Kurtaxe · Hausordnung | Check-in · Ausstattung)
- Betriebsferien (форма | запланированные закрытия)
- Weiterleitungen (добавить + CSV | список)
- Hilfe (мои обращения | новое обращение)
- Importieren (загрузка | последние импорты)
- Beiträge (композер | запланированные/последние)
- Kanäle (платформы | личные каналы + последние публикации)

**Б. Отчёты и таблицы, зажатые `max-w-4xl`** → на всю ширину, плитки 4 в ряд на xl:
Kurtaxe-Meldung, Berichte, Ergebnis, Offene Posten (таблица уже широкая — проверить плитки),
SEO (контейнер `max-w-3xl` → шире; превью сниппета уже справа внутри строки).

**В. Страницы объектов** (услуга, ресурс, номер) → две колонки на xl: слева вкладки и форма,
справа карточка «Überblick» (фото, ключевые числа, статус, «Auf der Website ansehen»). У номера —
фото переезжают в правую колонку. Общий партиал `core/_object_aside.html`, данные — из того, что
вьюха уже передаёт (новых запросов нет).

**Г. Блог: открытая форма «Neuer Beitrag» под списком** (нарушение П2; кнопка «＋» в шапке уже
есть и ведёт якорем на ту же форму) → своя страница `blog-new` (тот же код создания; GET без
побочных эффектов; X7 — запись в nav_registry/EXPECTED_UNLISTED; `view_perms` = как у списка).

**Оставляем узкими осознанно** (замок не нужен — это не «пустота», а читаемость):
- списки строк (Kollektionen, Zusatzleistungen, Team, Kombi, Aktionstypen) — строка из имени и
  2–3 чисел на 1280 px читается хуже; ширина `max-w-4xl` — по П1;
- сканер «Einlösen», запасные страницы шторок (`…/neu/` без JS), подтверждения удаления;
- «Sprachen» — один короткий список.

## 2. Инкременты

| ID | Что | Замки |
|---|---|---|
| D7.1 | класс А (7 экранов) | на каждом: обёртка `xl:grid-cols-2`, все формы/поля на месте (W0 — набор `name=` до/после совпадает) |
| D7.2 | класс Б (5 экранов) | нет `max-w-4xl/3xl` у корня; плитки `xl:grid-cols-4` |
| D7.3 | класс В (3 страницы объектов) | партиал есть, фото номера справа, формы вкладок те же |
| D7.4 | блог: страница создания | GET без записи; POST создаёт; список без `<form>` с полями; перевод/обложка/дата работают |
| D7.5 | стенд 1600/390 + повторный замер | пустота справа ≤ 25 % на экранах А–В; на 390 нет горизонтального скролла |

Гейт каждого батча: `ruff`, `ruff format --check`, `npm run build:css` (новые классы
`xl:grid-cols-2/4` могут отсутствовать в app.css), `test_template_comments`, `i18n_quickcheck`.

## 3. ECC-прогоны
- до кода: скиллы `accessibility` (порядок фокуса и чтения в двух колонках = порядок DOM),
  `e2e-testing` (стенд);
- после D7.1–D7.4: `django-reviewer` (блог-страница: права, GET без побочных эффектов),
  `a11y-architect` (две колонки, заголовки секций, aside с `aria-labelledby`);
- D7.5: Playwright-замер тем же скриптом (`d7scan.js`) до/после.

## 4. Итог (2026-11-04) — D7.0–D7.5 ✅

Замер после: пустота справа на экранах А–Б 9–13 % (было 25–55 %); стенд 30/30 (1600 и 390:
200, нет горизонтального скролла, нет JS-ошибок). Ревью: django-reviewer — без блокирующих
(исправлено: акцент тенанта в превью, ввод статьи не теряется при ошибке); a11y-architect —
превью стало `section` с пояснением для чтеца (не вложенный `aside`), sticky ниже шапки
(`xl:top-20`), видимые подписи полей статьи, autofocus снимается после ошибки, без дублей
заголовков. Отложено: роли `tabpanel` у вкладок страницы услуги (вне D7).
