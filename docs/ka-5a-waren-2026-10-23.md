# KA-5a · Проход по архетипам «Waren» (2026-10-23)

> Часть программы `ka-cabinet-audit-program-2026-10-22.md`. Архетипы: bakery, butcher, grocery
> (еда), retail, clothing, online_shop (+ кит outlet). Метод: 7 ежедневных сценариев владельца →
> путь в кабинете по коду (экраны, клики, обязательные поля) → что мешает, чего нет, что лишнее.
> Две разведки по коду; утверждения о деньгах и данных перепроверены вручную (помечено ✔/✘).
> Целевая структура меню — KA-4; пакеты — KA-3. Кода нет, кроме хотфикса KA-H4 (§5).

## 0. Модули по умолчанию

Еда: promotions, crm, reviews, orders, loyalty, gift, blog, inbox, customer_account (`modules.py:379-384`).
Не-еда: то же без loyalty. **У всех выключены finance, analytics, publishing, jobs** — отсюда половина
проблем со счетами, выручкой дня и Google Merchant. Демо-киты включают больше (jobs, lots), поэтому
демо выглядят богаче реального нового магазина.

## 3. Общие выводы для группы

**Лишнее (шум)** — подтверждает KA-4: Kitchen Display и Tisch-QR у пекарни/мясной/продуктового
(`_sales_body.html:43`, гейт `is_food` шире решения VF-5); Kollektionen, Kombi, Einkauf, Import у
всех; Stadtportal, Finder, Zusatzleistungen, Abläufe & Status; «Lieferungen» без доставки; Chargen/
MHD и «Produktion buchen» в Lager у одежды; в форме товара «Marke & Zustand», «Gang», UVP без гейта;
Aktionstypen mystery/vorbestellung; название модуля «Bestellungen (Click & Collect)» у онлайн-шопа.

**Не хватает (по важности):**
1. Время забора и слоты выдачи с ёмкостью, срок приёма предзаказов (еда).
2. Массовые действия: заказы (статус), товары (цена, видимость), экспорт товаров.
3. Генератор матрицы вариантов размер×цвет, фото на цвет.
4. Главная по делам (KA-4 §6): новые / к отправке / неоплаченные / к выдаче сегодня.
5. Возвраты: частичный возврат денег, RMA, Gutschrift/Stornorechnung; статус «zugestellt».
6. Доставка в AT/CH: страна в адресе, НДС по стране (OSS), вес, перевозчики/этикетки.
7. Производственный список дня (Backliste/Zerlegeliste), повторяющиеся заказы (Brötchen-Abo).
8. «Ausverkauft heute» с автосбросом, праздники/пауза заказов, товар на развес.
9. 7 % НДС по умолчанию у пищевых типов.
10. Скидка на категорию/магазин; §11 PAngV по вариантам; фид `g:size`/`g:color`.

## 5. Хотфикс KA-H4 — возврат денег не должен зависеть от экрана

По правилу программы (деньги — сразу хотфиксом): единая точка возврата оплаты при отмене/возврате
оплаченной сделки (order / booking / stay), вызываемая со всех поверхностей смены статуса
(per-app экраны, доска, список, общая карточка сделки, ЛК клиента). План и замки — отдельным
инкрементом по обычному циклу (planner → замки → ревью → CI → main).
