# Глоссарий кабинета — одно слово = одна сущность

Создан волной X4 (`docs/x4-navigation-plan-2026-08-19.md` §5). Причина: аудит
2026-08-05 и исследование 2026-08-18 нашли слова, которыми кабинет называл по три
разные вещи — владелец не мог угадать, куда ведёт пункт меню.

**Правило:** новое имя экрана/раздела/кнопки сверяется с этой таблицей. Если
нужного понятия здесь нет — добавить строку в том же коммите.

## Разделы навигации (якоря сайдбара)

| Слово | Значение | Где | НЕ значит |
|---|---|---|---|
| **Übersicht** | главная кабинета: работа дня + чек-лист настройки | `/dashboard/` | «обзорный список чего-либо» |
| **Verkäufe** | СДЕЛКИ: заказы, записи, брони, билеты, заявки, резервы + рабочие входы дня | `/dashboard/verkaeufe/` | каталог того, что продаётся |
| **Sortiment** | то, ЧТО бизнес продаёт: товары, услуги, номера, события, туры, комбо | `/dashboard/angebote/` | оферта клиенту |
| **Marketing** | привлечение и общение: акции, кампании, отзывы, контакты, сообщения | `/dashboard/marketing/` | продажи |
| **Website** | конструктор витрины (Studio) + SEO/домены/медиа | `/dashboard/site/home/` | настройки бизнеса |
| **Einstellungen** | настройки бизнеса, права, оплата, интеграции, команда | `/dashboard/settings/` | настройки внешнего вида |

## Спорные слова

| Слово | Что значит в кабинете | Чем НЕ является |
|---|---|---|
| **Angebot** | ОФЕРТА конкретному клиенту: Sofort-Angebot из переписки, смета Handwerker | раздел товаров (он «Sortiment»); скидка (она «Aktion») |
| **Aktion** | скидочная кампания (`promotions.Promotion`) | оферта; товарная позиция |
| **Ticket** | СДЕЛКА по событию (проданный билет) — вкладка Verkäufe | само событие (оно «Veranstaltung») |
| **Veranstaltung** | событие как продаваемая сущность — раздел Sortiment | проданный билет |
| **Auftrag** | заявка клиента (`jobs.Job`) в работе | заказ товаров (это «Bestellung») |
| **Bestellung** | заказ товаров (`orders.Order`) | заявка; закупка у поставщика |
| **Einkauf** | ЗАКУПКА у поставщика (`inventory.Bestellung`) | продажа |
| **Leistung** | услуга по времени (`booking.Service`) | работа по заявке |
| **Abläufe** | статусы, правила переходов, колонки доски | «процессы» вообще |
| **Kanäle** | каналы публикации (GBP/FB/IG) | каналы уведомлений; OTA-каналы («Channel Manager») |

## Витрина ≠ кабинет

На витрине «Angebote» остаётся привычным клиенту словом для акций/предложений
(пункты меню демо-китов, `apps/tenants/menu.py`). Глоссарий регулирует ЯЗЫК
КАБИНЕТА; менять витринные подписи под него не нужно.
