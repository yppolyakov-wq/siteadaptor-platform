# DL-14 — «Verteilen» + авто-колонки по количеству (фидбэк 2026-09-02)

**Запрос владельца:** «если товара мало, к примеру 4, а сетка на 5 — либо делать сетку на 4,
либо растягивать на всю ширину (увеличивать отступ); так же с последними товарами в
списке — скорее всего увеличивать отступ». Решение: «по рекомендации — Verteilen +
авто-колонки». Продолжение DL-11 (`dl11-fill-rows-plan-2026-09-02.md`), БЕЗ миграций.

## 1. Механика

| Слой | Что | Где |
|---|---|---|
| **Авто-колонки** (без ключа, всегда) | Если элементов N меньше колонок окна — колонки = N, но не ниже пола: планшет 2, десктоп 3, телефон без изменений. Сервер клампит триплет в `data-sf-cols` и ставит `data-sf-auto="1"`; CSS по этим атрибутам переопределяет `grid-template-columns` (классы Tailwind не меняются → паритет-замки строк классов целы). | `siteconfig.auto_cols_triplet` · `grid_attr_string(count=)` · генератор |
| **Verteilен** (`tail="spread"`) | Неполный последний ряд (и единственный неполный ряд после пола авто-колонок) раскладывается равномерно по всей ширине: ширина плитки как у колонки, отступы больше (`flex-wrap` + `space-evenly`; ширина плитки = (100% − (n−1)·gap)/n на каждом окне через `--sf-n`/`--sf-gap`). Полные ряды выглядят как прежняя сетка. | генератор: `[data-sf-tail="spread"]` |
| **Дефолты** | Главная: `trim` как в DL-11 (ряды полные), в Studio «Letzte Reihe» += «verteilen». Листинги (каталог, категории/подкатегории, /aktionen/, /kombi/, «похожие»): `spread` вместо плитки-подсказки; плитка (`fill`) остаётся режимом по ключу `tail` раскладки страницы. | вьюхи + шаблоны |
| **Лента «Endet bald»** | 4 карточки фиксированной ширины на десктопе распределяются по ширине (`lg:justify-evenly`). | promotions_list.html |

Исключения (как в DL-11): `.is-list` (посетительский список), `[data-density]` (KAT-4).

## 2. Точки правки
siteconfig (`_LAYOUT_TAILS`, `auto_cols_triplet`, `grid_attr_string`) · `scripts/gen_fill_rows_css.py`
(+ блок app.css) · `siteui.grid_attrs(count=)` + новый `sf_grid_attrs` для сеток без секции ·
13 секций главной (count) · products.html / promotions_list.html / _combo_grid.html /
product_detail.html · public_views (tail листинга = `layout.tail or "spread"`, плитка только при
`fill`) · Studio-селект · замки test_fill_rows (осознанно: листинги spread) + новые.

## 3. Замки
auto_cols_triplet (пол/кламп/без count — 1:1) · grid_attr_string с count → `data-sf-auto` ·
CSS-блок = генератор (spread-правила, gap-переменные) · главная: 2 категории при cols4 →
`2/2/3` + auto · листинг по умолчанию `spread`, без плитки; `fill` по ключу — плитка есть ·
Studio round-trip `spread` · стенд: каталог «Getränke» (4 товара при 5 колонках) → 4 колонки,
/aktionen/ группа из 4 при 3 колонках → второй ряд распределён.
