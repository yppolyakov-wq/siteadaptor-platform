# T-8.24 «Страница предложения внутри портала» — план (2026-10-11)

Решения владельца: Q5 — отдельная страница; SEO — стратегия **А** (canonical на страницу
бизнеса, хаб в выдаче — страницы-списки портала). Источник — `t8-23-lite-feedback-plan §5.4/§5.6`.

## 1. Что сейчас

Карточка в ленте портала (`aggregator/_cards.html`) ведёт сразу на сайт бизнеса
(`AggregatorListing.portal_url` = `detail_url?ch=portal`). Житель уходит из портала с первого
клика и не видит рядом ни других предложений этого бизнеса, ни похожих в районе.

## 2. Что делаем

- **Роут** `angebot/<int:pk>/` — на портальном хосте (`portal-offer`, до catch-all `<facet>`) и
  на главном домене (`entdecken/angebot/<int:pk>/`, `aggregator-offer`, до `<city>`).
- **Вьюха** `aggregator.views.offer_page`: одна выборка по pk из `objects.public()` (видимость
  T-8.6 — приостановленный/скрытый/без согласия = 404); на портале — в границах портала
  (город/тип бизнеса/демо — как лента), иначе 404 (чужое предложение не открывается чужим
  порталом).
- **Страница** `aggregator/offer.html`: фото, бейджи вида/скидки/«Neu»/наличия/Demo, заголовок,
  цена/«statt», срок «bis …», тизер, бизнес (имя, район, рейтинг, ссылка на страницу бизнеса в
  портале), **главная кнопка «Zum Angebot bei <Geschäft>»** → `portal_url` (атрибуция
  `?ch=portal` сохраняется), «Melden». Ниже две полосы карточек: «Mehr von <Geschäft>» и
  «Ähnliches in der Nähe» (тот же район, иначе город; тот же раздел каталога, иначе тот же вид) —
  по 4, без самого предложения, через общий `_cards.html`.
- **SEO (стратегия А):** `<link rel="canonical">` = `detail_url` (страница бизнеса),
  JSON-LD Product/Offer с `url` = `detail_url` — для ИИ-агентов данные доступны и здесь.
- **Ссылки:** карточки ленты (`_cards.html`) ведут на страницу предложения (тот же партиал —
  страница бизнеса, «Merkliste», результаты Finder). Оплаченная позиция (D2.3) по-прежнему ведёт
  счётчиком прямо на сайт бизнеса — клик оплачен рекламодателем, `rel=sponsored` сохраняется.
  Под тенантным urlconf роута нет — карточка ведёт на сайт бизнеса, как раньше.

## 3. Нагрузка

Нового хранения нет; одна выборка по первичному ключу + две полосы по 4 (индексы
`tenant_schema`, `city/is_active`). Меньше ленты.

## 4. Замки

`apps/aggregator/tests/test_offer_page.py`: 200 + кнопка с `?ch=portal` + canonical на
`detail_url`; скрытое/приостановленное/чужой портал → 404; демо на портале без `show_demo` →
404; карточки ленты ведут на `/angebot/<pk>/`; полосы не содержат само предложение;
под тенантным urlconf карточка ведёт на сайт бизнеса.

## 5. Вне v1

Отдельный sitemap страниц предложений не делаем (canonical на бизнес — индексировать нечего);
карта на странице — по спросу.
