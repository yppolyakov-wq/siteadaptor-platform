# KA-12 GA-9 · Tageskarte: блюдо по дням недели (2026-10-26, ⚠️ `catalog/0041`)

Продолжение `ka-12-w4-gastro-plan-2026-10-26.md` (D7). Сегодня блюдо «только по средам»
(Fischtag, Schnitzeltag) владелец вынужден включать/выключать руками каждое утро; «Heute
ausverkauft» (W1.3) — про остаток, не про расписание.

## 1. Модель
`Product.available_weekdays` — JSONField-список `0..6` (пн=0), `[]` = каждый день (все прежние
товары — без изменений, миграция аддитивная, `default=list`). Свойства
`available_on(day)` и `is_on_menu_today`; подпись `weekdays_label` («Mo · Mi»).

## 2. Где действует (одна точка `available_on`)
- **Чекаут** (`orders.services.create_order`): блюдо не по дню выдачи → новое
  `NotOnMenu(title, label)` ДО списания склада; день = `pickup_slot` (локальная дата), без слота —
  сегодня. Сообщение в корзине: «„X“ gibt es nur Mo · Mi.» Предзаказ на нужный день остаётся
  возможным — `in_stock` НЕ трогаем (иначе кнопка пропала бы и для предзаказа).
- **Витрина**: бейдж «Nur Mo · Mi» на карточке/детали/строке корзины (общий партиал);
  фасет `?heute=1` «Heute auf der Karte» в `CatalogFacets` (`[]` ∪ `contains=[wd]`).
- **Фид Google / наличие в магазине**: сегодня не в меню → `out_of_stock` (как «ausverkauft»).
- **PDF Speisekarte**: «nur Mo · Mi» в подстроке блюда.
- **Кабинет**: чекбоксы дней в форме товара (гастро — секция маркировки еды), сентинел
  `weekdays_present` (W0: форма без поля не стирает расписание), все 7/ни одного → `[]`.
- **Демо** restaurant: два блюда с днями.

## 3. Замки (до кода)
available_on/label; create_order отказывает по дню слота и пропускает в нужный день, без слота —
по сегодня, склад не списан при отказе; фасет `?heute=1`; форма: сентинел, 7 дней → `[]`,
без сентинела — не трогает; фид out_of_stock; PDF содержит пометку.

## 4. Не в этом инкременте / осознанные границы v1 (по ревью)
- Фильтр дней в пикере слотов по составу корзины (сервер отказывает на POST — UX v2).
- Доставка и самовывоз без слота проверяются по СЕГОДНЯ (дня доставки в модели нет).
- Запрос (`quote`) и предложение владельца (`offer`) правилу не подчиняются; строки акций с
  товаром — подчиняются. Блюда внутри наборов (Combo) — v2.
- Чужие обработчики чекаутов (акция/Anprobe) показывают общий «nicht verfügbar».
- Снимок агрегатора по дню (обновляется по сохранению — как у «ausverkauft»); основной фид
  Google — заказуемость (предзаказ), локальный фид — 0 на «чужой» день.
