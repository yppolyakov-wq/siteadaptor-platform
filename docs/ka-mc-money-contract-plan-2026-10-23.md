# KA-MC — денежный контракт сделки + сквозной инвариант (2026-10-23)

Батч F пилотной волны (`pilot-wave-plan-2026-10-23.md`), корень №1 из
`ka-11-synthesis-2026-10-23.md §2`. План — агент planner; решения владельца ниже.

## Решения владельца (2026-10-23)
- **MC-D1:** выручка проводится в журнал **при исполнении** (как сейчас), не при
  поступлении денег (Ist-Versteuerung — отдельная волна, если понадобится).
- **X1:** оплата «на месте» (способ `on_site` или пусто) считается полученной в
  момент исполнения — сделка уходит из Offene Posten. Vorkasse/счёт/Stripe остаются
  открытыми (настоящая дебиторка).

## Контракт `apps/core/money_contract.py` (только чтение, без миграций)
`money_state(kind, obj) -> MoneyState(total, paid, refunded, due, posted, online_paid, invoice)`.
Один источник карт состояний оплаты (сейчас скопированы в `finance/bank.py`,
`core/payments_page.py`, `core/payment_holds.py`, `core/refunds.py`).

## Инвариант (по фазам; журнал — при исполнении)
- **I-J:** достигнут статус выручки и не отменено → `posted == total`; отменено →
  `posted == paid − refunded`; иначе `posted == 0`.
- **I-C:** `0 ≤ refunded ≤ paid ≤ total`; отменено → `due == 0`.
- **I-INV:** выставленный счёт → `gross == total`, `open_amount == due`.
- **I-OP:** сумма сделки в Offene Posten == `due`, не больше одной строки на сделку.

## Найденные расхождения
Чиним в батче: **X1** (на месте → оплачено при исполнении), **X2** (банк-сопоставление
мимо FSM → один `settle_payment`), **X3** (сделка дважды в Offene Posten при
выставленном счёте; оплата счёта не трогает сделку), **X4** (билет в Offene Posten
до вычета ваучера), **X5** (счёт из записи: ставка допов и копейка округления),
**X6** (no-show удерживает депозит, а журнал 0).
Известные (strict xfail с ID): **MC-E8** частичный возврат (миграция `refunded_cents`),
**MC-H6** аванс заявки без Anzahlungsrechnung (налоговое решение), **MC-Z9**
сертификат как Rabatt режет базу НДС, **MC-J1** заявка с неоплаченным депозитом не
в Offene Posten, **MC-T1** депозит билета как «не оплачено» в удержании.
