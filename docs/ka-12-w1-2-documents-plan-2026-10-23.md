# KA-12 Волна 1.2 — документы: Stornorechnung, счёт по ставкам, адрес получателя (2026-10-23)

План — агент planner (полный отчёт в истории сессии). Источник — `ka-12-master-plan` E1.1–E1.3,
`ka-9-compliance` №14–17.

## Сегодня
- Отмена счёта оставляет номер и рисует красный водяной знак «CANCELLED» на оригинале —
  выданный документ меняется задним числом (GoBD).
- PDF: нет нетто по ставкам, нет переноса страниц, описания режутся до 70 знаков.
- Частному получателю — только имя (§ 14 Abs. 4 Nr. 1 UStG; Kleinbetragsrechnung до 250 €).
- После отмены нельзя выставить исправленный счёт (переиспользуется первый счёт сделки).

## Решения
- **D-1** Stornorechnung — тот же счётчик (сквозная нумерация без пропусков), заголовок
  «Stornorechnung zu RE-… vom …», суммы = минус оригинал (снимок, не пересчёт).
- **D-2** старые отменённые счета без сторно сохраняют водяной знак; новые — без него.
- **D-3** 0 %: текст освобождения из снимка строки (`vat_note`, Kurtaxe — «durchlaufender Posten»),
  иначе общий текст. Формулировки — юристу (пакет E7).
- **D-4** новая раскладка PDF действует и для уже выданных счетов (суммы те же).

## Миграция `finance/0015` (аддитивная)
`Invoice.kind` (invoice|storno, default invoice) + `cancels` OneToOne(self, PROTECT) + CheckConstraint.

## Где сторно исключается
`money_contract.invoice_for`, `bank.open_items` и сопоставление, Mahnung, win-back, переиспользование
счёта сделки (после отмены можно выставить новый).

## Замки до кода
Суммы сторно = −оригинал по каждой ставке; оригинал неизменен; нумерация без пропусков и
идемпотентность; сторно не в Offene Posten/Mahnung; журнал job — ноль по ставке; PDF: нетто по
ставкам, 0 %-текст, 60 строк → ≥ 2 страниц, длинное описание целиком; частный > 250 € без адреса —
выставление заблокировано.
