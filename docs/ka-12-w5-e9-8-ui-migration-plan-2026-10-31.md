# KA-12 W5 · E9.8 — перевод экранов кабинета на детали `ui-*` (2026-10-31)

## Замер
Рукописные классы вместо деталей E9.1 в шаблонах кабинета: **поля во всю ширину** 257
(`w-full rounded-lg|xl border border-gray-… px py`), **основные кнопки** 121
(`bg-indigo-600|bg-gray-900 text-white …`), **карточки** 130 (`bg-white rounded-xl|2xl shadow|border`).
Каждый экран выглядит чуть по-своему (радиусы 8/12/16, тени, высота полей 36–44 px, шрифт 14/16 px
на телефоне → iOS зумит поле).

## Что делаем
Механический конвертер по токенам класса (не по строкам целиком):
- поле → `ui-input` (снимаются: `w-full rounded-* border border-gray-* bg-white px-* py-* text-sm|base
  focus:*`; остаются раскладочные: `sm:col-span-*`, `flex-1`, `min-w-*`, `font-mono`, `mt-*`, …).
  Не трогаем: file/checkbox/radio, узкие инлайн-поля (без `w-full`).
- основная кнопка → `ui-btn ui-btn-primary` (+`ui-btn-sm`, если была `py-1|1.5` или `text-xs`);
  снимаются цвет/фон/отступы/радиус/hover/шрифт; остаются раскладочные (`w-full`, `mt-*`, `shrink-0`…).
- карточка → `ui-card` (снимаются `bg-white rounded-* shadow* border border-gray-*`; отступ `p-*`
  остаётся — утилита сильнее компонента).
Студия (`site_home`, `site_preview`, `_cb_row`, `_section_fields`, `_builtin_list_fields`) и мастер
настройки (`setup*`) — вне объёма: там JS переключает именно эти классы, свой вид. Публичные
регистрация/онбординг (`tenants/`) и витрина — не кабинет.

## Инварианты
Только классы; разметка, `name`/`data-*`/JS-хуки, тексты — прежние. Цвета — токены `--ui-*`.

## Замок
Храповик в `test_design_guard.py`: число рукописных полей/кнопок/карточек в кабинете не растёт
(после конвертера — фиксируем остаток, цель 0).

## ECC-прогоны
- Скилл `accessibility` (размер цели 44 px у полей, фокус-кольцо `ui-btn`).
- `code-reviewer` — выборочно дифф конвертера (потерянные раскладочные классы, JS-хуки).
- Playwright-стенд: 4–5 экранов до/после на 1440 и 390 (товар, заявка, логистика события,
  оплата/доставка, склад) — без наездов и переполнения.
- Гейт: ruff, полный pytest (замки разметки на старые классы), `npm run build:css`.
