# T-15 — справка по коду: связи файла по запросу, оглавление ядра, замок на новые взаимные зависимости

Дата: 2026-11-24. Запрос владельца: «карта зависимостей всего проекта, чтобы ИИ быстрее понимал задачи,
зависимости и связи». Код приложения не меняется; только новые файлы в `scripts/` и `docs/`.

## 1. Что показал замер
- 32 приложения, 881 файл кода, 258 тыс. строк. Между приложениями 310 связей, 98 пар взаимных; ядро
  импортирует 26 приложений из 32. Граф «всего проекта» — клубок, одной картинкой не читается.
- В `apps/core` 221 модуль, у 219 есть описание первой строкой. Структура проекта — внутри ядра.
- Сессия в начале среза собирает связи файла десятком поисков; журнал: `предпосылка-без-grep` и
  `второй-писатель` — 17 находок из 109.

## 2. Срезы
| Срез | Что | Файлы |
|---|---|---|
| T-15.1 | Справка по запросу `scripts/codemap.py <файл\|модуль\|файл::имя>`: кто импортирует (по приложениям), что импортирует, тесты и эталоны, скилл, строки памяти («единственный писатель»), находки журнала, последние шаги в git, упоминания в передаче | `scripts/codemap.py`, `apps/core/tests/test_codemap.py` |
| T-15.2 | `--plan <план>`: по таблице срезов — приложения-импортёры, число тестов и наборов эталонов на срез | те же |
| T-15.3 | Оглавление ядра `docs/codemap-core.md` (модуль — назначение — сколько приложений зовёт), строит `--core-index`; замок: каждый модуль ядра есть в оглавлении | + `docs/codemap-core.md` |
| T-15.4 | Замок на новые взаимные зависимости приложений: нынешние пары — базовая линия `docs/codemap-mutual-baseline.txt`, новая пара — находка | + базовая линия |

## 3. Решения
- Связи считаются из кода в момент запроса (AST импортов), ничего не хранится — справка не устаревает.
- Оглавление ядра хранит только имя и назначение модуля; числа обновляются при пересборке и замком не сверяются
  (иначе каждая правка ядра роняла бы CI у параллельных стопок).
- «Кто пишет ключ настроек сайта» берётся из строк памяти со словами «единственный писатель», а не из кода:
  вывести это из кода без ручного реестра нельзя (писатели — обычные функции). Справка так и подписывает источник.
- Существующие 98 взаимных пар не чиним.
