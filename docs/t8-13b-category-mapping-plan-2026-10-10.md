# T-8.13b «Свои категории → категории города» (2026-10-10)

Пункт 7 общего плана `t8-roadmap-2026-10-10.md` (вторая половина, закрывает этап 2). Справочник
и выбор у акции — T-8.13a (`t8-13a-city-categories-plan-2026-10-10.md`). ТЗ «Siteadaptor 2.0» §5:
своя навигация сайта остаётся, сопоставление — связь, а не копия; клиент управляет своими
категориями и их сопоставлением, справочник ведёт платформа.

## 0. Факты

- `catalog.Category` — своё дерево бизнеса (parent, name i18n), его видят только витрина и
  кабинет; до города не доходит ничего.
- Акция на товар (PL) сегодня получает категорию города из своего поля или по типу бизнеса —
  у магазина одежды и куртка, и сумка уходят «Damenmode».
- Товаров в каталоге города пока нет (T-8.11) — сопоставление готовит и их.

## 1. Решение

- **Поле** `Category.city_category` (⚠️ `catalog/0035`, аддитивная; слаг справочника, пусто =
  «как у родителя», у корня — подсказка по названию).
- **Подсказка по названию** `city_categories.suggest_for_name(text)`: ключевые слова справочника
  (Damen → Damenmode, Schuh → Schuhe, Brot/Brötchen → Brot & Backwaren…), только для
  предвыбора — владелец подтверждает. Не угадали — пусто.
- **Резолвер** `catalog/city.py::resolve(category)`: своё поле → вверх по родителям → подсказка
  по названию → "". Один на синк акций сейчас и на товары T-8.11.
- **Синк акции:** своё поле акции → категория её товара-цели (резолвер) → подсказка по типу
  бизнеса.
- **Кабинет:** селект «Kategorie im Stadtkatalog» в форме категории (подпись «Automatisch: …»
  показывает, что выйдет) + блок «Zuordnung zum Stadtkatalog» на странице «Kategorien» — все
  свои категории строками с селектом, одна кнопка «Speichern» (presence по скрытым id строк;
  чужой id и неизвестный слаг игнорируются).

## 2. Замки (до правок)

- подсказка по названию: «Damenjacken» → damenmode, «Brötchen & Brot» → brot-backwaren,
  «Sonstiges» → "";
- резолвер: своё поле сильнее; ребёнок без поля наследует родителя; мусор в поле → дальше;
- синк: акция на товар без своей категории получает категорию категории товара; своя категория
  акции сильнее;
- форма категории сохраняет и сбрасывает выбор; массовое сопоставление пишет только переданные
  строки.

## 3. Вне объёма

Товары в каталоге города и их выдача — T-8.11. Управление справочником из админки (ТЗ 2.0 §5) —
предмет обсуждения ТЗ 2.0 (справочник сейчас — код, как районы).
