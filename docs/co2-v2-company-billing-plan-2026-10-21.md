# CO-2 v2 «Счёт фирме из брони» — план (2026-10-21)

Порядок владельца «2, 3, 1» — пункт 1 (корпоративный контур отеля). Разведка — агент planner.

## Что уже есть
CO-1 v1 и CO-2 v1 сделаны 2026-07-28 (build-log): справочник `crm.Company`, привязка
`Customer.company`, экраны `/crm/firmen/`, подстановка реквизитов в РУЧНОЙ счёт, фильтр
`?firma=`. SH-23 (2026-09-03) добавил способ оплаты `invoice`, тип покупателя Privat/Firma и
снимки `customer_type`/`billing_company`/`billing_vat_id` на всех видах сделок.

## Найденные дыры
- **D1** ни один построитель счёта (`invoice_from_stay|booking|order`, старый
  `stays.stay_to_invoice`) не читает реквизиты фирмы → счёт фирме уходит на имя гостя без
  USt-IdNr (§ 14 UStG).
- **D2** тип покупателя и реквизиты не видны и не правятся на карточке сделки.
- **D3** автосчёт при «Kauf auf Rechnung» подключён только к заказу; бронь номера держит номер
  14 дней без счёта; переход на Stripe при предоплате не смотрит на выбранный способ.
- **D4** фирма с витрины не сопоставляется со справочником.
- **D5** второй (старый) построитель счёта брони `stays.stay_to_invoice`.

## Инкременты (миграций нет в a–d)
- **CO-2a** `finance/recipient.py::recipient_for(deal)` — один выбор получателя (плательщик
  заказа → фирма со сделки + адрес справочника + USt-IdNr → `company.invoice_recipient` →
  клиент) во всех построителях; `action=invoice` брони → `invoice_from_stay`, старый удалить.
- **CO-2b** блок «Rechnungsempfänger» на карточке сделки + правка (`deal-billing-edit`),
  «Aus dem Firmenverzeichnis» / «Ins Firmenverzeichnis übernehmen».
- **CO-2c** `crm/companies.py::link_by_vat` — привязка к справочнику по точному USt-IdNr при
  бронировании (без автосоздания).
- **CO-2d** автосчёт для брони номера и записи при «Kauf auf Rechnung»; без Stripe при
  `invoice`/`vorkasse`.
- **CO-2e** (по решению В-2) адрес для счёта на витрине + `billing_address` у брони/записи
  (аддитивные миграции).

## Вопросы владельцу (рекомендации)
- **В-1** когда выставлять автосчёт за номер: сразу при автоподтверждении, иначе при
  подтверждении отелем (иначе отклонённый запрос оставит выставленный счёт → сторно по GoBD).
- **В-2** адрес для счёта на витрине — да, шагом CO-2e (§ 14 UStG при сумме > 250 €).
- **В-3** автосоздание компании при бронировании — нет; только привязка по USt-IdNr и кнопка.

## Решения владельца (2026-10-21)
В-1 — при подтверждении (сразу при автоподтверждении) · В-2 — да, шагом CO-2e ·
В-3 — нет, только привязка по USt-IdNr + кнопка на карточке.
