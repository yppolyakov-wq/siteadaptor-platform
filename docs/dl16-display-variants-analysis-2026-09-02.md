# DL-16 — Формы вывода информации: категория · акции · карточка/деталь товара и акции · слайдеры (анализ на согласование, 2026-09-02)

**Запрос владельца:** «давай поработаем над дизайном вывода информации в категории, акциях и карточке
товара/акции. Слайды и другие виды — проанализируй и дай на согласование».
**Метод:** 4 разведки по коду и докам (все факты — с file:line в отчётах; здесь — выжимка), сверка с
уже принятыми решениями (чтобы не переоткрывать закрытое: DL-12 §1 R1–R13, SF-волна, KAT, MEN, DL-11…15),
затем предложения по кодам **K** (категория) · **A** (акции) · **P** (карточка товара) · **D** (деталь
товара) · **AK** (карточка акции) · **AD** (деталь акции) · **S** (слайдер и другие виды вывода).
Макеты — канвас «Anzeigeformen» (артборды по кодам). Код — ТОЛЬКО после отмашки по §5.

## 1. Пробелы и дефекты, найденные разведкой (факты)

**Данные, которые есть в модели, но нигде не показаны (акции):** `starts_at` («gültig ab»), `target_rules`
(окно happy-hour: дни/часы — деталь пишет лишь «wird automatisch angewendet»), `max_per_customer`,
`reservation_ttl_hours`, **сама цель акции** (товар/услуга/номер/комбо — ни имени, ни фото, ни ссылки на
детали акции), `promo_type=discount` (без визуального маркера), `views`. На карточке акции нет группы и
«Sie sparen» (только на детали); у `sm`-countdown нет фолбэка «gültig bis».

**Навигация/структура:** на категории нет хлебных крошек (только «← Alle»; BreadcrumbList есть лишь в
JSON-LD деталей); фото Kopfbild без лайтбокса; поиск `?q=` на `/aktionen/` работает, но **входа в UI нет**
(шапка ищет по primary-листингу); на живой детали акции нет «других акций» (есть только на 410-странице);
секции детали товара только скрываются (у событий — переставляются).

**Дефекты (кандидаты на быстрый фикс):** (1) на `/sortiment/` в контексте нет `site` → гейт
`menu_show_prices=False` не прячет цены на каталоге/категории; (2) archetype-cover крутится каждые 6 с и
на телефоне (у hero — гейт есть); (3) стиль категорий `compact` на странице каталога падает в 4:3 (нет
записи в `CATEGORY_TILE_ASPECTS`); (4) промо-`sm` countdown без фолбэка даты; (5) Studio-чекбокс `scroll`
есть только у секций главной — лента недоступна каталогу/категориям из UI.

## 3. Рекомендуемый пакет v1 (что просить утвердить)

1. **S1 слайдер-примитив** (фундамент; без него K2/A3/D1/D4/AD3 — «полосы без управления») + S4-фиксы.
2. **Акции:** A3 Gruppen-Slider как новый режим страницы (рядом с «по темам/по времени»), A4 таблица
   посетителю, A5 дозаполнение карточки (группа, Sie sparen, gültig ab), поиск на `/aktionen/`.
3. **Деталь акции:** AD1 + AD2 + AD3 — все XS, закрывают «данные есть, показа нет».
4. **Карточки:** AK1 Preis-zuerst + P1 Etikett как значения `card_style` (Look-aware), P2 Hover-Slider.
5. **Категория:** K1 Kopfbild-Slider + крошки, K2 Regale для типов с подкатегориями, K3 Tabs.
6. **Деталь товара:** D1 галерея-слайдер (мобайл свайп), D3 Vertrauensleiste, D4 ленты, D2 табы.
Отложить: A1 (зависит от «scheduled-Vorschau» — отдельное решение), A2 Prospekt-Seite и AD4 (эффектно,
но дорого и Look-специфично — после v1), K4 L3, D5, D6.

## 4. Границы
Без миграций (все формы — ключи `site_config`/Studio + CSS/шаблоны; A1 может потребовать флаг на
акции — уточнится план-доком). `_discount_display`/`_promo_card` не переписываем (C1) — новые формы
как ветки `card_style` с паритет-замками «"" байт-в-байт». Каждая форма — только при потребителе в демо.
