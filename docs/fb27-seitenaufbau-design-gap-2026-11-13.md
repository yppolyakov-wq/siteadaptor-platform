# FB-27 «Seitenaufbau» — расхождения экрана с согласованным макетом

Дата: 2026-11-13. Замечание владельца: «Структура страницы совсем не такая, как в
согласованном дизайне». Сверка экрана (`templates/tenant/site_schema.html`) с макетами
`docs/design/website-seiten-2026-11-11/Main.dc.html` (1440) и `L3_Mobil.dc.html` (390).

Вывод: **замечание верное.** В R1–R9 сделана функция (черновик, ширины, блок «Liste», ручной
состав, настройки типа, новые блоки, схема категории, граница со Студией), но вид экрана
собран «формами», а не по макету. Ниже — что именно расходится и в каком порядке доводим.

## 1. Расхождения

| № | Место | В макете | Сейчас |
|---|---|---|---|
| G1 | Шапка | Одна полоса: «Seitenaufbau» · выбор страницы · переключатель «Computer / Telefon» · «Entwurf · 3 Änderungen» · «Auf der Seite bearbeiten» · «Vorschau» · «Verwerfen» · «Speichern» | Выбор страницы с кнопкой «Öffnen»; пояснительный абзац; черновик — отдельной полосой ниже; переключателя «Computer / Telefon» нет |
| G2 | Выбор страницы | Название страницы | «Главная · 4» (со счётчиком блоков) |
| G3 | Строка схемы | Карточка: название, строка-сводка («3 Folien · Slider», «Neuheiten · 8 Stück · Raster 4 Spalten», «handverlesen · 4 · Kacheln»), значок ширины (½, ⅓, ⅔), схематичная миниатюра содержимого | Название; сводка только у своих блоков (их заголовок); у встроенных секций главной — пусто; миниатюр нет |
| G4 | «Einstellungen der Seite» | Такой строки нет: вид баннера — в строке «Banner», вид списка — в строке списка | Отдельная первая строка со своей панелью (решение R4-D1, принятое без макета) |
| G5 | «+ Block» | Одна пунктирная кнопка «+ Block hinzufügen», по нажатию — выбор | Две формы подряд: список типов + кнопка и «готовая строка» + кнопка |
| G6 | Панель блока — «Welche» | Переключатель из трёх кнопок «Regel · Kategorie · Einzeln», под ним поля выбранного способа | Все поля правила подряд селектами; «Einzeln» — отдельным списком ниже |
| G7 | Панель — «Wie» | Кнопки «Raster · Slider · Liste» + выбор числа колонок | Селекты «Ausgabe», «Spalten», «Reihen», «Kartenform» |
| G8 | Панель — «Breite» | Ряд кнопок Ganz · ⅔ · ½ · ⅓ · ¼ · ⅕ · ⅙ с пояснением | Отдельная форма ширины |
| G9 | Панель — низ и меню | Ссылка «Produkte bearbeiten → Sortiment», кнопки «Nach oben / Nach unten»; «Ausblenden / Entfernen» — в меню «⋯» у заголовка | Кнопки порядка и «Ausblenden / Entfernen» вверху панели; ссылки на источник у списков нет |
| G10 | Применение правок | Правка в панели сразу видна в схеме (черновик), отдельной кнопки нет | Кнопка «Übernehmen» у каждой формы |
| G11 | Встроенные секции главной | Строка «Produkte» открывает ту же панель «Was · Welche · Wie» | Панель встроенной секции — только порядок и видимость (решение владельца: источник только для чтения + «Als eigenen Block kopieren») |
| G12 | Телефон | Список блоков; блок открывается листом снизу с «Fertig» | Панель под схемой, без листа |

G11 — не ошибка, а следствие более позднего решения владельца; в макете показан свой блок
«Liste». Строку «Produkte» главной приводим к виду макета (сводка, миниатюра), а панель
оставляем по решению: что показывает секция + «Als eigenen Block kopieren».

## 2. Порядок доводки (только рендер и разбор формы; операции черновика не меняются)

- **V1 — шапка и строки (G1, G2, G3).** Полоса шапки с черновиком и кнопками; выбор страницы
  без счётчика, без скриптов остаётся кнопка «Öffnen»; сводка и значок ширины у каждой
  строки, включая встроенные секции (`list_blocks.view_hint`/настройки секции), миниатюры.
- **V2 — панель блока (G6–G9).** Переключатели «Welche» и «Wie» кнопками, ряд кнопок
  «Breite», меню «⋯», низ панели со ссылкой на источник и порядком.
- **V3 — «+ Block» и настройки страницы (G4, G5).** Одна кнопка с выбором (группы и готовые
  строки — внутри); настройки типа страницы — в строке своего блока (баннер, основной
  список), строка «Einstellungen der Seite» остаётся только там, где блока-носителя нет.
- **V4 — телефон и «Computer / Telefon» (G1, G12).** Переключатель вида схемы; лист снизу.
- **G10** (без «Übernehmen») требует скрипта; без скриптов кнопка остаётся — делаем в V2 как
  улучшение поверх работающей формы.

## 3. Замки (до кода, по срезам)

- V1: у каждой строки схемы есть сводка или она осознанно пуста (реестр); счётчика в выборе
  страницы нет; кнопки черновика — в шапке, одна форма; без скриптов выбор страницы работает.
- V2: способ «Welche» переключается без потери полей другого способа (W0); ширина — кнопки с
  `aria-pressed`; «Ausblenden/Entfernen» достижимы с клавиатуры из меню «⋯».
- V3: каждая настройка типа страницы по-прежнему достижима (замок R4 остаётся зелёным).
- V4: на 390 px нет горизонтальной прокрутки; лист закрывается «Fertig» и Esc.

## 4. ECC-прогоны

- До кода: `accessibility`, `e2e-testing`, `django-tdd`.
- Каждый срез: `a11y-architect`, `django-reviewer`, стенды `scripts/aufbau_stand.py` и
  `scripts/aufbau_owner_stand.py` (1440/390, без JS), снимки рядом с макетом.

## 5. Итог (2026-11-13)

V1–V4 и G10 сделаны (build-log). Осталось одно расхождение: в макете у «Wie» три кнопки
«Raster · Slider · Liste»; вывода «Liste» (строками) у витрины нет — это новая функция, а
не вид экрана, записана в `roadmap-next-sprints.md`. Сейчас третья кнопка — «как у страницы».
G11 — по решению владельца (встроенные секции главной только для чтения).
