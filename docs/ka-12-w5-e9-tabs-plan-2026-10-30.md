# KA-12 W5 · E9 — единый стиль вкладок кабинета (2026-10-30)

Часть «перевод экранов на детали ui-*» (E9, task-catalog). Библиотека E9.1 уже содержит
`.ui-tabs` / `.ui-tab` / `.ui-tab-count` / `.ui-seg`, но ни один экран ими не пользуется:
вкладки нарисованы пятью разными способами (заливка индиго с рамкой, белые карточки с тенью,
подчёркивание, `rounded-lg` с рамкой, серые пилюли).

## Что делаем (батч 1 — серверные ссылки)

Вкладки-ссылки (каждая — отдельный URL/фильтр) переводим на `ui-tabs` + `ui-tab`,
активная — `aria-current="page"` (стиль `.ui-tab[aria-current]`), контейнер — `<nav aria-label>`:

| Экран | Файл |
|---|---|
| Finanzen (6 вкладок) | `finance/_finance_tabs.html` |
| Bewertungen (виды/скрытые/«Über den Betrieb») | `reviews/review_list.html` |
| Nachrichten (статусы) | `inbox/list.html` |
| Reservierungen (касса Mini App) | `promotions/reservation_list.html` |
| Medien (папки) | `tenant/media_library.html` |
| Abläufe (направления) | `tenant/ablaeufe.html` |
| Verkäufe (направления + «Kunden») | `core/verkaeufe.html` — было `role="tablist"` у ссылок (неверная ARIA: tablist требует `role="tab"`-детей и управляемых панелей) → `<nav>` + `aria-current` |
| Доска (переключение секций JS) | `core/_board_body.html` — настоящие вкладки: `role="tab"` + `aria-selected` + стрелки ←/→; JS переключает `aria-selected`, а не классы |

Не трогаем в батче 1: вкладки, которые JS переключает классами (`stays/units.html`
pt/ut/st-пилюли), `pf-tab` формы товара (свой механизм invalid-раскрытия), сегмент
превью акции. Это батч 2 вместе с переводом на `ui-seg`.

## Инварианты
- Только рендер: URL, параметры, `data-*`-хуки, порядок вкладок — прежние.
- Счётчики — `ui-tab-count`.
- Мобильный горизонтальный скролл Verkäufe сохраняется утилитами поверх `.ui-tabs`.
- Цель касания ≥ 24px (WCAG 2.5.8): `.ui-tab` ≈ 34px.

## Замки (до кода)
`apps/core/tests/test_ui_tabs.py`: каждый из перечисленных шаблонов рендерит `ui-tab` и
ровно одну активную (`aria-current="page"` / `aria-selected="true"`); в шаблонах больше нет
`role="tablist"` у контейнера ссылок; доска — `role="tab"` + `aria-selected`.

## ECC-прогоны
- До кода: скилл `accessibility` (роли вкладок vs навигации, видимый фокус, размер цели).
- После кода: `a11y-architect` — ARIA вкладок/навигации на диффе; `code-reviewer` — дифф
  шаблонов и замков (регрессия хуков `data-*`, сломанные тестовые сплиты).
- Стенд: Playwright (кабинет демо) — Verkäufe/Finanzen/доска, клик и стрелки на доске.
- Гейт: `ruff`, `template_comments`, `i18n_quickcheck`, `npm run build:css`.

## Батч 3 — вкладки форм товара и акции (2026-10-30)

`pf-tab` (свой CSS в `tenant/_i18n_switch.html`) → `ui-tab` с настоящей семантикой вкладок:
`role="tab"` + `aria-selected` + roving `tabindex`; `setTab()` переключает атрибуты, а не
класс `pf-tab-on`; стрелки ←/→ и Home/End по ВИДИМЫМ вкладкам (у не-гастро «Kennzeichnung»
скрыта). Переключатель языка 🌐 сейчас лежит ВНУТРИ `role="tablist"` (tablist обязан владеть
только вкладками) → выносится соседом. Языковые пилюли получают `aria-pressed`.
Механика панелей (`data-pf-panel`, рейл SR-2d, раскрытие при invalid) не трогается.
Превью акции «Meine Website / Stadtportal» уже доступно (`role=tab` + `aria-selected`) — остаётся.

Замки: в обеих формах `role="tab"` + `aria-selected` у `data-pf-tab`, нет `pf-tab-on`,
tablist не содержит переключатель языка; стенд Playwright — клик и стрелки на форме товара,
поле в скрытой вкладке по-прежнему раскрывает её при Save.
ECC: скилл `accessibility`; `a11y-architect` на дифф; Playwright-стенд.
