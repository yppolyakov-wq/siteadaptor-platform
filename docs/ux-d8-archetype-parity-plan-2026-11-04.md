# UX-D D8 — оптимизированный вид у ВСЕХ архетипов (2026-11-04)

Повод — вопрос владельца «по всем архетипам изменения? все приведены к оптимизационному
дизайну?». Сверка на стенде: 20 демо (все 16 типов бизнеса) × все пункты меню = 885 экранов,
0 ошибок. Общие экраны UX-D действуют у всех, но четыре места остались в старом виде
(замер — `scratchpad/stand/uxd_audit.js`: пустота справа + видимые поля POST-форм вне шторок).
Решение владельца: «Делай» (все четыре пункта, порядок как ниже). Без миграций.

## D8.1 Главная = сводка дня у всех архетипов
Было: сводку дня (D1.4) получил только отель; у остальных 19 демо главная — полоса виджетов +
петля продаж (список/доска) на ~70 % ширины (у кейтеринга — узкий канбан).
Станет (по образцу отеля, Р-1 D1): цифры дня · «Heute / diese Woche» · «Braucht Aufmerksamkeit»
· загрузка на 7 дней · кнопки «Verkäufe →» и «＋». Один модуль `apps/core/day_home.py` на четыре
вида продаж (order · booking · job · ticket); у отеля остаётся `stays/home_summary.py`.
Источники — те же, что у экранов, куда ведут ссылки: «Nicht bezahlt» = `finance.bank.deal_open_items`
(как Offene Posten), «Heute» = `sales_page.heute_columns` (как `?view=heute`), счётчики по стадиям —
`pipeline`/реестр статусов (свои статусы владельца учитываются), даты — поле события вида
(`pickup_slot` / `start` / `event_date` / `event__starts_at`). Каждый блок fail-safe; число запросов
не зависит от числа сделок.

## D8.2 Kampagnen: создание шторкой, авто-рассылки — в «Настройки»
Форма «Neue Kampagne» раскрыта над списком (П2) + настройки Win-back и поздравления с днём
рождения на рабочем экране (П4).

## D8.3 Kategorien: «Zuordnung zum Stadtkatalog» — с экрана списка
Блок выпадающих списков у каждой категории (до 50 полей) под плитками (П1). Сопоставление
уже есть в форме категории; со списка — ссылка на отдельный экран сопоставления.

## D8.4 Bewertungen: ответ по кнопке
Поле ответа раскрыто под каждым отзывом → кнопка «Antworten», форма раскрывается на месте
(`<details>`, без JS-зависимости; W0 — поле в DOM).

## Замки
- D8.1: главная каждого вида продаж содержит сводку (`data-day-home`), числа «Nicht bezahlt»
  равны строкам Offene Posten; сломанный источник не роняет главную; число запросов не растёт
  с числом сделок; без права `verkaeufe.view` — без сводки продаж.
- D8.2–D8.4: на экранах нет видимых полей POST-форм вне шторки/`<details>`; формы прежние (W0).
- Повторный обход всех 20 демо тем же скриптом.

## ECC-прогоны
До кода: скиллы `django-patterns`, `accessibility`. После D8.1: `django-reviewer` (запросы,
права), `a11y-architect` (новая главная). После всего: стенд Playwright 1600/390 по всем 20 демо.
