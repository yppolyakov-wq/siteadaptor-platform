# AIS A-2 — ИИ-ответ на свободный вопрос в шторке «✨ Assistent» (план, 2026-11-06)

План — агент ECC `planner` (сверен с кодом A-0/A-1, `apps/ai`, `inbox/ai_reply`), доработан
ведущим. Источник — `ais-modules-directions-assistant-plan-2026-11-05.md` §2.2–2.5, §5.2. Миграций
нет. Вопросы §12 планировщика — по его рекомендации (tier `fast` со сменой по замеру, квоты ниже,
кнопка «KI fragen» с JS + запасной путь без JS, эскалация «An den Support» — в A-3).

## 0. Суть

Кнопка «✨ KI fragen» под полем шторки. В модель уходят: вопрос в рамке недоверенных данных, 3–5
статей A-1, видимых пользователю (`for_prompt`: текст и КЛЮЧИ ссылок, без URL), снимок состояния
из белого списка кодов. Модель отвечает по закрытой схеме: короткий текст, до 3 ссылок как
идентификаторы из enum того, что ушло в промпт, ссылки на состояние (`state_refs`), флаги
`out_of_scope`/`unknown`. URL строит только сервер (`assistant.link`/`help_articles.opened`) —
при показе ответа ещё раз (права могли смениться). Пост-проверка не прошла → статьи A-1 без
ИИ-текста. Помощник ничего не меняет.

Что выяснено по коду: `api.generate` рамку не ставит — её ставит потребитель (замок на промпт);
права зависят от `request`, поэтому контекст (статьи, снимок, enum) собирает веб-запрос, воркер
только вызывает модель; фрагмент шторки без `<script>` — опрос в `cabinet.js` делегированием.

## 1. Решения

| # | Требование | Решение |
|---|---|---|
| R1 | вопрос ≤ 500, рамка, scrub, отсечка налогов/права/болтовни | `prepare_question` (длиннее — отказ, не обрезка); `out_of_scope()` правилами на 5 языках ДО модели: «термин И намерение совета» (вопрос «wo trage ich … ein» пропускается) |
| R2 | 3–5 статей + снимок без ПД | `select_articles` (ranked по вопросу + статьи экрана + статья к проблемному диагнозу, кап 5); `snapshot`: business_type, package, directions, role, surface, screen, readiness `{key: done/missing/unknown}` (только пункты с доступной ссылкой), checks `{diag: ok/problem/unknown/not_checked}` — без текста находок, имён, реквизитов, клиентов |
| R3 | ответ по схеме | динамическая схема: `text` ≤ 600, `links[{ref}]` ≤ 3 с enum `a:<article>:<link>` / `s:<url_name>`, `state_refs` ≤ 3 с enum `r:<item>` / `d:<diag>`, `out_of_scope`, `unknown` |
| R4 | пост-проверка | `check_answer`: отказ целиком при ПД-маркере, ссылке/домене/обфускации/IP/@handle/e-mail/телефоне, деньгах/процентах/сумме прописью, числе не из статей, словах цены/тарифа/обещаний не из статей, утверждениях о состоянии («ist bereits …», «уже …»), чужом языке; неизвестные ref — выброшены. Состояние — только через `state_refs` (рендерит сервер из снимка — верно по построению) |
| R5 | AI Act / DSGVO | заголовок «KI-Assistent» + `AI_LABEL`, «Sie chatten mit einer KI» + `{% ai_notice %}` у поля, `TASK_DATA` |
| R6 | стоимость | `assistant_answer` tier `fast` (выбор из ≤ 5 статей, задержка шторки); Celery + опрос (generate держит до 45 с); кэш по digest (схема + язык + промпт без маркера + enum + версия проверки, 1 ч, только прошедший проверку, без URL); замок «один вопрос одновременно»; лимиты 10/10 мин и 40/день на пользователя, 30/10 мин на бизнес, refund при сбое очереди |
| R7 | права | `login_required` + `view_perms` OPEN (режет `link()`), `TG_LITE_VIEWS`, пакет «Aktionen»; снимок и enum только по доступным пользователю ссылкам; сотруднику владельческое — пометка без href |
| R8 | ИИ выключен | кнопки нет, POST → `disabled`, поле — поиск A-1 |
| R9 | журнал A-3 | шов `on_outcome(code)` (no-op), текста не пишем |

## 2. Файлы

- `apps/ai/guard.py` — общие проверки текста ИИ, вынесенные из `inbox/ai_reply.py` байт-в-байт
  (`normalize`, ссылки/контакты/деньги/проценты/числа/язык); `ai_reply` импортирует оттуда. Замок —
  существующие тесты inbox без правок.
- `apps/core/assistant_ai.py` — ядро (вопрос, scope, статьи, снимок, промпт, схема, проверка, job,
  кэш, рендер ответа); регистрация задачи в `CoreConfig.ready()`; Celery `apps/core/tasks.py`.
- Вьюхи `assistant-ask` (POST, CSRF; JSON для шторки, без JS — 302 на страницу помощника с
  `?antwort=<job>`) и `assistant-answer` (GET, опрос: фрагмент; чужой/мусорный job → 404).
- `templates/core/_assistant_answer.html`, правка `_assistant_body.html`, опрос в `cabinet.js`.
- `view_perms`, `packages._AKTIONEN_VIEWS`, `tg_login.TG_LITE_VIEWS`, X7 `EXPECTED_UNLISTED`,
  `TASK_DATA`, 5 `.po`.

Отличие от планировщика: без режима `json:` у фейк-провайдера — тесты и стенд подменяют вызов
модели в `assistant_ai` (как в W4-4), меньше правок общего слоя.

## 4. ECC-прогоны

Скиллы: `django-security`, `django-patterns`, `django-tdd`, `django-celery`, `error-handling`,
`redis-patterns`, `accessibility`; pitfalls §3–§6, SEC. `security-reviewer` (обязательно: инъекция,
рамка, снимок, кросс-тенант, кэш-ключи, CSRF, job-ID, отражение) · `django-reviewer` (декораторы,

## 5. Риски

Ложные отказы чёрных списков (замер на стенде, правка с `CHECK_VERSION++`); ложные пропуски
утверждений о состоянии (основной канал — `state_refs`); качество `fast` (смена tier одной строкой);
стоимость (отказы до модели, кэш, лимиты, бюджет AI-0); Celery лежит → refund + статьи A-1;
перенос `guard` (тесты inbox — замок).

маршрут fast = Claude на Bedrock EU, `AI_REQUIRE_EU=True`; пока маршрут прямой, у поля пометка
«USA». Celery-воркер подхватит задачу после рестарта.

## 7. Итоги ревью (security-reviewer + silent-failure-hunter, 2026-11-06)

CRITICAL/HIGH — нет. Проверено и в порядке: рамка и маркер (замена `<<<`/`>>>` после NFKC), снимок
только кодами и платформенными подписями, кэш/job-ключи со схемой и пользователем, CSRF, вопрос не
попадает ни в URL, ни в HTML, autoescape. Исправлено:
- утверждения о состоянии — список по 5 языкам расширен («Sie haben keine …», «ist eingerichtet»,
  «fehlt», «you haven't», «у вас нет», «не настроено» …); слова-обещания («kostenlos», «sofort»,
  «garantiert», тариф…) — отказ ВСЕГДА, а не «если есть в статье»; домен с пробелами — отказ;
- зависший pending: в задаче срок 90 с — опрос после него отдаёт «nicht verfügbar», снимает замок и
  возвращает попытки; замок хранит id задачи (поздний `finally` не снимает чужой);
- сбой между замком и записью задачи, сбой провайдера/очереди — попытки возвращаются, замок снят;
- «сервис не ответил» показывается как «Der KI-Assistent ist gerade nicht verfügbar», а не как
  «Ich bin nicht sicher»; модель сказала «вне рамок» — тот же серверный отказ, что у правил;
- сбой показа ответа — спокойный текст, не 500; запись старой версии — 404, не `KeyError`;
- JS-опрос: два сбоя сети подряд терпит, 404 и таймаут — сообщение, текст ошибки из своей формы.

Закрыто настройкой (не код): вопрос в локальных переменных при `logger.exception` — Sentry
собирает события с `include_local_variables=False` (`config/settings/production.py`).
Осознанно не делаем в v1: язык ответа проверяется только по доле кириллицы (турецкий/английский
на немецкий вопрос пройдёт — качество, не безопасность); тенантный лимит 30/10 мин может выбрать
сотрудник (поверх — дневной бюджет AI-0).
