# Фидбэк 2026-07-28: форма номера табами + сворачиваемый сайдбар — план

**Источник:** владелец: «в настройках номера сильно длинная портянка — разберём,
сгруппируем, сделаем табами. Левое меню админки — сворачиваемым, чтобы
сдвигалось влево». Без миграций.

## 1. Форма номера (units.html, блок редактирования StayUnit) — табы

Прецеденты: W2 (форма товара: секции, «скрытие только CSS, все поля в DOM» —
инвариант W0) и Ф1 (пилюли-табы + `data-pf-goto`, делегирование кликов на
document — грабля Ф1 №1). Группировка полей:

- **Grunddaten**: название, тип, описание, фото (+ переводы `<details>🌐`).
- **Preise**: цена/ночь, Wochenende, сезоны (SeasonRate), депозит/предоплата.
- **Regeln & Kapazität**: quantity (гейт: readonly при комнатах), min_nights,
  max_guests, Zimmer (комнаты R1), удобства (amenities).
- **Sichtbarkeit/Extras**: is_active, iCal-источники/экспорт, агрегатор-★.
  (точный состав — по факту разметки units.html; ничего не терять — W0-замок
  «все поля в DOM, скрытие только CSS», обязательный тест).
- Механика: реюз паттерна `tenant/_i18n_switch.html`/product-form табов
  (кнопки-пилюли + hidden-переключение), submit сохраняет ВСЕ поля формы
  (одна форма, табы — только представление).

## 2. Сворачиваемый сайдбар кабинета

- `templates/tenant/_base_dashboard.html` (или где aside ST-4b): кнопка «⟨»
  в шапке сайдбара → класс `sb-collapsed` на контейнере: ширина ≈ 3.5rem,
  подписи скрыты (иконки остаются — сайдбар ST-4b с SVG-иконками), контент
  сдвигается влево (грид-колонка сужается), состояние в localStorage
  (`sb_collapsed`), без прыжка при загрузке (инлайн-скрипт до рендера).
- Мобайл не трогаем (там таб-бар). classic_ui — тоже дать (общий aside)?
  Если легаси-разметка отдельная — v1 только новый сайдбар.
- Замок: тумблер есть в DOM; collapsed-класс переключается (JS-тест не
  обязателен — характеризационный ассерт разметки).

Порядок: сайдбар (быстрый) → форма номера (аккуратно, W0-инвариант).
Оба — один батч, гейты обычные, push → CI → merge.
