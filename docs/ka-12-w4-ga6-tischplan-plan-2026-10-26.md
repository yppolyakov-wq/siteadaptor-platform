# KA-12 GA-6 · Экран «Tischplan» (2026-10-26, без миграций)

Продолжение `ka-12-w4-gastro-plan-2026-10-26.md` (решение D6: план зала v1 — плитки по зонам,
без координат и редактора).

## 1. Сегодня
Стойка ресторана видит брони только сеткой Tagesplan «ресурс × время» — ответа на вопрос
«какой стол свободен СЕЙЧАС и до скольки» нет; walk-in заводится через общую форму «Add booking»
с выбором стола и времени руками; комбинация «Tisch 3+4» (GA-5) держит столы 3 и 4, но в сетке
это не видно.

## 2. Решение
- **Слой чтения `apps/booking/tischplan.py`** (чистая функция, без записи):
  `build(tables, bookings, at)` → зоны с плитками. Состояние плитки на момент `at`:
  `busy` (действующая бронь области занимает стол: своя, комбинации с этим столом, частей
  комбинации; `start ≤ at < occupied_until|end`), `soon` (бронь области начнётся в ближайшие
  30 мин), `free` (+ «frei bis HH:MM» до следующей брони области). «Через» — подпись
  «belegt über Tisch 3+4». Пул (кафе, `counts_party_size`) — занято N из M мест.
  Область считается В ПАМЯТИ по предзагруженным `parts` (одна выборка столов + одна броней дня),
  без N запросов `scope_ids` — семантика та же (части ∪ комбинации с частью).
- **Вьюха `booking:tischplan`** (`/dashboard/booking/tische/plan/`, GET `?tag=&zeit=HH:MM`):
  дефолт — сегодня и «сейчас» с округлением вниз до 15 мин; стрелки ±30 мин и «Jetzt».
  Пусто (нет столов) — честная подсказка со ссылкой на «Öffnungszeiten & Ressourcen».
- **Действия — существующими путями (никакой второй логики занятости):**
  walk-in = POST `booking:booking-create` (ядро `create_manual`: часы, места, область GA-5) с
  `start=at`, `party_size`, «Trotzdem eintragen»; «Tisch zuweisen» = POST `booking:booking-action`
  `action=move` с `resource` (ядро `services.move`). Оба возвращают на Tischplan через `next`
  (общий хелпер `_safe_next`: только внутренний путь — как у карточки брони).
- **Навигация:** запись `board` → `booking:tischplan` «Tischplan» (подпункт Verkäufe,
  `module_key="booking"`, `business_types=TABLE_TYPES`), `view_perms` `_r(V, E)`, вход из
  тулбара Tagesplan при наличии столов. Якоря не трогаем (мораторий X7).
- **A11y:** состояние словами (не только цветом), `aria-label` плитки, формы — `<details>`
  с подписанными полями, кнопки ≥44 px.

## 3. Замки (до кода)
build: занято/свободно/скоро; комбинация держит части и наоборот (с подписью «über»); пул N/M;
«frei bis»; отменённая бронь не занимает. Вьюха: 200, мусорные `tag/zeit` → дефолт, анонима не
пускает (middleware), запросов не больше константы (нет N+1). Walk-in с `next` создаёт бронь и
возвращает на Tischplan; чужой `next` (`//evil`) игнорируется; «zuweisen» переносит на свободный
стол и отказывает на занятой комбинации. Реестр: запись видна restaurant и не видна friseur.

## 4. Не в этом инкременте
Координаты/редактор зала, перетаскивание плиток, статусы «gesetzt/bezahlt» (v2); демо — GA-7.
