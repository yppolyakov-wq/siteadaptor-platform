# T-8.10h H-7: бот владельца — фото, кабинет, данные, свой бот, «где моя акция», права DSGVO

План 2026-10-20 (агент planner) по фидбэку владельца: «непонятно, как и на каком этапе
добавить фотографии; как из бота работать с данными кабинета; как создать свой бот или
изменить информацию; где публикуется; что ещё релевантно» + права субъекта данных
Art. 15–21 DSGVO (Auskunft, Berichtigung, Löschung, Einschränkung, Datenübertragbarkeit,
Widerspruch).

## 1. Факты из кода

**Фото** (`apps/promotions/telegram_promo.py`): фото с подписью → черновик сразу (`_new_draft`:
разбор подписи + фото + `ai_fill`, ИИ дописывает только пустые title/description); альбом
склеивается (`_album_photo`/`_album_wait_key`, до `quick.MAX_PHOTOS = 6`). **Нет:** фото, присланное
ПОСЛЕ превью, становится НОВЫМ черновиком (без ИИ — «Wie heißt das Angebot?», фото теряется); в
превью нет «📷 hinzufügen»/«удалить»; подсказки говорят лишь «gern mit Foto»; ✏️ ведёт на веб-форму
под входом.

**Что владелец может сейчас:** привязать бизнес, `/geschaeft`, `/neu`, акции текстом/фото/альбомом,
`/wiederholen`, `/datenschutz`, `/daten_loeschen`, `/abbrechen`, «🔑 Anmeldelink per E-Mail» после
регистрации (без `next`). **Нет:** данных бизнеса, списка своих акций, паузы/завершения, «где
опубликовано», `/hilfe`.

**Свой бот бизнеса:** кабинет `/dashboard/telegram/` — токен из @BotFather → `getMe` → вебхук; из
общего бота туда не ведёт ничего.

**Где появляется акция:** своя страница `/p/<uuid>/`; каталог города (`AggregatorListing`, только
при `visibility.listable`: почта подтверждена, согласие, не приостановлен, не скрыт); каналы
(`publishing.Publication` по каналу со статусом). После ✅ бот пишет только «✅ Live: <url>».

**DSGVO:** есть только удаление (Art. 17). Ловушка: `links.mark_unblocked` срабатывает на каждое
сообщение — `blocked_at` нельзя использовать как флаг ограничения.

## 2. Срезы

- **H-7a «Фото» (без миграций):** «последний черновик» `tgpromo:last:{schema}:{chat}` 30 мин; фото
  без подписи после превью дописывается в черновик (≤6), превью переотправляется; кнопки
  «📷 Foto hinzufügen» и «🗑 Fotos entfernen»; инструкция в приветствии и `/hilfe` (фото с подписью,
  альбом до 6, фото после текста добавляется, первое — главное). Подпись к фото = новый черновик.
- **H-7b «/hilfe и меню»:** `/hilfe` + «☰ Menü» (Aktionen · Profil · Kabinett · Eigener Bot ·
  Datenschutz), команды в `setMyCommands`.
- **H-7c «/kabinett»:** `owner_login.send_login_link(..., next=...)` (проверка `safe_next`), кнопки
  «Login per E-Mail → Aktionen / Einstellungen / Telegram-Bot / Benachrichtigungen» + прямые URL для
  уже вошедших; под ✏️ — «Nicht angemeldet? /kabinett».
- **H-7d «Wo ist meine Aktion?»:** `apps/promotions/where.py::report` — своя страница, флаер, каталог
  города (ссылка или причина: почта, согласие, скрыто, демо), каналы словами; после ✅ и кнопкой
  повтора (каналы идут через Celery).
- **H-7e «/aktionen»:** 10 последних со статусом; ⏸/▶/⏹ только через FSM, 🔁, 📍 статус, ✏️ веб-форма,
  📄 флаер; кнопки через `routing.wrap` + `owner_ok` на каждом нажатии, дедуп.
- **H-7f «/profil»:** показ данных; правка в чате — телефон, WhatsApp (той же формой, что кабинет),
  тумблер «Im Stadtkatalog zeigen» (с подтверждением → `apply_visibility`); название, адрес, часы,
  почта — через веб.
- **H-7g «/eigener_bot»:** инструкция @BotFather → кабинет «Telegram-Bot» (кнопка `/kabinett` с
  `next`); **токен в чате не принимаем** (секрет в облачной истории Telegram).
- **H-7i «Права DSGVO»** (⚠️ миграция `platform_bot/0002` — `OwnerBotPrefs`: locale, restricted_at,
  ai_objected_at, reminders_objected_at; пишет только `platform_bot/rights.py`):
  `/meine_daten` (Art. 15/20: сводка + `meine-daten.json` через `sendDocument`, лимит 3/сутки;
  роли: по данным бота платформа — Verantwortlicher, данные бизнеса — ссылка в кабинет),
  `/berichtigen` (Art. 16: язык, отвязать не тот бизнес; данные бизнеса → `/profil`, почта →
  `/kabinett`), `/einschraenken`/`/freigeben` (Art. 18: сообщения не обрабатываются, доставка
  через общий бот молчит, данные целы; `/freigeben`/`/meine_daten`/`/daten_loeschen` работают),
  `/widerspruch` (Art. 21: «KI-Fotoanalyse aus», «Erinnerungen aus»; полный отказ — удаление).
  **Бот портала** (⚠️ `PortalChat.paused_at`): `/meine_daten`, `/pausieren`/`/fortsetzen`,
  `/widerspruch` (все подписки), `/berichtigen` (язык, частота). Тексты Datenschutzerklärung — с
  командами прав и жалобой в надзорный орган (⚠️ юр. вычитка).

## 3. Тесты до кода, риски, i18n

Замки по срезам — см. разделы выше (фото в тот же черновик и лимит 6; `next` и `//evil`; причины
каталога; чужой pk/ref и FSM-отказы; JSON только своего tg_user_id; ограничение переживает
сообщение; `ai_fill` уважает возражение; пауза глушит сводку портала). Риски: подмена callback
(только `routing.wrap`/`owner_ok`), «последний черновик» — ключ со схемой, `sendDocument` хранит
файл у Telegram (сказать в тексте), отчёт каналов до Celery — «в очереди». i18n: немецкие msgid,
5 `.po`, описания команд на 5 языках.

## 4. Вопросы владельцу (рекомендация)

1. Вход в кабинет из бота — только письмом, но сразу на нужный экран (**да**).
2. Правка в чате — телефон, WhatsApp, согласие на каталог города; остальное — веб (**да**).
3. Цену/текст живой акции в чате — нет в v1, через ✏️ или 🔁 (**да**).
4. Токен своего бота в чате — нет, только инструкция и кабинет (**да**).
5. Две миграции под права DSGVO (`platform_bot/0002`, `PortalChat.paused_at`) (**да**).
6. Порядок: 7a → 7b → 7c → 7d → 7e → 7i (+ портал) → 7f → 7g.
