# AIS — упрощение создания сайта и ИИ: анализ (2026-11-05)

Запрос владельца: «что ещё можно сделать для упрощения создания сайта с учётом нашей структуры;
что есть на рынке; где внедрить ИИ для упрощения настройки и работы». Метод: скиллы ECC
`product-lens` (аудит пути пользователя + ICE) и `market-research`; две разведки — рынок
(21 поиск) и инвентаризация кода (пути входа, мастер, все точки ИИ). Кода в этом инкременте нет.

## 1. Вывод одной фразой

На рынке хорошо работает ИИ, который **превращает то, что у владельца уже есть** (фото меню,
старый сайт, Google-профиль, отзывы, свои продажи), в черновик с проверкой человеком. Плохо
работает ИИ, который **сочиняет контент или действует сам**. У нас уже построено много ИИ
правильного типа, но почти всё выключено, а у мастера нет главного: он спрашивает владельца,
вместо того чтобы показать ему заполненный черновик.

## 2. Что у нас сегодня (факты из кода)

**Пути входа.** `/registrieren/` (7 полей → письмо → ожидание → мастер), `/aktion-starten/`
(одна страница, без пароля), регистрация в Telegram-боте (9 сообщений), Mini App (→ тот же
quick-start).

**Мастер** (`apps/tenants/onboarding.py:121`, `apps/core/setup_steps.py`): до 13 слайдов, все
пропускаемые: старт (демо/пусто) → языки → компания (6 полей, часы СВОБОДНЫМ ТЕКСТОМ) → стиль →
меню → первая позиция (одна!) → карточка → раскладка каталога (категории не создаются) →
главная → о нас → Impressum (пустая textarea) → оплата → готово.

**ИИ уже построен** (`apps/ai`, 8 задач, все с пост-проверкой «новых фактов нет»):

| Задача | Что делает | Включена по умолчанию |
|---|---|---|
| `promo_photo_draft` | фото → заголовок/описание акции | в белом списке, но `AI_ENABLED=False` |
| `promo_text_check` | советы UWG/PAngV поверх правил | то же |
| `site_import_extract` | старый сайт → черновик каталога | то же |
| `setup_plan` | фраза → план «что создать» с префиллом форм | **нет** |
| `inbox_reply_draft` | черновик ответа клиенту из фактов | **нет** (ждёт ЕС-ключ) |
| `catalog_moderation` | пометки в очереди модерации | под вторым гейтом |
| `search_phrase_filters` / `search_query_expand` | поиск портала фразой / на чужом языке | под `AI_SEARCH_ENABLED` |

**Ручной труд без помощи:** описания товаров/услуг/номеров; создание категорий; часы работы в
мастере (структура живёт отдельно в настройках — а от неё зависят «открыто сейчас», слоты
самовывоза, поиск портала); Impressum (генерируемый запасной текст есть, но слайд — пустое поле);
AGB (запасного текста нет); переводы en/ru/uk/tr (только вручную, готовые — только у демо);
меню/прайс/услуги салона — по одной позиции или CSV; SEO-мета — шаблоны без ИИ.

## 3. Рынок (кратко; источники — §7)

| Кто | ИИ-функция | Урок для нас |
|---|---|---|
| Wix Harmony/Aria (янв. 2026) | чат-анкета → сайт → правка фразой | сам Wix: «до 80 %»; на вопросе про УТП люди застревают |
| Squarespace Blueprint | 5 шагов дизайна + ассистент | «годится как старт» |
| Jimdo Dolphin + **Companion** (нояб. 2025, DACH) | приоритетный список «что дальше» + чат по своим данным | вендор: +50 % первых заказов за 30 дней |
| Hostinger, Durable | сайт по промпту | тексты и фото — заглушки «типичного бизнеса» |
| IONOS MyWebsite Now | <20 слов → 8 дизайнов | победитель теста netzwelt «для прагматиков» |
| Shopify Sidekick, Square AI | чат-аналитика, агент в админке | работает, но дорого (маржа Shopify) |
| **Lightspeed** | **меню из фото/PDF/скриншота → позиции с проверкой каждой строки** | самый долгий шаг гастро убран; **у нас этого нет** |
| Fresha AI Concierge | ИИ-ресепшн, запись в календарь | платное дополнение ~$100/мес |
| Uberall, GBP | ответы на отзывы черновиком | самый массовый паттерн; GBP в ЕС не выкатил |

**Контраргументы:** 6 % владельцев сильно доверяют ИИ говорить с клиентами (Bluehost, вендор);
58 % покупателей меньше доверяют контенту, который считают ИИ-шным (Kinsta); сгенерированные
сайты упираются в потолок без логики продаж — у нас она есть, это наше преимущество, а не их.

**Комплаенс:** AI Act ст. 50 действует с 02.08.2026 (чат-ассистент обязан говорить, что он ИИ —
у нас `AI_LABEL` есть). UWG §5: за текст отвечает бизнес → ИИ НЕ сочиняет цены, скидки, аллергены,
обещания (наш инвариант во всех задачах). DSGVO: AVV с провайдером, ЕС-маршруты (`AI_REQUIRE_EU`).

## 4. Диагноз пути пользователя (product-lens, Mode 3)

1. **Мастер спрашивает, а не показывает.** 13 вопросов подряд владельцу, у которого «нет времени
   и нет навыков» (главный барьер по всем опросам). Рынок перешёл к «дай то, что есть → проверь
   черновик».
2. **Первая позиция — одна.** Пекарня с 40 позициями после мастера имеет сайт с одной булкой.
   Массовый ввод (CSV, импорт сайта) спрятан в кабинете.
3. **Часы текстом.** Мастер собирает часы так, что ими не пользуется ни одна функция.
4. **Готовое выключено.** `setup_plan` и черновики ответов не видны ни одному пользователю.
5. **Нет метрики.** Мы не меряем время до первого живого сайта — не узнаем, помогло ли.

## 5. Предложения, ранжированные по ICE (Impact × Confidence ÷ Effort, 1–5)

| ID | Что | ИИ? | I | C | E | ICE |
|---|---|---|---|---|---|---|
| **AIS-0** | Метрика «время до живого сайта»: таймстемпы шагов в `onboarding` state + отчёт (как `pilot_report`) | нет | 3 | 5 | 1 | **15** |
| **AIS-1** | **Часы работы в мастере — структурой** (сетка Mo–So + «как вчера»), разбор старого свободного текста правилами, ИИ — только запасной разбор | правила (+ИИ) | 4 | 5 | 1 | **20** |
| **AIS-2** | **Включить готовое:** `setup_plan` → первым слайдом мастера «Опишите бизнес одной фразой» (есть запасной путь на правилах — работает и без ключа); черновики ответов — после ЕС-ключа | уже есть | 4 | 4 | 1 | **16** |
| **AIS-3** | **Вход «Что у вас уже есть?»**: сайт (импорт Г1) · Google-профиль (адрес, телефон, часы — с подтверждением) · фото меню (AIS-4) · ничего (демо). Дальше мастер открывается заполненным, и владелец только правит | да | 5 | 4 | 3 | **6.7** |
| **AIS-4** | **Меню / прайс / услуги из фото или PDF** (паттерн Lightspeed): позиции, цены, категории → черновик «Prüfen & veröffentlichen» построчно; цена — только прочитанная с фото, аллергены не выводятся; переиспользует черновик Г1 | да | 5 | 4 | 3 | **6.7** |
| **AIS-5** | Кнопка «🌐 Übersetzen» в свитчере языков (Ф1): заполняет пустые en/ru/uk/tr из базы; проверка — числа/цены/ссылки совпадают с оригиналом; DeepL EU или ЕС-LLM | да | 4 | 5 | 2 | **10** |
| **AIS-6** | «Was als Nächstes?» по данным (паттерн Jimdo Companion): 3 конкретных шага («у 12 товаров нет фото», «часы не заданы», «Google не подключён») поверх `setup_checklist` и `today.py` | нет | 3 | 4 | 2 | **6** |
| **AIS-7** | Тексты из фактов: описание позиции, «О нас», hero из заполненных полей + фото; тот же гард «никаких новых фактов», что у `inbox_reply_draft` | да | 3 | 3 | 2 | 4.5 |
| **AIS-8** | Impressum в мастере — показать генерируемый текст для проверки вместо пустого поля; AGB — внешний генератор (решение уже принято) | нет | 3 | 5 | 1 | **15** |
| AIS-9 | Чат-аналитика «что продаётся / что залежалось» по своим данным | да | 3 | 3 | 4 | 2.3 |
| AIS-10 | ИИ-приём записей и вопросов в WhatsApp/Telegram с записью в календарь (паттерн Fresha) | да | 4 | 2 | 5 | 1.6 |

**Осознанно НЕ делаем:** сайт «по промпту» с придуманными текстами и стоковыми фото (главная
жалоба на Durable/Hostinger); агента, который сам меняет сайт или цены без подтверждения;
генерацию картинок товаров (недоверие покупателей + риск §5 UWG «товар не такой»).

## 6. Порядок

1. **Этап 0 (без ИИ, ~1–2 инкремента):** AIS-0 метрика → AIS-1 часы → AIS-8 Impressum →
   AIS-2 `setup_plan` в мастере на правилах. Ощутимое упрощение уже без ключа.
2. **Этап 1 (нужен ЕС-ключ ИИ):** AIS-4 фото меню → AIS-3 вход «что у вас уже есть» (собирает
   AIS-4 + Г1 + Google). Это главный разрыв с рынком.
3. **Этап 2:** AIS-5 перевод → AIS-7 тексты из фактов → AIS-6 «что дальше».
4. **Позже, по данным пилота:** AIS-9, AIS-10 (дорогие по токенам и поддержке).

**Вопросы владельцу:** (1) ЕС-провайдер для этапа 1 — Bedrock EU / Azure EU / Mistral (гайд
`docs/ai-providers-setup-2026-10-16.md`); (2) перевод — DeepL (не LLM, дешевле) или тот же
ЕС-LLM; (3) Google-профиль во входе AIS-3 — через подключённый GBP (OAuth, D3-1) или по
Place ID без входа.
