# AIS-7 «Texte aus Fakten» — план (2026-11-06)

Источник: анализ AIS (строка AIS-7), план агента `planner`, сверен с кодом.

## Суть
«✨ Text vorschlagen» пишет описание/«Über uns»/баннер из УЖЕ СОХРАНЁННЫХ фактов. Сервер
читает факты сам (клиент шлёт kind + pk + подписанный экран), браузеру не верит. В базу
ничего: пустое поле заполняется, заполненное — предложение с «Übernehmen»/«Rückgängig».

## Цели v1
1. Описание товара (`catalog:product-edit`, rich-поле).
2. Описание услуги (`booking:service-edit`).
3. Студия: «Über uns» и баннер (`site-home`), язык канвы.
Номер/событие и шаг мастера — следующим инкрементом.

## Проверка «никаких новых фактов»
- Ссылки/контакты — всегда отказ; деньги/проценты/скидки — отказ ВСЕГДА (даже из фактов:
  PAngV, цена на витрине отдельно); числа — только целыми токенами фактов.
- Утверждения (vegan/bio/…): только при опоре в фактах; аллергены — только из декларации.
- `text_check` уровня high (превосходные степени, здоровье, гарантия, срочность) — отказ.
- Длины по полю; только плоский текст; язык результата сверяется.

## Инкременты (без миграций)
7a ядро (факты, проверка, задача, раскрытие) → 7b эндпоинты + кнопка на товаре → 7c услуга
→ 7d Студия → 7e стенд + документация.

## ECC-прогоны
Скиллы: django-security, django-tdd, django-celery, accessibility, error-handling. Агенты:
django-reviewer каждый шаг; security-reviewer (подмена фактов, инъекции, лимиты);
silent-failure-hunter (фон, refund, busy); a11y-architect (кнопки/статус/откат); стенд.

## Риски
Rich-редактор перетирает поле на submit; язык канвы Студии; ложные отказы на часах работы;
«seit Generationen» guard не ловит (промпт + «bitte prüfen»); стоимость strong-задачи.
