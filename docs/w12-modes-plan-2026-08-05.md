# W12 — честные режимы: одна ось Einfach/Experte

Дата: 2026-08-05. Родитель: `cabinet-unification-plan-2026-08-05.md §2.7`.
classic_ui снесён в W-CL → classic-измерение из §2.7 отпало; матрица тестов
сводится к (simple|expert) на ключевых поверхностях. Все инкременты БЕЗ миграций.

## §1. Разведка (2026-08-05)

Ось режима сегодня разорвана на три механики:
- `SIMPLE_HIDDEN_MODULES` (finance/analytics) + `ARCHETYPE_SIMPLE_HIDDEN`
  (ручная карта 4 из 15 типов, все → catalog) → `simple_hidden_modules()` —
  гейтит сайдбар/hub_tabs/плитки/виджеты.
- Флаг `advanced` NavEntry (ящик «Erweitert» таб-баров) — от режима НЕ зависит:
  Простой видит ящик целиком.
- `ui_simple` (context) — CSS-скрытие продвинутых полей форм (инвариант W0).
Тумблер в шапке (W4-fix) + карточка на «Funktionen» + список
`simple_hidden_labels` (#4). Модульная автоматика архетипа уже есть в другом
месте: `default_disabled_for` (S6a, recommended_for) — нерелевантные ОПЦИОНАЛЬНЫЕ
модули выключены по умолчанию; ручная карта нужна только из-за CORE-модулей
(catalog нельзя выключить — можно лишь спрятать).

## §2. Инкременты

- **W12-1 Страница «Ansicht»** (`/dashboard/ansicht/`, nav "ansicht", settings/
  Erweitert): выбор Einfach/Experte (тот же endpoint set-ui-mode) + список «что
  именно скрыто у ВАС» (simple_hidden_labels + подпись «страницы остаются
  доступны по прямой ссылке», принцип S5) + пояснение полевого скрытия форм.
  Карточка на «Funktionen» слимится до ссылки сюда; тумблер шапки остаётся
  (быстрый доступ). Реестр W8 += запись (иначе замок).
- **W12-2 Простой прячет advanced ВЕЗДЕ:** в Простом режиме ящик «Erweitert»
  таб-баров НЕ рендерится (страницы доступны по URL — принцип S5; Ctrl+K-палитра
  продолжает находить всё). Гейт в `hub_tabs`-теге по `is_simple`; замки
  test_hub_tabs/test_ui_mode дополняются. Поля форм уже скрываются (`ui_simple`).
- **W12-3 Архетип-автоматика вместо ручной карты:** `ARCHETYPE_SIMPLE_HIDDEN`
  выводится, а не перечисляется: скрывается CORE-модуль, который (а) не primary
  архетипа и (б) не входит в `recommended_for` его типа (сегодня это ровно
  catalog у friseur/handwerker/events/hotel — поведение 1:1, замок-паритет ДО
  правки; масштабируется на все 15 типов без ручного списка). Опциональные
  модули НЕ трогаются — их прячет `default_disabled_for` (урок Битрикса:
  «нерелевантный = выключен с возможностью включить, а не спрятан»).

## §3. Статус

- **W12-1 ✅** (2026-08-05): экран «Ansicht» (`/dashboard/ansicht/`, settings/
  Erweitert): Einfach/Experte (endpoint set-ui-mode) + честный список «что
  скрыто у вас» + принцип S5. Карточка на «Funktionen» слим до статуса+ссылки.
- **W12-2 ✅** (2026-08-05, правило уточнено замком): Простой прячет из ящика
  «Erweitert» продвинутые ИНСТРУМЕНТЫ (записи без module_key); advanced-функции
  активных модулей остаются — werkstatt в Простом держит Produkte/Lager
  (замок S6b поймал первоначальное «прятать ящик целиком» как регрессию).
  Открытая advanced-страница по прямой ссылке показывает ящик (подсветка честная).
- **W12-3 ✅** (2026-08-05): константы SIMPLE_HIDDEN_MODULES/ARCHETYPE_SIMPLE_HIDDEN
  удалены — ось живёт в ModuleSpec (simple_hidden у finance/analytics;
  simple_hidden_for у catalog: friseur/handwerker/events/hotel). Производная
  `_simple_hidden_for_type`; паритет 1:1 замком по всем BUSINESS_TYPES.

  «не primary → прятать»); знание курируется в спеке модуля (один источник).
