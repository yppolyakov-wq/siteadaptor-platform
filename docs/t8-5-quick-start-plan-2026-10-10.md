# T-8.5 «Aktion in 3 Klicks» — регистрация и первая акция одной страницей (2026-10-10)

Пункт 5 общего плана `t8-roadmap-2026-10-10.md` (этап 2) + запрос владельца 2026-10-10:
«после завершения этапа напиши страницу, где зарегистрироваться и опубликовать в 3 клика».
Анализ лёгкой версии §2.2 (экраны «Was bieten Sie an?» → «Wer sind Sie?» → «Fertig»),
решение Р-3: **сразу на поддомене, в городской каталог — после подтверждения почты**.

## 0. Факты (разведка 2026-10-10)

- `/registrieren/`: 7 обязательных полей (тип, имя, поддомен вручную, город, e-mail, пароль
  ×2); AB5.1 — тенант создаётся только после клика по ссылке из письма (`SignupRequest`).
- Провижининг: `start_business_provisioning` → Celery `provision()` (~1 мин, схема +
  User + Membership owner) → страница-спиннер → `/accounts/login/` на поддомене,
  **повторный вход e-mail+пароль**, автологина нет.
- Сессии не делятся между хостами (HIGH-10, `SessionSchemaGuardMiddleware`) → автологин =
  одноразовый токен, который логинит запросом НА ПОДДОМЕНЕ (паттерн `core/team.py`).
- Входа владельца без пароля нет нигде (magic-link есть только у жителя портала и у
  клиента витрины — другие модели пользователя).
- Ни у Tenant, ни у User нет признака «почта подтверждена»; агрегатор выкладывает акцию
  сразу при активации (фильтр только `is_demo`).
- Хранилище медиа общее (не по схемам) → фото можно сохранить на публичном хосте.
- Тёплого пула схем нет; `schema_name` выводится из slug в трёх местах.

## 1. Решение

**Страница `/aktion-starten/`** (публичный хост, телефон первым). Три клика:

1. **«Weiter»** — экран «Was bieten Sie an?»: фото (камера), заголовок, цена / statt /
   или %, срок чипами (Heute · Wochenende · 7 Tage · Datum), отклик чипами
   (Zurücklegen · Coupon · Nur zeigen; дефолт — Zurücklegen).
2. **«Veröffentlichen»** — экран «Wer sind Sie?»: название, тип (карточки), Stadtteil
   (Solingen по умолчанию), e-mail. **Без пароля и без поддомена** — поддомен генерируется
   из названия (умлауты → ae/oe/ue/ss, резерв, уникальность slug и схемы, суффикс -2…).
   Подпись «Mit dem Veröffentlichen akzeptieren Sie AGB und Datenschutz».
3. **«Teilen»** — экран «Fertig» ассистента T-8.4 (ссылка, QR, WhatsApp/Telegram, флаер).

Без JS оба экрана — одна форма (поля в DOM, шаги — только CSS-скрытие, инвариант W0).

**Провижининг:** `services.start_quick_provisioning` — тот же `_new_tenant`, плюс
`site_config["profile"]="aktionen"`, район, `email_pending=True`; владелец без пароля
(`set_unusable_password`). Celery `provision_quick` = `provision()` (без письма «bereit») →
в схеме: акция из ТОГО ЖЕ `QuickPromotionForm.build()`, фото, `limits.activate`; мастер
онбординга помечен пройденным (как демо-киты) → письмо «E-Mail bestätigen». Идемпотентно:
повтор не создаёт вторую акцию.

**Ожидание:** `/aktion-starten/<slug>/` — превью своей акции + прогресс, опрос JSON раз в
2 с; по готовности — переход на поддомен `/start/<token>/?next=/promotions/<pk>/fertig/`.
Токен (Redis `owner_login:<schema>:<sha256>`, TTL 1 ч) выдан при POST и лежит в сессии
публичного хоста — его знает только браузер, который регистрировался.

**Вход без пароля** (`apps/core/owner_login.py`, новый, для всех владельцев):
- `/start/<token>/` — GET показывает «Jetzt anmelden» (токен НЕ расходуется: почтовые
  сканеры делают GET), JS сам жмёт кнопку; POST расходует токен и логинит;
- `/anmelden/link/` — «Login-Link per E-Mail» (TTL 15 мин, rate-limit, нейтральный ответ —
  без перебора адресов); ссылка с формы входа allauth.

**Р-3 — каталог после подтверждения:** `Tenant.email_pending` (⚠️ миграция
`tenants/0034`, аддитивная, default False → живые тенанты не затронуты). Все upsert-пути
агрегатора (акции/номера/события/меню) при `email_pending` листинг удаляют.
`/start/bestaetigen/<signed>/` (подпись, 30 дней, привязка к тенанту) снимает флаг и
пересинхронизирует активные акции. Плашка «E-Mail bestätigen» на «Fertig» и в списке
акций + «Erneut senden»; при console-почте — прямая ссылка (как AB5.1).

**Защита от ботов** (класс T-5: каждый тенант — домен и сертификат): honeypot, rate-limit
5/ч на IP, ловушка времени (подписанная метка формы, отправка быстрее 3 с — отказ).

**Входы:** CTA «Aktion in 3 Klicks» на `/branchen/` и в шапке публичных страниц;
`?ref=` партнёра ловится как в регистрации.

## 2. Замки (до правок)

- slug: «Bäckerei Müller & Söhne» → `baeckerei-mueller-soehne`; занятый → `-2`; резерв и
  пустое имя → безопасный фолбэк; длина ≤ 40;
- POST: создаёт тенант (profile aktionen, email_pending, район), токен в сессии, редирект на
  ожидание; honeypot/слишком быстро/rate-limit — тенанта нет;
- `provision_quick`: владелец без пароля + owner-членство, ОДНА активная акция с фото и
  откликом, мастер пройден, повтор не дублирует;
- листинг акции при `email_pending` не создаётся; подтверждение — создаётся;
- `/start/<token>/`: GET не расходует, POST логинит и уводит на безопасный `next`
  (`//evil` → `/promotions/`), второй POST — 404; чужая схема — 404;
- `/anmelden/link/`: одинаковый ответ для существующего и несуществующего адреса;
- без JS все поля в DOM.

## 3. Вне объёма

Google/Apple-вход (провайдеры allauth — отдельный инкремент), тёплый пул схем (ожидание
~1 мин остаётся, маскируется превью акции; замер после пилота), автоудаление
неподтверждённых тенантов (кандидат в T-8.6 вместе с модерацией).

## 4. T-8.5b — доводка по фидбэку владельца (2026-10-10)

Запрос: «несколько фото; вводить предпочитаемый субдомен с проверкой на свободный; где название
на других языках; где потом исправлять акцию».

- **Несколько фото (до 6)** — общий партиал `promotions/_photo_picker.html` для ассистента T-8.4 и
  страницы `/aktion-starten/`: кнопка камеры (каждый снимок ДОБАВЛЯЕТСЯ — скрипт подставляет новое
  пустое поле) + галерея (сразу несколько), миниатюры с ✕, первое фото — главное. Поле
  `quick.MultiplePhotoField`, сохранение `quick.save_photos` (ошибка одного — откат всех файлов);
  «Wiederholen» копирует ВСЕ фото (`copy_images`). Фото с публичного хоста вносятся в медиатеку
  бизнеса фоновой задачей (в public её таблицы нет).
- **Свой адрес** — поле «Ihre Adresse ….siteadaptor.de»: пусто = из названия; живая проверка
  `/aktion-starten/adresse/` (JSON, rate-limit) — «✓ Frei» или «✗ vergeben» + кнопка «Stattdessen
  nehmen: …-2»; сервер проверяет ещё раз (гонка → понятная ошибка, фото удаляются). Свободным
  считается адрес, не занятый ни тенантом, ни схемой, ни ДОМЕНОМ (портал `solingen` живёт на своём
  Domain — без этой проверки регистрация «Solingen» упала бы на unique). Начинается с буквы (имя
  схемы Postgres), 3–40 символов.
- **Другие языки** — при создании пишется только базовый (немецкий) текст; переводы — в обычной
  форме акции. Экран «Fertig» даёт «🌐 In weitere Sprachen übersetzen» по языкам витрины; ссылка
  `?sprache=en` открывает форму сразу на этом языке (общий свитчер Ф1).
- **Исправить акцию** — «✏️ Bearbeiten» на «Fertig» (полная форма), а потом — список «Aktionen»
  в кабинете, имя акции = ссылка на форму.

## 5. T-8.5c — сначала город, потом район (2026-10-10)

Фидбэк владельца: «выбор города тоже нужен, а потом уже район в городе». Поле «Stadt»
(по умолчанию Solingen, подсказки — города реестра районов + города действующих порталов;
известный город приводится к каноническому написанию). Список районов сгруппирован по
городам, скрипт оставляет районы выбранного города и прячет поле, если районов у города нет
(сбрасывая выбор). Сервер сверяет район с городом (`districts.normalize`): чужой район
отбрасывается. Подписи «Stadtportal Solingen» → «Stadtportal Ihrer Stadt».
