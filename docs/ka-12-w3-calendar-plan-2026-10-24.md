# KA-12 W3 · Ресурс-календарь без миграций: E4.1 · E4.3 · E4.7 · E4.8 (план, 2026-10-24)

Источники: `ka-12-master-plan-2026-10-23.md` §1, KA-5b G-3/G7, KA-5c T-2, KA-5d Z8/§1.1/Z10. Всё без
миграций. План — агент planner; решения О-1…О-8 — по рекомендации, пока владелец не скажет иначе.

## 0. Что есть сейчас (сверено с кодом)
- **E4.1 слоты:** сетка только из `AvailabilityRule` ресурса (`booking/availability.py`); часы бизнеса
  в записи не участвуют, ресурс без правил — без слотов. **Betriebsferien:** `ClosedDate(resource=None)`
  = весь бизнес, но читает только запись; самовывоз, заказы, акции, «Jetzt geöffnet» его не видят;
  экран — только под `/dashboard/booking/`.
- **E4.3:** `booking.services.move` проверяет только ёмкость — нет `ClosedDate`, часов ресурса, письма
  клиенту, сброса `reminder_sent_at` (и дедуп-ключ напоминания без даты не дал бы повтора).
  Ручная запись проверяет `ClosedDate`, часы — нет.
- **E4.7:** `move_stay(reprice=False)` при смене числа ночей оставляет старую сумму и Kurtaxe; форма
  «update» сохраняет гостей/заметку/допы ДО `move_stay` → частичная правка при ошибке (Z8).
  Мультиномер: `rooms=N`, но один `room` FK → в шахматке одна полоса (ёмкость считается верно).
- **E4.8:** `occupancy_report` вычитает ВСЕ блоки из доступных; iCal-блок = проданная на OTA ночь →
  загрузка занижена (2 своих + 3 iCal из 10 → 29 % вместо 50 %).

## 1. Порядок
E4.8 → E4.7a → E4.7b → E4.1a → E4.1b → E4.3. Замки до кода, гейт, ревью, CI, FF.

## 2. E4.8
Внешний блок = `source_id_ref != ""` или «Import-Konflikt» в причине. Ручные — из доступных; внешние —
в проданные с капом `min(внешние, quantity − свои − ручные)` посуточно (без задвоения овербукинга).
ADR/RevPAR — по своей выручке с подписью (О-7). Ключи `external_nights`, `own_sold_nights`.

## 3. E4.7a
Без «Neu berechnen»: цена за ночь сохраняется (`lodging × new/old`), per-night допы пересчитываются,
Kurtaxe всегда свежая; drag (те же ночи/гости) — байт-в-байт. Форма «update» — в одной `atomic`,
ошибки ловятся снаружи (откат гостей/заметки/допов/трекеров). Сброс `reminder_sent_at` при переносе.

## 4. E4.7b
Честный показ: бронь ×N = полоса в назначенной комнате + (N−1) в «ohne Zimmer»; карточка
«3 Zimmer · 1 zugewiesen». Хранение N комнат — в батче E4.10 (миграция).

## 5. E4.1a Betriebsferien
`apps/core/closures.py` — единственная точка чтения `ClosedDate(resource=None)` (в public — пусто).
Потребители: слоты самовывоза, чекаут, «Kaufen»/«Zurücklegen» (купон и запрос работают), `open_status`/
presence, баннер витрины + сброс кэша. Экран `/dashboard/settings/betriebsferien/` (владелец/admin,
и в лёгком кабинете). Отель — не трогаем (есть `UnitBlock`). Агрегатор — позже (roadmap).

## 6. E4.1b
Ресурс без правил → окно дня из часов бизнеса; правила ресурса сильнее; кнопка «Aus Öffnungszeiten
übernehmen»; `within_hours` для E4.3.

## 7. E4.3
`move`: `ClosedDate` → `ResourceClosed`; вне часов → `OutsideHours` (override «Trotzdem eintragen»);
сброс напоминания; письмо «moved» (дедуп с новым временем, событие в матрице уведомлений); ключ
напоминания с меткой старта. То же для ручной записи.

## 8. Решения (рекомендации, действуют по умолчанию)
О-1 `ClosedDate` + экран · О-2 отель не трогаем · О-3 заказы/«Kaufen»/«Zurücklegen» закрыты, купон и
запрос работают · О-4 часы бизнеса — фолбэк, правила ресурса сильнее; О-4b вне часов — с
подтверждением, закрытый день — жёстко · О-5 цена за ночь сохраняется · О-6 мультиномер — показ сейчас,
хранение в E4.10 · О-7 RevPAR по своей выручке с подписью · О-8 экран и в лёгком кабинете.
