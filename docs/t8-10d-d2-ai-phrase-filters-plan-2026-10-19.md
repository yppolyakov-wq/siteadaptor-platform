# T-8.10d D-2 «ИИ: фраза → фильтры» — план (2026-10-19)

Родители: `t8-10-rest-plan-2026-10-19.md §3`, `t8-10d-search-subscriptions-plan-2026-10-19.md §4`.
**Статус (2026-10-19): ✅ сделано, выключено флагом до решения владельца.**
План — агент planner. Миграций нет. Всё за `AI_SEARCH_ENABLED=False`; владелец включает, когда
`search_log_report` покажет `d2_recommended` (Р-9: ≥500 поисков за 30 дней и ≥10 % многословных
запросов с пустой/малой выдачей).

## 1. Архитектура — асинхронно, ничего не применяется само
1. Страница выдачи рендерится как раньше. При включённом флаге и сработавшем триггере — пустой слот
   `<div data-ki-suggest data-url="…?t=<подписанный токен>">` + маленький скрипт.
2. Скрипт делает fetch на `ki-vorschlag/` (портал) или `entdecken/ki-vorschlag/`: кэш есть → 200 и
   HTML-фрагмент; промах → задача Celery, 202, опрос ≤ 5 раз по 1,5 с; нечего показать/ошибка/лимит → 204.
3. Воркер зовёт `apps.ai.generate`, проверяет ответ, кладёт в кэш ТОЛЬКО проверенные пары фильтров.
4. Предложение — обычная ссылка поиска с явными фильтрами + маркер `ki=<имена>`; после клика фильтры —
   обычные GET с ✕. Без JS подсказки нет (прогрессивная деградация).

## 2. Триггер (сервер, при рендере)
`enabled()` первым (флаг D-2 ∧ `AI_ENABLED`) · первая страница · ≥ 2 значимых слова в `q_eff`
(`search.significant_word_count`, общий с отчётом D-0) · в тексте нет контактов/ссылок · выдача ≤ 3
(портал — `hits`; режим «рядом» → нет; `/entdecken/` — `count_capped(pool, 3)` только при флаге) ·
GET ≤ 2000 символов.

## 3. Модуль `apps/aggregator/ai_search.py`
Задача `search_phrase_filters` (fast, 400 токенов, 10 с); `vocab(city)` (разделы/категории/теги/районы/
виды/размеры) + `vocab_digest`; `cache_key(phrase, city, lang)` = `ai-search:<версия>:` + sha256
(нормализованная фраза | город | язык | digest); `should_suggest`; `slot_context`; промпт с рамкой
маркера; `clean_suggestions`; `run` (никогда не бросает); `fragment` (эндпоинт); `remove_words`;
`landing_chips`; `KI_KEYS = kat, merkmal, stadtteil, kind, preis_von, preis_bis, groesse, marke`.
Регистрация в `AggregatorConfig.ready()`; Celery `ai_search_suggest` (dedupe = ключ кэша).
Настройки: `AI_SEARCH_ENABLED=False`, `AI_SEARCH_DAILY=500`, `AI_SEARCH_IP_LIMIT=10/600 с`,
`AI_SEARCH_POLL_LIMIT=120/600 с`, `AI_SEARCH_CACHE_HOURS=24`, `AI_SEARCH_ERROR_TTL=600`,
`AI_SEARCH_MAX_RESULTS=3`, `AI_SEARCH_MIN_WORDS=2`. Роуты выше catch-all портала; robots Disallow.

## 4. Токен и эндпоинт
`signing.dumps(..., salt="aggregator.ai-search")`, max_age 600: поверхность, хост портала, путь, район
из пути, сырой q, q_eff, город, язык, GET-пары (без cursor/ki). Шаги: лимит опроса по IP → флаг →
подпись (чужой портал → 204) → кэш: done → 200/204, pending → 202, error → 204; промах → лимит новых
фраз по IP → `cache.add(pending, 60)` → потолок дня (`cache.add`+`incr`) → `.delay` (брокер упал → 204)
→ 202. Заголовки `private, no-store`, `X-Robots-Tag: noindex`. Воркер: успех/пусто → done на 24 ч,
`AIError` → error на 10 мин. Фраза в кэш не попадает.

## 5. Контракт
Фраза — данные в рамке маркера; только ключи из списков; ничего не угадывать; `drop_words` — слова
фразы, полностью выраженные фильтрами; ≤ 2 предложений. Схема с enum из реестров. Не в контракте:
`unternehmen` (продвижение бизнеса), `datum`/`offen` (суточный кэш), `sort`/`umkreis`, свободный `q`.

## 6. Постпроверка (сомнение = отброс)
kat — `keys_for_filter` (≤ 2); merkmal — `normalize_tags` (≤ 3); stadtteil — нормализуется И топоним
есть во фразе; цены — число дословно во фразе, `von ≤ bis`; groesse — regex размера И токен во фразе;
marke — `clean_brand`, без ссылок/контактов, И есть в публичных листингах города; kind — из KINDS;
drop_words — только слова фразы; ≥ 1 фильтр; сквозной замок `parse_filters → carry` воспроизводит пары;
дедуп, ≤ 2.

## 7. Фрагмент
Явное сильнее (ключ, заданный явно, из предложения убирается); `q_new = remove_words(q, drop_words)`;
URL = путь + пары страницы + `q_new` + новые пары + `ki`; проверка наличия (`execute(...).exists()`,
≤ 2 запроса); подписи — из реестров на языке посетителя, не из ответа ИИ; «✨ KI-Vorschlag:» + чипы +
«Vorschlag übernehmen →» (nofollow) + `AI_LABEL`. Выдача исходной страницы не меняется.

## 8. После клика, журнал, подписка
`?ki=` (при флаге) → пилюли «Aus KI-Vorschlag: … ✕»; журнал страницы после клика — `extra["ki"]="1"`
(замер принятия `ki_landing` в отчёте); вызов ИИ в журнал не пишется (`AIUsage` без текста).
`follow_query.canonical` не знает `ki` → тот же `target_key` подписки (замок).

## 9. Замки
Флаг выключен: ни одного лишнего запроса/HTML, `?ki=` байт-в-байт, эндпоинт 204 · триггер · токен/
эндпоинт/лимиты/брокер · постпроверка адверсариально + свойство белого списка · рендер не меняет
выдачу · после клика + подписка · кэш-ключ · robots · отчёт D-0. Стенд Playwright на фейк-маршруте.
