# M4-A: цвет × размер + фото варианта (2026-07-31)

Последний пункт волны M4 бутика (`m4-boutique-plan-2026-07-30 §A`). Решение из
плана — **вариант (1)+(3)**: добавляем ОСИ (`size`/`color`) и фото рядом с
существующим `label`, а не вместо него.

## Почему label остаётся
`ProductVariant.label` — денормализованный ключ, на котором уже держатся:
склад-леджер (`inventory`, сущность = вариант), позиции заказа
(`OrderItem.title_snapshot`), PDF-накладные, товарный фид, CSV-импорт
(match по `(product, label)`), уникальный constraint `variant_product_label_uniq`.
Замена ключа = переписывание пяти подсистем ради витринного удобства. Поэтому:
- `size`/`color` — НОВЫЕ необязательные поля (обе пустые = поведение как было);
- `label` генерируется в `save()` из осей («S · Blau»), если задана хотя бы одна
  ось И label пуст — старые варианты и ручной ввод не трогаются;
- constraint/склад/заказы/импорт не меняются.

## Ловушки (проверить замками)
1. **Фасет Größe станет декартовым произведением.** Сейчас `_size_chips` берёт
   `label` → при осях чипы превратятся в «M · Blau», «M · Rot». Переключаем на
   `variants__size` (непустые), с фолбэком на `label`, когда осей нет.
2. **Форма корзины пинится замком** `test_cart_form_variants_and_modifiers_fields`
   (набор полей ровно `{csrf, product, variant, mod, qty}`). Значит два новых
   селекта осей НЕ должны слать своё имя: они `data-`-фильтры поверх ЕДИНСТВЕННОГО
   `select name="variant"`; без JS остаётся ровно прежний селект.
3. **Фото варианта** — v1 только подмена главного фото при выборе; галерея товара
   не трогается (её правит канва/inline-edit).
4. **CSV-импорт**: матч по `(product, size, color)` с фолбэком на `label` —
   иначе повторный импорт задвоит варианты.

## Инкременты
- A1 — миграция `catalog/0021` (size/color/images) + генерация label в `save()` + замки.
- A2 — фасет Größe на `variants__size` + фолбэк + замок «чипы не декартовы».
- A3 — витрина: оси data-атрибутами поверх одного селекта + подмена фото; замок паритета формы.
- A4 — кабинет: поля осей в форме варианта; CSV-импорт по осям.
