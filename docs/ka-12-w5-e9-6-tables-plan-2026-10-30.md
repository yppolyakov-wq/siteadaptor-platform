# KA-12 W5 · E9.6 — таблицы кабинета и клавиатура в списках (2026-10-30)

## Факты (разведка)
- 27 шаблонов кабинета с `<table>`; стиль у каждой свой (`bg-gray-50` шапка / `border-b` /
  `uppercase tracking-wide` / разные отступы `px-4 py-2`, `py-2`, `py-1 pr-3`).
- На телефоне таблицы либо сжимаются, либо уходят в `min-w-[640px]` + горизонтальный скролл.
- Горячих клавиш в списках нет; в хроме уже есть Ctrl+K (палитра) и Esc.

## Что делаем
1. **`.ui-table`** в `@layer components` (`static/src/app.css`): шапка (мелкий капс не нужен —
   `--ui-muted`, 12px, `font-weight 600`), строки с разделителем `--ui-line`, ховер-фон, числа
   `.ui-num` (табличные цифры, вправо). Плотность: `md+` — `padding .5rem .75rem`, `lg+` —
   `.375rem .75rem` (больше строк на экране). Утилиты страниц остаются сильнее компонента.
2. **Карточки на телефоне — `.ui-table-stack`** (опция): до `md` строка = карточка, ячейки
   столбиком «подпись: значение». Подпись берётся из `<th>` ОДНИМ общим скриптом в хроме
   (`data-label` проставляется на `td` по индексу колонки; без JS — обычная таблица со скроллом).
   Ячейки-действия (`data-cell="actions"`) — строкой кнопок внизу карточки.
3. **Клавиатура в списках** — общий модуль в хроме, только где страница пометила список
   `data-kb-list`: `j/k` (и ↓/↑ при фокусе внутри списка) — строка, `Enter` — открыть ссылку
   строки (`data-kb-href` или первая `<a>`), `/` — фокус в поиск страницы (`data-kb-search`).
   Не срабатывает в полях ввода, с модификаторами, при открытом диалоге. Подсказка клавиш —
   в палитре Ctrl+K (строка «Tastenkürzel»).
4. **Перевод экранов** порциями: сначала списки с наибольшим трафиком — Offene Posten,
   Rechnungen/Ausgaben, Aktionen, Lager, Einkauf, Reservierungen, Gutscheine; затем остальные.

## Инварианты
- Только рендер: колонки, ссылки, формы в ячейках, `data-*`-хуки — прежние.
- `scope="col"` на `th` (замок E9.4b) — сохраняется.
- Таблицы документов/PDF/писем/витрины — не трогаем (не кабинет).

## Замки (до кода)
- `.ui-table` / `.ui-table-stack` есть в `app.css`; переведённые шаблоны используют `ui-table`.
- Скрипт хрома проставляет `data-label` по `th` (Playwright: 390 px — строка-карточка с
  подписями; 1440 px — обычная таблица).
- Клавиатура: `j` выделяет первую строку, `Enter` переходит, `/` фокусирует поиск, в поле
  ввода `j` печатается (Playwright).

## ECC-прогоны
- До кода: `accessibility` (таблица остаётся таблицей для скринридера в stack-режиме —
  `display:block` ломает семантику → `role` на элементах сохраняем явно), `e2e-testing`.
- После кода: `a11y-architect` (stack-режим, горячие клавиши vs WCAG 2.1.4 «Character Key
  Shortcuts» — одиночные буквы только при фокусе в списке или с возможностью выключить),
  `code-reviewer`; Playwright-стенд 390/1440.
