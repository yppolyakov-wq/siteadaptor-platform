## Запрос владельца (2026-11-19)
- Каша в «Seitenaufbau»: не все элементы — блоки (плитки под баннером, FAQ без настроек); так на ВСЕХ
  типах страниц (главная, категория, каталог, акции, страницы, корзина, оплата…).
- Каждый элемент типа страницы — свой блок. Виды вывода списков чётко различимы в админке; у каждого
  стиля отображения — свои формы карточек.
- Студия на сайте — только тексты и порядок. Окно (попап) для добавления и правки блоков — вариант.
- Структура типа страницы — на экране «Структура страницы». У объекта (товар, акция, категория,
  страница…) своя вкладка структуры: по умолчанию повторяет общую, можно переопределить
  персонально — становится основной для объекта. Только внутренность страницы: шапку и подвал не
  менять.

## Предложенная модель (рекомендация, ждёт решений 1–6 и 7–9)
- Тип страницы → блоки; закреплённые (покупка, форма) не двигаются, но настраиваются.
- Окно блока (B на движке панели A): вкладки Что · Как расставить · Карточка · Тексты (+ «Страница» у ★).
- Карточки: формы получают геометрию плитка/строка; вид списка принимает только свою геометрию;
  вида без карточек — без вкладки «Карточка». Наследование видно на каждом поле.
- Студия: тексты, порядок, показ, фото; кнопка «Настройки» → то же окно.
- Своя структура объекта = полная копия общей (разделы, порядок, блоки, оси), отвязана, плашка
  «Своя структура · общие правки здесь не действуют · Вернуть общую»; сброс — целиком; шапка/подвал —
  никогда. Хранить копию в поле объекта (не в `site_config`: потолок 120 хостов, чтение на запрос).

## architect (2026-11-19) — варианты
Модель: тип страницы → блоки; блок → вкладки Was · Wie · Karte · Texte (+ «Seite» у ★). Одно место на настройку;
наследование видно (Design → страница → блок → объект; «N Produkte haben eigene Kartenform»). Конфликт: вид побеждает.
Вид→формы: CARD_FORMS получает shape tile|row; Raster/Slider → tile-формы; Liste/Zeilen → row (compact, deal, promo rows);
Preisliste → варианты строки (2/3 Spalten — параметр); Spotlight/Banner → главная фикс. + tile; Kategorien Kacheln → формы
Quadrat/Hoch/Breit/4:3; Chips/Regale/Index/Wegweiser/Reiter → без Karte; FAQ/Team/Trust/… → только Wie.
UI: A — панель по вкладкам (мало работы, тесно); B — окно (dialog) с предпросмотром блока (средне); C — правка на холсте
Студии (дорого, рискованно). Рекомендация: B на движке A + Студия только тексты/порядок/фото, кнопка «Einstellungen» → то же окно.
Новые блоки: «Schnellzugriff» (hero_widget), FAQ пункты в панели, стили about/team/... в панели; checkout — закреплённые строки
+ «Hinweise» вне формы. Миграция M0 макеты → M1 реестр block_settings + shape → M2 недостающие блоки → M3 окно → M4 урезать
Студию → M5 обход типов страниц → M6 уборка дублей. Вопросы владельцу 1–6 (см. ответ в чате).

und Leistungen» действует и на номера/события/туры. Студия пишет ширину/порядок/видимость (дубль), стиль и визуал блоков.

## architect: своя структура объекта (2026-11-19)
Три механизма вместо одного: НАЛОЖЕНИЕ (товар, услуга, номер, событие, тур, деталь акции — общие
блоки закреплены, общие правки доходят, разделы — разница `page_override`); ЗАМЕНА (категория —
копия только по кнопке, иначе первый блок молча убирает общие; группа акций — неявная копия без
плашки и сброса); контентные страницы — свой хост без общего типа; у комбо и блога своей нет.
Сброс неполный («Zurück zum Standard» оставляет свои блоки; у акции — не трогает оси). Правка в двух
местах (шаблон — радио во вкладке формы; разделы/блоки — в Seitenaufbau). Шапка/подвал нигде не
редактируются — требование выполнено. Оценка: хранилище в поле объекта 2–3 дн; 5 видов объектов
3–4 дн; акция 1; группа 0,5; категория 1; комбо/блог 1–2 (по решению).
