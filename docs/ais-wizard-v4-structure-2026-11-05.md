# AIS-W — мастер создания сайта v4: структура «базово / в процессе» (2026-11-05)

Продолжение `ais-ai-setup-simplification-analysis-2026-11-05.md`. Запрос владельца: «мастер
корявый — продумать структуру заново: что идёт базово, а что в процессе заполнения».
Решения владельца (2026-11-05): ИИ — Claude API; перевод — через ИИ, в будущем расходует
ИИ-квоту тарифа; данные Google-профиля — «как посоветуешь» (§5). Кода нет — структура на
согласование.

## 1. Почему нынешний мастер корявый

Сегодня 13 слайдов подряд (`apps/tenants/onboarding.py:121`), все пропускаемые:

`Start → Sprachen → Firma → Stil → Menü → Angebot → Produktseite → Kategorien → Startseite →
Über uns → Recht → Zahlung → Fertig`

1. **Порядок от формы к содержанию.** Стиль, меню, вид карточки и раскладку каталога (4 слайда)
   выбирают ДО того, как есть что показывать: выбор вслепую.
2. **Нет понятия «обязательно».** Пропустить можно всё, включая Impressum, и сайт уходит онлайн
   без него (нарушение § 5 DDG), а для отказа от онлайн-продаж мастер вообще не нужен.
3. **Одна позиция.** Слайд «Angebot» создаёт одну запись; реальный ассортимент живёт в кабинете.
4. **Часы — свободный текст** — не питают «открыто сейчас», слоты, портал.
5. **Языки на втором шаге** — до того, как появился текст, который нужно переводить.
6. **Дубль с концепцией T-8.32.** Там уже решено: реестр готовности по направлениям (§3) и
   жёсткий гейт продажи (Р-4). Мастер этот реестр не использует — свой чек-лист.

## 2. Принцип v4

**Базово = то, без чего сайт нельзя показать или нельзя продавать** (реестр «Обязательно» из
T-8.32 §3). **В процессе = всё «Желательно»**: не слайды, а карточки «Nächster Schritt» на
главной кабинета, по одной-три, в порядке пользы.

Три правила:
1. **Сначала содержание, потом оформление.** Оформление подбирается по типу бизнеса само
   (Look + сборка архетипа) и меняется одним кликом на превью, а не отдельным слайдом.
2. **Показывать, а не спрашивать.** Мастер получает то, что у владельца уже есть, и
   показывает заполненный черновик на проверку.
3. **Один реестр готовности** питает мастер, карточки «в процессе», экран «Laden eröffnen»
   и гейт чекаута/брони (T-8.32c). Отдельного чек-листа мастера больше нет.

## 3. Базовый мастер — 3 шага до «сайт онлайн»

### Шаг 1. «Was haben Sie schon?» — источник
Тип бизнеса уже известен с регистрации. Один экран, можно отметить несколько:
- **Google-профиль** — поиск «название + город», выбор карточки (§5);
- **свой сайт** — ссылка (импорт Г1, уже есть);
- **фото или PDF меню / прайса / вывески** (AIS-4, новое);
- **одна фраза о бизнесе** (`setup_plan`, уже есть; работает и на правилах без ИИ);
- **«Nichts davon»** — образцы позиций по типу бизнеса (из демо-кита) как предложения.

Без ИИ работают: Google, фраза (правила), образцы, ввод строками «Name — Preis».

### Шаг 2. «Prüfen» — один экран-черновик карточками
Всё, что собрано на шаге 1, сводится в карточки с галочкой и «✏️»:
1. **Kontakt & Öffnungszeiten** — название, адрес, телефон, e-mail, часы СЕТКОЙ (AIS-1),
   логотип (необязательно).
2. **Angebot** — СПИСОК позиций главного направления архетипа: товары / услуги с длительностью
   / номера с ценой за ночь и вместимостью / события / виды работ (без цен — Anfragen).
   Цены — только найденные в источнике или введённые; аллергены не выводятся. Образцы
   помечены «Beispiel» и не публикуются без правки или подтверждения.
3. **So sieht's aus** — живое превью с Look по типу и 3 миниатюрами для смены одним кликом.
4. **Texte** — заголовок главной и «О нас» из собранных фактов (ИИ, AIS-7) или шаблон типа.

«Übernehmen» записывает всё одной транзакцией через существующие сервисы.

### Шаг 3. «Rechtliches & Veröffentlichen»
- Impressum — короткими полями (ответственный, форма/регистр, USt-IdNr или § 19 UStG) →
  готовый текст на проверку (генератор `impressum_text` уже есть). **Обязательно.**
- Datenschutz — генерируется сам, ссылка «ansehen».
- Кнопка **«Website veröffentlichen»**. Сайт онлайн как визитка и каталог «смотреть».

**Чего в базовом нет:** языки, меню, вид карточки товара, раскладка каталога, отдельные слайды
«Startseite»/«Über uns», оплата. Всё это получает разумное значение по архетипу.

## 4. «В процессе» — после публикации

### 4.1. «Verkauf öffnen» — второй обязательный блок (только если бизнес продаёт онлайн)
Короткие вопросы с вариантами вместо форм (T-8.32 §5.2 п. 4), по направлению:
- Waren: получение (самовывоз / доставка с зонами), оплата (на месте / карта / перевод),
  НДС позиций, Grundpreis весовых, AGB, Widerruf при доставке, аллергены у еды;
- Termine: правила отмены, часы или расписание мастеров;
- Zimmer: правила отмены, Kurtaxe;
- Tickets: правила возврата; Anfragen: поля формы, НДС сметы.

Пока блок не закрыт — корзина/оплата/бронь закрыты с понятным текстом (жёсткий гейт Р-4),
сайт при этом работает.

### 4.2. Карточки «Nächster Schritt» (AIS-6) — желательное, по одной-три
Порядок — по данным, а не фиксированный:
1. фото к позициям («у 12 позиций нет фото»);
2. первая акция (Schnell-Aktion);
3. подключить Google-профиль для синка часов (D3);
4. языки + «🌐 Übersetzen» (ИИ, квота тарифа);
5. дизайн подробно (Design des Shops / Seitenvorlagen);
6. домен, Telegram-бот, категории/варианты/склад, мастера, сезоны — по направлению.

Экраны уже существуют; карточка — только вход с объяснением «зачем».

## 5. Google-профиль — рекомендация

**Сейчас: поиск по названию и городу без входа (Places API, платформенный ключ).**
Владелец выбирает свою карточку → подтягиваем адрес, телефон, сайт, часы → каждое поле
показывается на проверку и сохраняется как ввод владельца. Сохраняем `google_place_id` —
он нужен и Google-рейтингу (GK-11). Фото из Google не берём (условия Places API).

**Позже, по желанию: вход в Google (GBP, D3-1)** — только для синхронизации часов и постов, не
для регистрации: экран согласия Google на старте отпугивает и требует аккаунт-владельца профиля.

Ключ `GOOGLE_PLACES_API_KEY` с включённым Places API и биллингом — тот же, что ждёт GK-11.
Каждый поиск — платный запрос Google (центы на регистрацию); лимит частоты на сеть.

## 6. ИИ: Claude API и тариф

- **Где ИИ в мастере:** фото меню → позиции (AIS-4), фраза → план (`setup_plan`), тексты главной
  и «О нас» (AIS-7), позже перевод. Везде: цены и факты только из источника, черновик на проверку.
- **Claude API напрямую** — включаем на разработке и стенде сразу. Для прода важно:
  `AI_REQUIRE_EU=True` пропускает только маршруты ЕС, прямой API Anthropic им не является. Два
  пути — (а) тот же Claude через AWS Bedrock в регионе ЕС (другой ключ и счёт — AWS);
  (б) прямой API с AVV Anthropic и исключением для задач с данными бизнеса — после юриста.
- **Тариф:** учёт `AIUsage` по тенанту и дневные лимиты уже есть. Перевод и импорт фото —
  самые «тяжёлые» задачи; квота тарифа считается от них (тестовый период — малая квота).

## 7. Что переиспользуем, что новое

| Есть | Новое |
|---|---|
| state мастера v2, рельса, `?step=` (AB6.1) | реестр готовности T-8.32c (общий для мастера/гейта/карточек) |
| импорт сайта Г1, `setup_plan`, `impressum_text`, демо-киты, Look'и/сборки | шаг «Was haben Sie schon?» и экран-черновик |
| сетка часов в настройках (`openinghours`) | часы сеткой в мастере (AIS-1) |
| `promo_photo_draft` (фото → поля) | фото меню → список позиций (AIS-4) |
| Places API ключ (GK-11) | поиск места по тексту и разбор полей |

Старые слайды не удаляем сразу: прямые ссылки `?step=` и экраны остаются, мастер v4
включается флагом и сменяет v3 после стенда.

## 8. Инкременты (предложение)

1. **W4-0** реестр готовности по направлениям (T-8.32c) — без UI, замки.
2. **W4-1** шаг 3 (Impressum полями + публикация по гейту) + часы сеткой.
3. **W4-2** экран-черновик (шаг 2) на источниках без ИИ: образцы типа + ввод строками + фраза
   на правилах.
4. **W4-3** Google-поиск места (§5).
5. **W4-4** фото меню/прайса → позиции (Claude API).
6. **W4-5** «Verkauf öffnen» вопросами + карточки «Nächster Schritt».
7. **W4-6** стенд (5 типов × телефон) → включить v4 по умолчанию.

ECC-прогоны: `planner` по W4-0/W4-2 до кода; `django-reviewer` каждый инкремент;
`security-reviewer` на W4-3/W4-4 (внешние вызовы, загрузка файлов); `e2e-runner`/Playwright
и `a11y-architect` на W4-2 и W4-6.
