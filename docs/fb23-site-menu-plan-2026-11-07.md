# FB-23 — меню сайта: многоуровневое, прогрессивное, с привязкой к категориям и ссылкам

Фидбэк владельца 2026-11-07: «настройка меню в Website, прогрессивная и многоуровневая, как на
портале; пример — CS-Cart, но не копировать полностью; проверь конкурентов» + «нужно полноценное
управление меню, привязка к категориям или указание ссылок». Разбор батча —
`fb-feedback-batch-2026-11-07.md`. **Статус (2026-11-07): ИСПОЛНЕН ЦЕЛИКОМ FB-23a…e** —
виды A/B/C + D «Spalten» и G «Symbolleiste» (решение владельца; E/F — расширяемый реестр
`siteconfig.MENU_LAYOUTS`, по спросу).

## 1. Что есть сегодня (разведка, файл:строка)

- **Хранение** `site_config["menus"] = {top:{style,sticky,items}, bottom:{enabled,items}}`
  (`apps/tenants/siteconfig.py:2679`). Узел: `label`, `type`, `target`, `enabled`, `children`,
  `icon` (эмодзи), `with_combos`, `label_i18n` (только de/en) — `_clean_menu_node` :2609.
  Типы: archetype · category · categories · promo_group · page · url · anchor · group (:2573).
  **Глубина 2** (`_MENU_MAX_DEPTH`, :2584), ≤20 пунктов на уровень.
- **Резолвер** `apps/tenants/menu.py`: узел «Kategorien» сам подставляет подкатегории (≤12, один
  уровень, с фото и описанием — :193), наборы меню (`with_combos`), гейты модулей/контента,
  пустой узел выпадает. «Мега» = только флаг `has_images` (у кого-то из детей есть фото).
- **Витрина** `templates/storefront/_header_nav.html`: выпадашка-список или сетка плиток 2×N с
  фото (560 px); иконка пункта **нигде не рисуется**; мобильное меню — 2 уровня;
  **подвал зашит в шаблоне** (`_base.html:302`), своего меню нет.
- **Редакторы — два, оба неполные:**
  - кабинет «Menü-Generator» (`/dashboard/site/menu/`): пункты, тип, цель, вложенность на 1
    уровень, перестановка только внутри списка; нет иконки, переводов (хотя Studio обещает),
    `with_combos`, переноса пункта на другой уровень, подвала;
  - Studio (область «Menü»): только верхний уровень, нет удаления, детей, ссылок/якорей.
- **Портал** (`templates/aggregator/_portal_menu.html`): мега-меню «Kategorien» — слева разделы
  с иконкой, описанием и счётчиком, справа панель подразделов карточками + «Alles in X →».

## 2. Как у других (кратко)

| Платформа | Уровни | Привязка | Вид выпадашки |
|---|---|---|---|
| CS-Cart | дерево через «Parent item» в Design → Menus | ссылка/категория | шаблон блока; мега-меню — только аддонами |
| Shopify | 3 уровня, перетаскиванием | коллекция/товар/страница/ссылка | мега-меню — если умеет тема (3-й уровень = колонки) |
| Shopware | дерево категорий = навигация | категория | флайаут с колонками и фото категории |
| WordPress/Woo | любая глубина, перетаскивание вправо = вложить | всё | мега-меню — плагинами |

Вывод: стандарт рынка — **3 уровня**, **перетаскивание с вложением**, **привязка к категории с
авто-подпунктами** и **вид выпадашки на выбор** (список / плитки / мега-колонки). У CS-Cart
сильная сторона — один список «меню» и выбор шаблона показа отдельно; слабая — мега-меню только
аддоном и неудобное дерево через поле «родитель». Берём идею «структура отдельно, вид отдельно»,
дерево делаем перетаскиванием, мега-меню — встроенным.

## 3. Предлагаемое решение

### 3.1 Данные (presence-minimal, golden целы)
- Глубина **3** (`_MENU_MAX_DEPTH = 3`).
- Узел += `image` (фото пункта), `desc` (подпись ≤ 80 знаков), `auto` (у пункта-категории:
  «подкатегории показывать сами» — да/нет), `layout` у пункта верхнего уровня:
  `list` · `tiles` · `mega` (пусто = как сегодня: плитки, если у детей есть фото, иначе список).
- `label_i18n` — все включённые языки сайта, а не только de/en.
- `menus.footer = {columns:[{label, items}]}` — подвал из колонок ссылок (нет ключа — прежний
  зашитый подвал байт-в-байт).
- Новые цели в выборе: **конкретная категория** (с переключателем «авто-подпункты»), **товар**,
  **услуга**, **номер**, **событие/тур**, **акция**, **страница**, **своя ссылка**, **якорь**.

### 3.2 Виды выпадашки (на утверждение)

```
A «Liste»                B «Kacheln» (как сейчас)      C «Mega» (как портал)
┌──────────────┐         ┌───────────┬───────────┐     ┌──────────────┬───────────────────────┐
│ Brot         │         │ [img] Brot│[img] Kuchen│     │ 🍞 Brot     ›│ BROT · 24 Angebote    │
│ Kuchen       │         │ Frisch …  │ Torten …   │     │ 🍰 Kuchen   ›│ ┌Roggen┐ ┌Dinkel┐     │
│ Snacks       │         ├───────────┼───────────┤     │ 🥨 Snacks   ›│ └──────┘ └──────┘     │
└──────────────┘         │ [img] …   │ [img] …    │     │              │ Alles in Brot →       │
                         └───────────┴───────────┘     └──────────────┴───────────────────────┘
                                                        2-й уровень слева, 3-й — карточками справа
```

Мобильный — аккордеон на все 3 уровня; иконка пункта рисуется везде.

### 3.3 Редактор — один экран «Website › Menü» (вместо двух неполных)
- Слева **дерево** пунктов: перетаскивание, в т.ч. **вложить/вынуть** (тянуть вправо/влево или
  кнопки «→ / ←»), 👁 показать/скрыть, ✕ удалить, «＋ Punkt» на любом уровне.
- Справа **панель пункта**: название (+ переводы по языкам сайта), «Wohin führt der Punkt?»
  (выбор цели из п. 3.1, недоступные — «noch leer»), иконка, фото, подпись, у верхнего уровня —
  вид выпадашки A/B/C с мини-макетом.
- Сверху вкладки **Kopfzeile · Untere Leiste (Handy) · Fußzeile**; внизу — **живое превью** шапки.
- Быстрый старт: «Aus Kategorien erstellen» (меню из дерева категорий одной кнопкой).
- Studio: клик по шапке открывает краткую панель (вид шапки, CTA) и кнопку «Menü bearbeiten» —
  второго редактора структуры нет.
