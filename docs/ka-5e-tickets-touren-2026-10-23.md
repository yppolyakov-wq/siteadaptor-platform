## 2. Лишнее
«Reisen» в меню у ретритов/мастерских (гейт только по модулю); «Gastgeber/Guides» спрятаны в Ctrl+K, хотя
туроператору нужны; `jobs` в демо moto/stadtfuehrung; у ретрита одновременно депозит и рассрочка.

## 3. Не хватает (по важности)
1. Массовая отмена события: возврат + письмо участникам + остановка рассрочек.
2. Данные по каждому участнику групповой брони (имя, анкета, Waiver, документы).
3. Перенос/смена имени, частичный возврат и Stornogebühr по сроку.
4. Напоминание о доплате и ссылка на остаток; резерв мест на время оплаты (`payment_due_at`).
5. Счета по билетам (B2B), ставка НДС из события, § 25 UStG для пакетных туров, Sicherungsschein (§ 651r BGB).
6. Минимум участников с автоотменой, early bird по дате.
