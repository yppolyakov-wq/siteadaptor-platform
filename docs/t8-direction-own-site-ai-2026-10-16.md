# Куда двигать сервис: «свой сайт + наш каталог» и ИИ-будущее

**Дата:** 2026-10-16. **Статус:** разбор на решение владельца, кода нет.
**Вопрос владельца:** «В какую сторону двигать? Позволить ли бизнесам со своим сайтом
адаптировать его под наш функционал и публиковаться на портале — если полный функционал
им не нужен, а в каталоге быть хотят? Какие ещё идеи на разработку в ИИ-будущем?»
**База:** `market-research-t8-saas-ai-2026-10-16.md` (ветка `claude/gifted-wozniak-k131jm`,
в `main` ещё не влит) + разведка 2026-10-16 по моделям «только листинг / виджет на своём
сайте» (источники — §8) + сверка с кодом.

Легенда: ✅ официальный источник · ⚠️ данные вендора/вторичные/старше 2024 · **факт** /
*вывод* / **рекомендация** разделены.

---

## 1. Короткий вывод

1. **Да, открывать вход для бизнесов со своим сайтом — и это не «урезанный тариф», а
   ступень −1 перед «Nur Aktionen».** Рынок DACH сошёлся на одной схеме: *бесплатный или
   дешёвый листинг + плата за результат + виджет на своём сайте без комиссии* (Treatwell
   Connect, OpenTable, Too Good To Go, eBay «Deine Stadt»). Главный риск каталога —
   пустота (все городские площадки умерли на 30–60 продавцах); порог входа «заведи наш сайт»
   режет именно тех, у кого Instagram/Google-профиль уже есть и кто плотность и создаёт.
2. **Сегодня это невозможно по построению кода:** карточка «Unternehmen» в каталоге
   всегда ведёт на наш поддомен (`sync_business_listing`: `detail_url = _site(tenant) + "/"`),
   поле `Tenant.website_url` в каталог не уходит, лёгкая регистрация `/aktion-starten/`
   всё равно создаёт схему и витрину. То есть «быть в каталоге без нашего сайта» — три
   точечных изменения, не новый продукт (§3).
3. **Не тянуть чужие сайты автоматически (скрейпинг).** Юридически безопасно и
   технически надёжно — только **явный opt-in + официальные API** (Google Business Profile
   «Offer»-посты, Instagram Content Publishing API) или ручной ввод через ассистент 3 экрана.
   Фото/тексты с чужого сайта = Urheberrecht; цены без воли продавца = UWG/PAngV.
4. **ИИ: три ставки, уже выбранные в `t8-ai-layer`, рынок подтверждает** (данные важнее
   протоколов; ИИ-ввод для владельца; синк с Google). Новых «больших» идей я не предлагаю;
   предлагаю две **дешёвые и асимметричные**: (а) наш каталог как **источник правды для
   ИИ-ассистентов о местных предложениях** (ассистенты ошибаются о местных бизнесах в
   ~половине ответов — наша ниша «свежая цена и срок»), (б) **«ИИ-проверка перед
   публикацией»** (PAngV/UWG/LMIV) как аргумент продаж «у нас абмахнунг не получите».

## 2. Что показал рынок (факты)

### 2.1 Как берут бизнес со своим сайтом

| Игрок | Вход | Что получает | Кто платит и за что |
|---|---|---|---|
| Treatwell Connect | 39 €/мес ⚠️ (+ ✅ «Provision nur bei der ersten Buchung eines Neukunden» через маркетплейс) | листинг в маркетплейсе + кнопка «Jetzt buchen» на своём сайте **без комиссии** | за НОВОГО клиента, не за видимость |
| Too Good To Go | ~39 €/год + ~1,1–1,2 € за пакет ⚠️ | листинг в приложении, выдача в магазине | за результат (пакет) |
| OpenTable | 149 €/мес (NL ✅) + 1,50 € за гостя из сети; прямые брони — 0 | виджет + листинг | за гостя из сети |
| eBay «Deine Stadt» ✅ | 0 € для торговца, платит город | **существующие объявления появляются сами** | город |
| Google Business Profile ✅ | 0 € | профиль, «Offer»-посты через Local Posts API (документация обновлена 2026-08) | — |
| Jameda ⚠️ | профиль бесплатно, 99–199 €/мес за Pro | — | за выделение |
| atalanda 2015 ⚠️ | 20 €/мес + 8–12 % с заказа; **профиль без товаров допускался** | — | умерли на 60 торговцах |
| nebenan.de Business, kaufDA, Lieferando «только листинг» | 🔍 цен не найдено | — | пробел |

*Вывод:* у выживших **собственный канал бизнеса всегда бесплатен**, маркетплейс берёт за
привлечённого клиента/результат. Листинг — крючок, деньги — с роста.

### 2.2 Виджеты на своём сайте

Shopify Buy Button, resmio, Smoobu, Calendly — виджет есть везде, но это **функция SaaS,
а не канал в маркетплейс**; только Treatwell/OpenTable связывают виджет с маркетплейсом и
делают брони через виджет бесплатными. *Вывод:* рынок сошёлся на «маркетплейс — для
привлечения, свой канал — для повторных».

### 2.3 Откуда брать данные без ручного ввода

- ✅ Instagram Content Publishing API — публикация (50 постов/сутки), нужна верификация
  бизнеса; **чтения чужих постов для каталога** без согласия владельца нет.
- ✅ GBP Local Posts API: `topicType: OFFER` с купоном и сроком — можно и писать, и читать
  **свои** посты по OAuth (у нас адаптер `google_business` уже есть в `apps/publishing`).
- Google ↔ Instagram родного синка нет (только Zapier ⚠️).
- Скрейпинг: BGH 2011 «Automobil-Onlinebörse» ⚠️ — агрегация свободно доступных объявлений
  не нарушает §87b UrhG при отсутствии технических барьеров; но CJEU Ryanair — AGB могут
  запретить; свежие решения 2024–25 — уже по DSGVO. **Фото и описания — авторское право.**

### 2.4 ИИ-профили и «акция из фото»

- Google: Gemini ↔ Business Profile (черновики ответов, часы, «Business Notebooks»),
  анонс 2026-06-10, **в ЕЭЗ — позже**.
- Localo 39–49 $/мес (ИИ-посты GBP), Birdeye ~299 $/локацию ⚠️, Yext/Uberall — без цен для
  микробизнеса.
- 🔍 **Ни одного немецкого продукта «акция из фото/WhatsApp» не найдено** — T-8.10a/b
  остаются незанятой нишей.

### 2.5 Доказательства «виджет+листинг лучше замены сайта»

Прямых исследований нет. Косвенно: Wolt Local Commerce Report 2025 ⚠️ — 40 % партнёров
ценят присутствие «без собственного сайта»; Treatwell/OpenTable структурно обнуляют свой
канал ради удержания. *Вывод:* замена сайта как ценность не продаётся; продаётся приход
клиента.

## 3. Ответ на вопрос владельца: «свой сайт + наш каталог»

### 3.1 Предлагаемая лестница входа (расширение ступеней §9.2 лёгкого анализа)

| Ступень | Что у бизнеса | Что мы даём | Цена (предложение) |
|---|---|---|---|
| **−1 · Nur Eintrag** (новое) | свой сайт / Instagram / GBP | карточка в каталоге города со ссылкой **на его сайт**, акции через ассистент 3 экрана или импорт из GBP-постов, кнопки «Zurücklegen / Coupon / Anfragen» **в виджете на его сайте** | 0 € до N активных акций (Р-5), дальше — как сейчас |
| 0 · Nur Aktionen | ничего | визитка на нашем поддомене + всё выше | 0 € |
| 1–4 | — | как в `t8-aktion-start-lite-analysis §9.2` | 39 €+ |

Переход −1 → 0 → 1… — та же подсказка «следующий шаг» из данных (§9.3 там же).

### 3.2 Три механики (что именно делать)

**(a) Карточка с внешней ссылкой — T-8.27a.** `Tenant.website_url` уже есть (форма
«Mein Geschäft»). Нужно: признак «витрина выключена / внешний сайт» у тенанта, в
`sync_business_listing` и у листингов акций — `detail_url` на внешний сайт **только для
карточки бизнеса**; страница акции остаётся у нас (там «Zurücklegen»/купон/QR/флаер —
это наша ценность и мерило «визит и выдача»). `?ch=portal`-атрибуция цела. Витрина
поддомена при этом либо 302 на внешний сайт, либо остаётся «визиткой» — решение Р-A.
Без миграции, если признак положить в `site_config["profile"]` (прецедент
`"aktionen"`); чище — поле.

**(b) Виджет на своём сайте — T-8.27b.** Один `<script>`/iframe «Aktuelle Aktionen»
(лента карточек + кнопки отклика T-8.2/8.3, ссылки на нашу страницу акции). Техника
уже есть: G10 iframe-виджет отеля, stateless-превью, `_promo_featured`. Важно по
рынку: **действия через виджет — без комиссии, всегда.** Это и есть «адаптировать свой
сайт под наш функционал» без переезда.

**(c) Импорт из своих источников — T-8.27c.** Только opt-in по OAuth: GBP «Offer»-посты →
черновик акции (срок, купон уже в структуре поста) → подтверждение владельцем; обратно —
автопост акции в GBP (адаптер есть). Instagram — чтение своих постов тем же путём,
ниже приоритет (верификация бизнеса). **Скрейпинг чужих сайтов — не делаем** (§2.3).

### 3.3 Что есть в коде / чего нет

| Нужно | Есть | Нет |
|---|---|---|
| Внешняя ссылка бизнеса | `Tenant.website_url`, форма | не уходит в листинг; `detail_url` жёстко на поддомен |
| Регистрация без сайта | `/aktion-starten/` (slug, схема, владелец без пароля) | режим «у меня есть сайт» (ввести URL, не показывать витрину) |
| Отклики без оплаты | Zurücklegen, Coupon, Anfragen, QR, флаер | встраиваемая версия |
| Виджет | G10 (отель), stateless-превью | generic «Aktionen»-виджет + аттрибуция `?ch=widget` |
| GBP | адаптер `google_business`, OAuth in-app | чтение «Offer»-постов, автопост акций каталога, синк часов |
| Лимит бесплатного | `promotions/limits.py` (5 активных на «Nur Aktionen») | распространить на ступень −1 |

### 3.4 Контраргументы

- **«Ссылка наружу = утечка трафика с портала».** Да, но мерило пилота — визит и выдача,
  а не время на портале; eBay/Treatwell на этом и живут. Страница акции остаётся у нас.
- **«Каталог заполнится мёртвыми карточками».** Автопротухание (рекомендация отчёта §2.4)
  обязательно и для ступени −1: карточка бизнеса без активной акции N недель —
  понижается/гаснет, напоминание с «Wiederholen».
- **«Бизнес со своим сайтом никогда не поднимется на 39 €».** Вероятно, большинство — и
  не должно; его ценность — плотность и «отложено/выдано» для соседей. Подсказка
  «следующий шаг» (§9.3) — единственный апсейл, навязывать не нужно.
- **Данные тонкие:** ⚠️ цены Treatwell/TGTG — вторичные; nebenan/kaufDA — не найдены.

## 4. ИИ-будущее: что сверх `t8-ai-layer`

Очередь из отчёта остаётся: **ИИ-ввод владельца (T-8.10a/c) → GBP-синк + проверка
перед публикацией → поиск фразой (T-8.10d) → MCP только на чтение (T-8.10f) → агентская
оплата заморожена.** Дополнения (по убыванию асимметрии «дёшево нам / дорого
повторить»):

1. **«Источник правды о местных предложениях» для ассистентов — T-8.28.** Ассистенты
   верны в 48–56 % ответов о местных бизнесах, врут в телефоне/сайте/цене. У нас уже есть
   JSON-LD Offer, открытый фид, llms.txt (T-8.8). Не хватает **честной свежести**: поле
   «проверено владельцем <дата>» на карточке, автопротухание, `lastmod` по факту изменения.
   Это то, что даёт нам цитирование (бренды в AI Overview получают +35 % кликов ⚠️ Seer),
   а GBP-синк (§4.6 отчёта) делает нас свежее, чем профиль, который бизнес ведёт вручную.
2. **ИИ-проверка перед публикацией — T-8.10e (поднять приоритет).** SF-7 (ветка
   `gifted-wozniak`) закрыл процент от 30-дневного минимума арифметикой; остаётся
   текст: «garantiert», превосходные степени, «bio» без кода, аллергены — подсказка, не
   блокировка. Это **единственная ИИ-функция, за которую микробизнес в Германии готов
   платить прямо сейчас** (страх абмахнунга реальнее, чем «ИИ-пост»).
3. **Подписка на намерение (§3.2 ai-layer)** — после T-8.7 «Folgen» стоит один шаг:
   сохранённый запрос поиска T-8.20 → сверка SQL при активации акции. ИИ нужен один раз.
4. **Ассистент владельца в Telegram (T-8.10b)** — ниша пуста в DE (§2.4); привязка
   владельца уже есть (UD4-2), не хватает приёма команд.
5. **EU AI Act, ст. 50 (с 02.08.2026):** любой ИИ-черновик/ответ — пометка «создано с
   ИИ», метки на синтетике. Заложить в общий интерфейс провайдера (T-8.10d) сразу.

**Чего не делать:** генерация фото товаров (решение AMP), оплата через агентов (ACP/UCP —
свёрнута даже у OpenAI), ставка на `llms.txt`, «ИИ-конструктор сайта» (сайт обесценен,
<1 % трафика из LLM у Wix).

## 5. Рекомендация (очередь, на решение)

1. **T-8.27a** внешняя ссылка + регистрация «у меня есть сайт» (малый инкремент, без
   миграции при `profile`-ключе). Открывает ступень −1 для пилота Solingen.
2. **T-8.27b** виджет «Aktionen» для своего сайта (отклики без комиссии, `?ch=widget`).
3. **Автопротухание не-акций + еженедельное письмо «просмотры · отложено · выдано»**
   (отчёт §7 п.2–3) — удержание ступеней −1/0.
4. **T-8.27c** GBP: чтение «Offer»-постов → черновик + автопост акций каталога + часы.
5. **T-8.10e** ИИ-проверка перед публикацией (после мержа SF-7).
6. Далее по roadmap: T-8.10a/c, T-8.28, T-8.10d, T-8.10f.

Миграций в п.1–3 не требуется (при `profile`-ключе); п.4 — OAuth-скоупы, без модели.

**Вопросы владельцу:**
- **Р-A.** Витрина поддомена при внешнем сайте: 302 на сайт бизнеса (чисто) или
  визитка остаётся (SEO/карточка «So finden Sie uns»)? *Рекомендация: визитка остаётся,
  в карточке каталога — внешняя ссылка.*
- **Р-B.** Ступень −1 бесплатна навсегда (как GBP/eBay) или 39 €/год (как TGTG)?
  *Рекомендация: 0 € до лимита Р-5; деньги — с продвижения «★ Anzeige» и ступеней выше.*
- **Р-C.** Instagram-импорт в v1 или только GBP? *Рекомендация: только GBP (верификация
  Meta — недели).*
- **Р-D.** Влить ветку `gifted-wozniak` (отчёт + SF-7) в `main` до начала T-8.27?
  *Рекомендация: да, SF-7 — правовой блокер выхода каталога в город.*
