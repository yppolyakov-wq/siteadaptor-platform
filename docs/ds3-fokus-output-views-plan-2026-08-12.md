# План DS-3/DS-4 «Fokus: виды вывода per-модуль + композиция» (2026-08-12)

Решения владельца (2026-08-12, AskUserQuestion): (1) модель осей — **Look = кожа,
«вид вывода» per-модуль, работает в любом Look'е; в мастере 2–3 готовые СБОРКИ
на архетип** (Look + виды одним кликом); (2) пилот — **каталог: прайс-лист**;
(3) композиция Fokus-макета (сплит-hero, CTA в шапке + липкая мобильная кнопка,
мини-форма заявки на главной) — **в эту же волну**. Концепт-макет одобрен
(«фокус отлично») — артефакт «Look Fokus».

## Архитектурный принцип

Ничего не дублировать: виды вывода = новые значения СУЩЕСТВУЮЩИХ осей
(`SECTION_STYLES` для секций главной, `LAYOUT_PRESETS`/`*_layout` для страниц),
композиция = новые значения `HERO_STYLES`/`nav`-ключа. Сборка (Startpaket) —
данные поверх: {look, стили секций, раскладки страниц, композиция}. Всё
presence-minimal — golden целы (кроме осознанной регенерации при новой секции).

## Срезы (батчи, каждый — локальный гейт → CI)

### DS-3a Прайс-лист каталога (пилот)
- `SECTION_STYLES["products"] += "preisliste"` — секция главной: группы по
  категориям, строка «название · серый состав … цена» с отточием, без фото;
  «Ganze Speisekarte»/PDF-чип под списком.
- Страница каталога: пресет `catalog_layout` **"preisliste"** — тот же рендер
  строками ПОВЕРХ существующего листинга (фасеты/поиск/пагинация/провайдер UB
  не трогаются — меняется только партиал сетки; характеризационный замок
  прежнего вида ДО правок).
- Деталь не меняется (строка ведёт на неё). Цена справа `tabular-nums`;
  описание ≤1 строки серым; диет-иконки как сейчас.

### DS-3b Композиция первого экрана
- `HERO_STYLES += "split"` — текст слева на чистом поле (eyebrow=город/тип,
  заголовок, подзаголовок, CTA + ghost-CTA, строка доверия ★/стаж/Festpreis),
  фото справа (hero_image или ПЕРВЫЙ слайд heroes; слайдер в v1 при split не
  крутится — ограничение задокументировать).
- CTA в шапке: ключ `nav.cta` (presence-minimal, "" = как сейчас) — кнопка
  primary-действия архетипа (реестр `purchase_label`/`primary_item` готов;
  jobs → «Angebot anfordern» → /anfrage/). Мобильно тот же ключ включает
  ЛИПКУЮ нижнюю кнопку на витринных страницах (реюз стиля buybar; НЕ рендерить
  там, где уже есть data-buybar — двойной бар).
- Мини-форма заявки на главной: НОВАЯ секция реестра `anfrage` (default OFF,
  гейт модуля jobs; рендер = AF-2 партиал `_anfrage_form` + поля AF-1) —
  прецедент FD-2 (секция finder): ⚠️ ОСОЗНАННАЯ регенерация golden-эталонов
  (normalize дописывает известные секции выключенными).
- Компакт-доверие: `SECTION_STYLES["trust"] += "kompakt"` — рейтинг(и) +
  2 первых testimonial-цитаты + marks в одной полосе (цифры-полоса остаётся
  C-блоком ниже). Чередование фонов — БЕЗ новой механики: сборка ставит
  per-section visual.background (ось SE-3d существует).

### DS-3c Сборки (Startpakete)
- Реестр `sitetemplates.BUNDLES`: per-архетип 2–3 записи
  {key, label, look, section_styles, page_layouts, nav_cta, hero_style,
  sections_on/off}. v1: catering («Fokus» = klar-кожа + preisliste + split +
  cta + anfrage-секция + trust kompakt; «Fein klassisch» = текущий вид) +
  restaurant (Fokus-вариант для pranasy-типа). Применение — поверх
  `apply_look`-базы (полная копия конфига, W6-инвариант).
- Мастер, слайд «Stil»: карточки сборок НАД Look-галереей (Look-галерея
  остаётся «только кожа»). Studio: область Look получает те же сборки.

### DS-4 Пилот на демо
- Кит catering → сборка «Fokus» (как одобренный макет: белое поле, зелёный
  акцент klar/catering, прайс, сплит-hero, CTA в шапке, мини-форма, kompakt-
  trust, чередование фонов через section visual). Fein остаётся семейством в
  галерее (и на скриншотах для сравнения). Pranasy — Natur (не трогаем в
  этой волне). Пересев + Playwright-скриншоты владельцу.

## Замки
- Характеризационные ДО правок: текущий каталог-грид (карточный вид без
  пресета байт-в-байт), hero plain/accent, шапка без cta-ключа.
- Новые: preisliste секция/страница (группировка, цены, фасеты живы) ·
  split-hero (обе ветки фото) · nav.cta presence-minimal + отсутствие липкой
  кнопки при buybar · секция anfrage (off-дефолт, jobs-гейт, POST в штатный
  приёмник) · trust kompakt · BUNDLES: каждый apply→normalize идемпотентен
  (адверсариальный цикл — образец test_looks) · golden регенерация — отдельным
  коммитом с объяснением.

## Порядок
DS-3a → DS-3b → DS-3c → DS-4 (каждый срез мержится по зелёному CI — стоячее
правило). Дальше (за отмашкой): виды услуг/номеров/событий из матрицы
обсуждения (прайс-с-длительностью, пакеты-колонки, полоса-разворот, афиша).
