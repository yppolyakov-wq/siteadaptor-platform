# KA-12 PR-3 · Mengenaktion wirklich anwenden (2026-10-26, без миграций)

Из разбора `cs-cart-promotions-analysis-2026-10-26.md` (§3, решение владельца «поднять»).
Сегодня условие акции «2. Stück −50 %» / «3 für 2» / «ab 3 Stück −20 %» (`metadata
["price_condition"]`, В2) — только подпись: цена штуки обычная, корзина не дешевеет. Клиенту
обещано, а не исполнено (UWG-риск).

## Решение
- **Один расчёт** `apps/promotions/quantity_deals.py`: `split_units(cond, percent, base, qty)` →
  `[(штук, цена_базы)]`, сумма штук = qty:
  - `nth` (n, p %): `qty // n` штук по `base × (100 − p) %`, остальные по base;
  - `x_for_y` (n, pay): `(qty // n) × (n − pay)` штук бесплатно (0,00);
  - `min_qty` (n, p %): при `qty ≥ n` все штуки по `base × (100 − p) %`;
  - `other` / нет процента — без денег (только подпись, как сейчас).
  Округление до цента ROUND_HALF_UP; база — товар без варианта или вариант без своей цены
  (как `promo_line_price`).
- `deal_map(product_ids)` — активные условные акции на товар (не mystery, окно `target_rules`),
  при нескольких — наибольшая выгода для этой строки.
- **Корзина** показывает ту же разбивку: строка «3× … · Aktion 3 für 2: −1,50 €», итог строки
  уменьшен. **create_order** разбивает позицию на подстроки (скидочные — с `list_price`,
  `promotion`, маркером `{"promo": id}`), склад/леджер штатно, лимит кампании — скидочными
  штуками (`claim_units`), возврат при отмене — как сейчас.
- Обычная акция на товар (новая цена) сильнее условной — не суммируем.
- Витрина: цена штуки по-прежнему обычная + бейдж (UWG/PAngV — без изменений).

## Границы v1
Правка количества в кабинете не пересчитывает разбивку; SF-10 «акция исчезла между корзиной и
чекаутом» для условных акций не сверяется (заказ пройдёт по полной цене, корзина обновится);
комбо/услуги/номера — нет.
