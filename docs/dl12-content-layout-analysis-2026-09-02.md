## 3. Сквозные правила сеток (из R2, R3, R10, DL-11)

1. **Десктоп 3–5 карточек в ряд** (дискаунтеры 4–5; Dawn дефолт 4). Наши дефолты: акции 3,
   товары/категории 4 — ок; для «Prospekt» (H2) стоит 4 (плотнее, как HOFER).
2. **Телефон 2 колонки** для карточек (Dawn, Lidl, ALDI), **1** — для прайс-строк.
3. **Ряд полный или его нет** (DL-11): секции-превью режут хвост + «Alle …», листинги
   добивают плиткой-подсказкой; лента (`scroll`) — альтернатива для ≥ 6 позиций.
4. **Лимит секции-превью 4–8** (Dawn 4, Marktguru 5, ALDI ≥ 10 + «Alle anzeigen»). У нас
   products 8 ✓; **акции на главной сейчас без лимита** (aktionsmarkt — 18 карточек; Baymard:
   у 55 % «агрессивная реклама» вытесняет навигацию) → лимит 6/9/12 + «Alle Aktionen» (P1).
5. **Карусель ≤ 5 слайдов, без авторотации на мобильном, CTA дублируются** (R5).
6. **Карточка акции:** цена крупно → Grundpreis → зачёркнутая/процент → срок (R3).
7. **Карточки при фото, строки при однородном без фото** (R8).
