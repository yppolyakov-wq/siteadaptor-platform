# Пилотная волна — план исполнения (2026-10-23)

Источник: `docs/ka-11-synthesis-2026-10-23.md` (§3 блокеры, §4 порядок, §7 решения
владельца). Каждый батч — один прогон CI → FF в main. Цикл: planner → тесты до кода →
django-reviewer + security-reviewer → CI → main. Порядок: **A → B → D → E → C → F**.

## Батч A — решения владельца (без миграций)
- **KA-D5** каталог города всегда вкл: поле `in_city_catalog` убрано из формы «Mein
  Geschäft», быстрой регистрации, бота (signup/profile); `create_business` — True;
  выключение — только флаг оператора в админке (письменный отказ). Существующие False
  не трогаем без решения владельца (могли быть настоящие отказы).
- **KA-D7** финансовые выгрузки (журнал CSV, DATEV, DATEV расходов) — owner + admin;
  клиенты/участники/гости/банк — только владелец.
- **KA-D4** витрина скрыта до подтверждения почты (`email_pending`): 503 «bald da»
  + noindex; кабинет, вход, подтверждение, Mini App, статика и превью владельца — работают.

## Батч B — деньги сделок
- **KA-D2** выручка заявки — в журнал при выставлении счёта (идемпотентно, сторно).
- **KA-D3** отмена брони номера из кабинета — обязательный выбор «erstatten / nicht
  erstatten» на всех поверхностях.
- **KA-P6** онлайн-оплата держит ресурс ограниченное время: `payment_due_at` для
  Stripe-путей booking/stay/ticket (механизм `expire_payment_holds` уже есть).

## Батч D — молча обрезанные списки (P4)
- **KA-P4a** пагинация + «N von M» (продажи, Sortiment, отзывы, inbox, журнал,
  расходы, счета, ваучеры) — общий партиал.
- **KA-P4b** выбор клиента в форме счёта — поиск вместо первых 200.

## Батч E — телефон (P5)
- **KA-M1/M3/M4/M5** 16 px полей (iOS), sticky-кнопка над таб-баром, цели 44 px,
  подтверждение опасных действий.
- **KA-M2** денежные поля принимают «12,50».
- **KA-M6** сканер ваучера на iOS/Telegram.

## Батч C — время самовывоза (P3, W-1) — высокий риск, возможна миграция
- **KA-W1** слоты из часов работы, ёмкость слота, отсечка; выбор на чекауте →
  `create_order(pickup_slot=)`; серверная проверка под гонкой.

## Батч F — корни
- **T-8.32a/b** пакеты: гейт доступа по направлению (лёгкий кабинет).
- **KA-MC** денежный контракт + параметризованный инвариант на 6 видов сделок.
- **KA-GP** «золотые пути» Playwright: Aktionen-lite и Click&Collect.

## На владельце
Stage 0 (Stripe live, бэкапы, Sentry), юр. вычитка, реальные устройства (iPhone,
Telegram), решение о существующих бизнесах с отказом от каталога.
