# KA-12 Волна 5 · E10 батч 2 «ни одного молча обрезанного списка» (2026-10-26)

Источник: аудит `ka-10-tech-2026-10-23.md` §D (№22–23), мастер-план E10.5. Батч D пилота
(KA-P4) уже перевёл на страницы продажи, журнал, расходы, счета, доставки, «Sortiment».
Сверка кода 2026-10-26 (греп срезов `[:N]` во вьюхах) нашла остаток.

Почему раньше индексов E10.4: обрезанный список — ошибка ДАННЫХ (владелец не видит строку и
не знает об этом), а индексы на объёмах малого бизнеса (сотни строк на схему) почти ничего не
дают, при этом миграция проходит по всем схемам. Индексы — следующим батчем, по замеру.

## 1. Что меняем

| # | Экран | Было | Стало |
|---|---|---|---|
| L-1 | Meldescheine (`stays:checkins`) | 200 последних — у отеля за год больше, а хранить их надо год (BMG) | страницы `paginate_queryset` + `{% list_pager %}` |
| L-2 | Список акций (`promotions:promotion-list`) | без предела, 4 distinct-счётчика на всю выборку | страницы; счётчики и §11-цены — только по странице |
| L-3 | «Ohne Termin» в Auftragsbuch | 50, без пометки | 50 + «und N weitere» со ссылкой на список заказов |
| L-4 | Открытые входящие счета (Ausgaben) | 100, без пометки | страницы (свой параметр `?offen=`) |
| L-5 | Банк: неразобранные операции | 100, без пометки | страницы (`?seite=`) |
| L-6 | CSV склада | 5000 в памяти | потоково (`iterator()`), без предела |

Не трогаем осознанно: «последние импорты» Channel Manager (50 — это журнал недавнего, а не
список работы), сообщения треда в JSON-поллинге (50 последних — окно чата, полный тред
рисует страница), сотрудники фирмы в карточке компании (100 — справочник, редкость).

## 2. Замки

`test_e10_lists.py`: на каждом экране при N > размера страницы видна пометка «1–50 von N»
(или «und N weitere»), вторая страница отдаёт следующие строки; CSV склада отдаёт все строки.

## 3. ECC-прогоны

- Скиллы: `django-patterns` (пагинация, `iterator()` при `select_related`), `django-tdd`.
- Агенты: `django-reviewer`; `security-reviewer` не нужен (новых входов нет, параметр страницы
  уже валидируется `page_number`).
