# KA-12 E9.10 — один переключатель языка ввода на всех экранах (2026-10-31)

Фидбэк владельца: «Просто оставить de, en, ru, значок глобуса и полную надпись убрать»,
затем «проверь весь функционал и переделай так, чтоб было одинаково везде, где нужно».

## Разведка (что было)

| Экран | Было |
|---|---|
| товар, категория, акция | выпадашка у заголовка (E9.9) |
| набор (combo) | все языки подряд под базовыми полями |
| услуги, номера (список и страница) | свёрнутый блок «🌐 Translations» в каждой строке |
| тип акции (метка группы) | свёрнутый «🌐 Translations» |
| правовые тексты | все языки подряд в каждом блоке |
| мастер (баннер, «о нас») | свои пилюли-кнопки |
| Studio | выпадашка «🌐 Deutsch» |
| события, туры, ведущие, блог, подборки | переводы есть в модели (`*_i18n`), но в кабинете **ввести нельзя** (только демо-сидер) |

## Решение

- Один тег `{% lang_switch %}` (cabinet): рендерит `tenant/_i18n_switch.html`;
  группы берёт из контекста формы (товар/категория/акция) или строит по языкам тенанта.
  Выпадашка показывает только код языка, полное имя — в `title`.
- Поля языка — `[data-i18n-loc="<код>"]`, видна группа выбранного; базовый язык
  (`settings.LANGUAGE_CODE`, тег `i18n_base_locale`) виден по умолчанию. Все поля в DOM
  (инвариант W0); обязательное поле скрытого языка раскрывается при отправке (`revealField`).
- `OverlayI18nFormMixin` (core/i18n_input.py) — переводы overlay-полей в ModelForm:
  поле перевода сразу за базовым, `i18n_loc` для шаблона, запись в `_post_clean`
  с presence-guard (нет в POST — не трогаем; пусто — удаляем перевод).
- Подключено: EventForm/TourForm (title/summary/description), TeacherForm (title/bio);
  блог и подборки — `apply_i18n_overlay` во вьюхах.
- Мастер: та же выпадашка с кодом (своя логика панелей `data-loc-pane` сохранена).
- Studio: язык канвы — код вместо «🌐 Имя»; язык кабинета (🗣) — без изменений,
  это другая настройка.

## Не трогаем

Витрина, язык кабинета, метки опций/вариантов в строках товара (уже `data-i18n-loc`),
поля без перевода в модели (описание подборки в кабинете не редактируется вовсе).

## ECC-прогоны

`django-patterns`/`django-tdd` до кода; `django-reviewer` — формы и вьюхи; Playwright-стенд —
по просьбе (JS переключения общий с товаром, уже проверен).

## Замки

`apps/core/tests/test_lang_switch.py`: каждый экран кабинета с полями переводов имеет
выпадашку; старых «🌐 Translations» нет; тег показывает только коды; миксин — порядок
полей, начальные значения, presence-guard, очистка, один язык = без полей.
