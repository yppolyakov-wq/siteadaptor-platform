# FLT-3 — быстрые фильтры и ширина витрины бизнеса (план, 2026-11-04)

Продолжение волны FLT (портал — `flt-portal-filters-plan-2026-11-04.md`). Макет утверждён
владельцем тем же днём (артборд «Shop · Desktop», артефакт «Filter & Breite — Entwurf»).

## 0. Что уже есть (разведка)
- Каталог витрины (`promotions/public_views.py::product_list`, `storefront/products.html` на
  каркасе `listing.html`) УЖЕ имеет: кнопку «Filter» + левый ящик-форму DS-6
  (`_catalog_filters.html`, мультивыбор размера/цвета со счётчиками, цена, марка, состояние,
  «Nur reduziert», наличие, диеты, рейтинг), пилюли активных фильтров с ✕ (`_facet_pills`),
  число найденного, сортировку в единой строке DS-10, навигатор-колонку категорий (DL-20).
- Чего нет по макету: **быстрых фильтров в строке** — «Preis ▾», «Größe ▾», «Farbe ▾»,
  «Marke ▾», «Nur reduziert» рядом с кнопкой «Filter», чтобы частый фильтр ставился в один
  клик без ящика. И **ширины 1536 px** (сейчас `max-w-7xl` = 1280 в четырёх местах `_base.html`).

## 1. FLT-3a — ширина витрины (решение владельца: по умолчанию 1536)
- `site_defaults.page_width`: `""` (по умолчанию, 1536) | `"normal"` (1280, прежний вид) |
  `"full"` (без ограничения). Presence-minimal в `siteconfig` рядом с `text_width`.
- Контекст `storefront_page_width` → класс контейнера (`max-w-screen-2xl` / `max-w-7xl` /
  `max-w-none`) в шапке, верхней полосе, `main` и подвале `storefront/_base.html`.
- Контрол — экран «Design des Shops» (targeted-write, как остальные ключи кожи).
- Замки: дефолт = 1536 во всех четырёх местах; `normal` возвращает прежние классы; мусор → дефолт;
  normalize сохраняет ключ, golden не тронуты (ключ presence-minimal).

## 2. FLT-3b — быстрые фильтры в строке каталога
- Рядом с «Filter» (только `sm+`, на телефоне остаётся кнопка + ящик — поповер внутри узкой
  строки обрезался бы, урок FLT-1e): `<details>`-поповеры «Preis», «Größe», «Farbe», «Marke»
  (каждый — только когда у фасета есть значения) + переключатель-ссылка «Nur reduziert».
- Поповер = маленькая GET-форма того же фасета; скрытые поля = всё состояние страницы БЕЗ
  ключей этого фасета (и без курсора) → «Anwenden» не теряет остальные фильтры (W0-замок).
- Поведение (один поповер, Esc/Tab/клик вне) — общий `static/js/portal.js` (он не зависит от
  шторки портала: без `#flt-drawer` открывается обычный поповер).
- Новых ключей хранения нет, миграций нет.
