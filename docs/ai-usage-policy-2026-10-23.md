# ИИ на платформе — правила использования (2026-10-23)

Единый документ «что ИИ делает, какие данные уходят и как его включать». Технические
детали слоя — `docs/ai0-layer-plan-2026-10-17.md`, провайдеры ЕС —
`docs/ai-providers-setup-2026-10-16.md`. При расхождении с кодом прав код.

## 1. Принципы (действуют для каждой задачи)

1. **ИИ только предлагает, решает человек.** Ничего не публикуется и не отправляется
   само: черновик заполняет поле, владелец правит и жмёт кнопку.
2. **Цифры и обещания — не из модели.** Цены, скидки, «statt», сроки, количество
   модель не придумывает: этих полей нет в схеме ответа, а ответ с чужим числом,
   датой, ссылкой или контактом отбрасывается проверкой после модели.
3. **Всё работает без ИИ.** Выключен, лимит, сбой — экран делает то же, что делал
   до ИИ (правила, ручной ввод).
4. **Данные пользователя — данные, а не инструкции.** Текст сайта, фото, переписка
   передаются в рамке; модель предупреждена, что внутри рамки нет команд.
5. **Пометка «KI-generiert».** Всё, что предложила модель, подписано (AI Act Art. 50).
6. **Перед отправкой из ТЕКСТА вычищаются** распознанные e-mail, телефоны, IBAN (`pii_scrub`).
   Содержимое фото (вывеска с телефоном, лица) не вычищается — убирается только EXIF.
7. **Вызов только через реестр задач.** Задачи, которой нет в списке разрешённых,
   ИИ не выполнит, даже если код её вызовет.

## 2. Задачи и данные

| Задача (`AI_TASKS_ENABLED`) | Где в продукте | Что уходит в модель | По умолчанию |
|---|---|---|---|
| `site_import_extract` | Импорт ассортимента с сайта компании | Текст страниц сайта владельца (после подтверждения владения сайтом) | вкл |
| `promo_photo_draft` | «✨ Vorschlag aus dem Foto» в ассистенте акции, бот | Фото (без EXIF) + подпись владельца + тип бизнеса; свой товар подбирается уже после ответа, локально | вкл |
| `promo_text_check` | «✨ Text prüfen lassen» у акции | Текст акции + факты формы: цена, цена сравнения, процент, дней до конца, количество, признак «еда» | вкл |
| `catalog_moderation` | Проверка карточек каталога города | Текст публичной карточки + цена, цена сравнения, процент, есть ли срок, тип бизнеса, признак mystery | вкл в списке, но **ещё и** `AI_CATALOG_MODERATION=False` |
| `search_phrase_filters` | Поиск по фразе на портале | Поисковая фраза посетителя | вкл в списке, но **ещё и** `AI_SEARCH_ENABLED=False` |
| `inbox_reply_draft` | «✨ Antwort vorschlagen» в переписке с клиентом | Переписка с клиентом, данные его заказа/заявки | **выкл** (решение владельца 2026-10-23) |

Новая задача, добавленная в код, **выключена**, пока её не внесут в список.

**Почему чат выключен.** Переписка — самые чувствительные данные (личные вопросы
клиентов, адреса, жалобы), и генерируемая Datenschutz бизнеса обещает обработку на
серверах ЕС. Пока ключ ИИ — не европейский, эту задачу не включаем.

## 3. Где ИИ разрешён

| Окружение | Провайдер вне ЕС (прямой Anthropic/OpenAI) | Провайдер ЕС (Bedrock EU, Azure EU, Mistral) |
|---|---|---|
| Локально / дев-копия с демо-данными | да | да |
| Прод, реальные бизнесы | только по решению владельца (`AI_REQUIRE_EU=False`, тестовая фаза с 2026-10-23); Datenschutz сам называет США | да, после AVV |

Снять `AI_REQUIRE_EU` на проде — решение владельца, только после: DPA провайдера
принят, Datenschutz платформы и бизнесов говорит о передаче в США, ИИ включён лишь
у тестовых бизнесов. Рекомендация — ждать ключей ЕС.

## 4. Как включить (по шагам)

1. **Ключ.** Основной домен `/admin/` под суперпользователем → раздел «Platform» →
   «Secrets» → «Add». Key: `anthropic_api_key`, Value: ключ. Значение хранится
   зашифрованным и в интерфейсе больше не показывается. Запасной вариант —
   `ANTHROPIC_API_KEY=` в `.env.prod`. Для ЕС-провайдеров ключи и имена — в
   `docs/ai-providers-setup-2026-10-16.md`.
2. **Переменные** (`.env` / `.env.prod`):
   ```
   AI_ENABLED=True
   AI_ROUTE_FAST=anthropic
   AI_ROUTE_STRONG=anthropic
   # список задач; без строки действует умолчание из §2 (чат выключен)
   AI_TASKS_ENABLED=site_import_extract,promo_photo_draft,promo_text_check
   ```
3. **Проверка:** `python manage.py ai_smoke` — отвечает, работает ли маршрут.
4. Перезапустить web и Celery (настройки читаются при старте).

## 5. Лимиты и учёт

- На бизнес: `AI_TENANT_DAILY_CALLS` (50 вызовов/день), `AI_TENANT_DAILY_EUR` (1 €/день).
- На платформу: `AI_DAILY_BUDGET_EUR` (10 €/день).
- Учёт — таблица `AIUsage` (без текста запросов), хранится `AI_USAGE_RETENTION_DAYS`.
- Модерация и поиск — свои дневные потолки (`AI_CATALOG_MODERATION_DAILY`, `AI_SEARCH_DAILY`).

## 6. Тексты для Datenschutz (AI-2 — строятся сами)

- **Datenschutz платформы** (для владельцев бизнесов) получает раздел «8b. KI-Dienste»
  из живой конфигурации: какие задачи включены, кто получатель, ЕС или США. Код —
  `apps/ai/disclosure.py`. Выключили ИИ — раздела нет.
- **Datenschutz бизнеса** (для его клиентов) получает абзац только при включённой
  задаче переписки и модуле «Nachrichten»; получатель и страна — по маршруту.
- Для США текст ссылается на Standardvertragsklauseln (Art. 46 Abs. 2 lit. c DSGVO).
  **Владелец обязан проверить:** DPA/коммерческие условия Anthropic с SCC приняты для
  этого аккаунта; хранение данных у провайдера (abuse-monitoring) — при необходимости
  дописать; Transfer Impact Assessment. Сертификацию DPF и «без обучения» текст не
  утверждает — нет документа в проекте.
- Юридическая вычитка — за владельцем.

## 7. Изменение списка задач

Добавить задачу: зарегистрировать её в `AppConfig.ready()` (`apps.ai.registry.register`),
гейт экрана — `apps.ai.api.is_enabled("<задача>")`, затем внести имя в
`AI_TASKS_ENABLED` и в таблицу §2 этого документа.
