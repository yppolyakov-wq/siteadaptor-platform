# SHP — способы доставки как список (Abholung · Kurier · Versanddienste) — 2026-11-09

**Статус: описание согласовано владельцем 2026-11-09 («по рекомендации»), кода нет** (владелец: «не разрабатывай, просто опиши»).
Проверка ECC: `architect` (модель/миграция/читатели, file:line — в отчёте сессии) +
рыночная разведка (Shopify, WooCommerce, Shopware 6, DHL/Hermes/DPD/GLS/UPS, право DE).

## 0. Требование владельца
- Обычный экран настройки, где бизнес **добавляет способы доставки** разных типов:
  самовывоз · курьер по городу · транспортные компании; у компании — **курьер до двери** или
  **пункт выдачи** (Packstation, PaketShop). Компаний и операторов может быть много.
- **Регистрация способы доставки не спрашивает.** Мастер (шаг «Verkauf öffnen») — только
  выбор ТИПОВ; подробная настройка — потом, на экране.
- Чипы регистрации «Waren im Laden & zum Abholen» и «Online-Shop mit Lieferung & Versand» —
  один пункт «Waren» (они одинаковы и вводят в заблуждение).

## 1. Что сейчас (проблемы)
- Самовывоз выключить нельзя — онлайн-магазин без лавки всё равно предлагает «Abholung».
- Курьер и посылка — один флаг `Tenant.delivery_enabled`; зоны по PLZ — модель курьера.
- Перевозчиков (DHL, Hermes …) и пунктов выдачи в системе нет вовсе.
- Чип «Online-Shop» при регистрации доставку не включает.
- «zzgl. Versand» висит при любой доставке; страницы «Versand & Lieferung» на витрине нет
  (PAngV требует ссылку на размер стоимости доставки).
- Портал и Google не знают, как бизнес отдаёт товар.

## 2. Как это видит владелец

### Мастер, шаг «Verkauf öffnen»
Вопрос **«Wie bekommen Kunden die Ware?»** — три галочки:
**Abholung im Geschäft · Kurier in der Stadt · Versand per Paketdienst**.
Галочка создаёт способ с разумными значениями (самовывоз — адрес бизнеса; курьер — 0 € с
предупреждением «überall kostenlos»; посылка — DHL до двери, 4,99 €, «2–4 Tage»). Снятая
галочка способ выключает, не удаляет. Выключить всё нельзя, пока принимаются заказы.

### Экран «Zahlung & Lieferung › Lieferung & Abholung»
Список способов (порядок перетаскиванием, включатель у каждого) и кнопка **«＋ Versandart»**
(шторка): тип → для посылки компания (DHL, Deutsche Post, Hermes, DPD, GLS, UPS, Sonstige) →
**до двери / пункт выдачи** → цена. У каждого способа своё «Speichern».

| Тип | Что настраивается |
|---|---|
| Abholung | пункты выдачи (адреса), окна выдачи, мин. сумма, сбор (по умолчанию 0) |
| Kurier in der Stadt | районы/PLZ с ценой и «frei ab», только в этих зонах или везде, мин. сумма, срок |
| Paketdienst | компания, до двери или пункт выдачи, цена по Германии (pauschal или по весу, §5a), «frei ab», мин. сумма, макс. вес/длина, срок доставки |

Одну компанию можно добавить дважды (DHL до двери и DHL Packstation — с разной ценой).

## 3. Как это видит покупатель
- В корзине — список включённых способов: **название · срок · цена** («frei ab 50 €»). Один
  способ — без выбора, просто строка. Способа для адреса нет — он не показывается (никогда 0 €).
- Пункт выдачи v1 — поля, а не карта: для **DHL Packstation/Postfiliale** — номер станции +
  **PostNummer** (свои поля, а не «Adresszusatz»: иначе DHL их не видит), PLZ и город; для
  PaketShop Hermes/DPD/GLS/UPS — номер или адрес магазина + ссылка «Paketshop finden» на сайт
  компании. Packstation бывает только у DHL.
- У товара: **«zzgl. Versandkosten»** со ссылкой на новую страницу витрины **«/versand/»**
  (все способы, цены, сроки, порог «frei ab»); при одном лишь самовывозе — без приписки.
- После отправки — ссылка отслеживания по компании (шаблон компании + трек-номер, который
  уже есть в заказе).

## 4. Как это устроено (кратко)
- Новая таблица **«способ доставки»** в схеме бизнеса (а не поля Tenant: у каждой строки своя
  цена, имя на языках, порядок; заказ ссылается на конкретный способ). Справочник компаний —
  в коде (имя, ссылка отслеживания, есть ли пункты выдачи).
- В заказ при оформлении — **снимок**: какой способ, компания, до двери/пункт, название и
  срок на момент заказа, цена доставки, пункт выдачи и PostNummer. Старые поля заказа
  (доставка/самовывоз, адрес, цена) остаются — отчёты, счета, возвраты не меняются.
- Существующие бизнесы: автоматически — способ «Abholung» (как сейчас) и, если доставка
  была настроена, «Kurier in der Stadt» с теми же зонами и ценами — **поведение без изменений**.
  Посылку молча не создаём: отчёт «кто, похоже, отправляет посылки», решает владелец.
- Миграции: новая таблица + поля снимка заказа (обе аддитивные); позже — метки для портала.

## 5. Право (DE) — учесть в текстах
- PAngV: «zzgl. Versandkosten» рядом с ценой + ссылка на страницу с суммами; в фидах (Google)
  стоимость доставки тоже должна быть (сейчас `g:shipping` нет).
- Срок доставки обязателен (Art. 246a § 1 Nr. 7 EGBGB): «2–4 Tage»; без «ca.»/«voraussichtlich».
- ⚖️ Онлайн-заказ с самовывозом обычно тоже Fernabsatz → право отказа 14 дней; исключение —
  скоропортящееся (§ 312g Abs. 2 Nr. 2 BGB), по каждому товару. «Reservieren» (оплата и решение
  в лавке) — не Fernabsatz. **К юристу**, отдельным переключателем.

## 5a. Вес и размеры товара (замечание владельца 2026-11-09)
Сейчас у товара НЕТ веса для доставки и размеров. Есть только `content_amount` — количество
для Grundpreis (PAngV, «500 g»): это вес НЕТТО без упаковки, для доставки не годится (подсказка
при вводе — можно, подмена — нет).

**У товара и варианта** (вариант переопределяет: XL весит больше S):
- **Versandgewicht** (брутто, с упаковкой), граммы;
- **Maße** Д × Ш × В, см — необязательно;
- **Sperrgut** — флажок «громоздкое» (не влезает в обычную посылку).
Ввод — на вкладке «Preis & Bestand»/«Versand» формы товара; массово — CSV-импорт и колонка в
списке «Sortiment»; у магазина — **вес по умолчанию** (для товаров без веса, чтобы цена не
стала 0 € и не «угадывалась»).

**Как считается цена Paketdienst** (выбирает владелец у способа):
- **pauschal** — одна цена (как сейчас, по умолчанию);
- **nach Gewicht** — строки «bis 2 kg → 4,99 € · bis 5 kg → 6,99 € · bis 10 kg → 9,99 € ·
  bis 31,5 kg → 16,99 €» (заготовка — классы DHL); вес корзины = Σ (кол-во × вес) + вес упаковки
  способа; тяжелее последней строки — способ НЕ предлагается (честно, без 0 €).
- **Ограничения способа:** макс. вес и макс. длина стороны (DHL: 31,5 kg, 120 × 60 × 60 cm);
  товар длиннее или Sperrgut → способ скрыт, а для Sperrgut — свой способ (Spedition, своя цена).
- «frei ab» и мин. сумма действуют поверх.
Почему не автоматический «пакет по габаритам»: какие товары лягут в одну коробку — задача
упаковки, её не решить надёжно; габариты v1 служат только проверке «влезает / не влезает».
Hermes считает по размеру посылки (S/M/L) — для него владелец задаёт цену по весу как
приближение или pauschal; точные тарифы — с API компаний (позже).

**Куда ещё идёт вес:** снимок веса корзины в заказе (для Lieferschein/этикетки потом);
Google `g:shipping_weight` (и `g:shipping_length/width/height`, если заданы); CSV-экспорт.
**Курьер по городу** вес не учитывает (зоны PLZ), кроме макс. веса способа при желании.

## 6. Что сразу и что позже
**v1:** три типа, много компаний, до двери/пункт выдачи полями, Германия, цена плоская +
«frei ab» + мин. сумма, зоны PLZ у курьера, страница «/versand/», снимок в заказе.
**Позже:** другие страны (AT/CH, таможня CH), цена по объёму/«упаковке» (см. §5a), классы доставки по
товару, карта пунктов выдачи, API компаний (этикетки, отслеживание, Sendcloud), DHL Packstation
без PostNummer (с 2027), несколько отправлений в заказе, экспресс/желаемый день.

## 7. Порядок работ (когда скажете «делаем»)
SHP-0 замки паритета (цена доставки, корзина, оформление) → SHP-1 таблица + перенос данных +
единый читатель → SHP-1b вес/габариты/Sperrgut у товара и варианта + вес по умолчанию (миграция
catalog, аддитивная) → SHP-2 снимок в заказе, выбор по способу, отключаемый самовывоз, поля пункта
выдачи → SHP-3 экран со списком и шторкой → SHP-4 мастер (три галочки) → SHP-5 «/versand/»,
приписки к цене, готовность → SHP-6 Google `g:shipping`, local feed, метки портала →
SHP-7 отчёт для существующих + демо. Регистрация: один чип «Waren» (без вопросов о доставке).
ECC: `django-reviewer` каждый шаг; `database-reviewer` SHP-1/2/6; `security-reviewer` SHP-2;
`a11y-architect` + Playwright SHP-3.
