## 0. Принципы волны

1. **Один набор шаблонов** — только брейкпоинты Tailwind. Ключ кэша P0-1
   (`apps/core/pagecache.py`) не различает устройство: «телефонный» ответ ушёл бы на десктоп.
2. **P0-1** — в кэшируемом HTML нет персонального; «Merken»/«Folgen» для анонима — ссылки.
3. **Всё работает без JS**: шторки — `<dialog>` с noscript-фолбэком
   (`_portal_filter_drawer.html`), липкая панель — CSS. JS-кнопки прячем КЛАССОМ `hidden`.
4. **UWG §5a**: featured никогда не попадает в органические блоки (чипы, ленты, Deal).
5. **Не выдумываем данные**: нет адреса — нет строки; одно фото — нет «1 / 3»; нет
   признака НДС — нет «inkl. MwSt.»; нет способа оплаты — нет «bar oder Karte».
6. **Десктоп не регрессирует**: замки PH-11/PH-12 зелёные; дифф скриншотов 1440.
7. Гейты батча: `npm run build:css`, `test_template_comments`, `i18n_quickcheck`, 5 `.po`.

## 4. ECC-прогоны

- **Скиллы до кода:** `django-patterns`, `django-tdd`, `accessibility`, `e2e-testing`, `seo`,
  `error-handling`.
- **Агенты:** `django-reviewer` — каждый инкремент; `a11y-architect` — PH-13b (порядок h1/
  слайдер), 13d (нижняя шторка: focus-trap, Escape, возврат фокуса), 13e (дерево), 13g
  (fixed-панель против фокуса, кнопки поверх фото); `security-reviewer` — 13g
  (`history.back` только same-origin, tel/WhatsApp из полей тенанта) и 13a (эхо `q`/`datum`);
  `silent-failure-hunter` — 13f (фолбэки «нет данных → нет строки»); `doc-updater` — 13h.
- **Стенд Playwright** 390/1440 × de/ru после каждого инкремента: y первой карточки
  < 844 (главная, раздел) и < 300 (поиск); `scrollWidth <= innerWidth`; шторки с
  клавиатуры (Tab в пределах, Escape, возврат фокуса); панель M8 не перекрывает «Melden»
  и последнюю ленту; нижнее меню и панель покупки не наслаиваются; без JS — шторка и
  дерево статичны, «OK» сортировки виден; 1440 — дифф скриншотов.
