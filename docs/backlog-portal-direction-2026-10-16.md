## 10. Тайлы карты (В3)

- **OpenFreeMap** — бесплатно, без ключа, коммерческое использование разрешено (FAQ проекта);
  только **векторные** тайлы → вместо растрового слоя Leaflet нужен MapLibre GL (или плагин
  `maplibre-gl-leaflet`). Риск: сервис на донатах, без SLA.
- **Запасной вариант без внешней зависимости:** свои векторные тайлы Германии (Protomaps,
  один PMTiles-файл) на нашем хранилище — платим только за место/трафик.
- **Минимальная платная цена, если понадобится SLA:** Stadia Maps Starter **20 $/мес**
  (бесплатные планы Stadia и MapTiler — только некоммерческие).
