# Пилот Solingen — протокол (KA-12 E11.5, 2026-10-23)

Что меряем, как снимать цифры и когда останавливаться и править. Персональных данных отчёт
не содержит: только схема бизнеса, тип, пакет и числа.

## 1. Цели пилота
| Метрика | Порог «работает» |
|---|---|
| Медиана «регистрация → первая активная акция» | ≤ 10 минут |
| Бизнесов с хотя бы одним откликом (резерв / купон / заказ / бронь) за 14 дней | ≥ 50 % |
| Подтвердили почту | ≥ 80 % |
| Обращений в поддержку на бизнес за первую неделю | ≤ 2 |
| Сбоев писем (`failed_notifications`) | 0 у 9 из 10 бизнесов |

## 2. Еженедельный снимок
На сервере, раз в неделю (лучше в понедельник утром):

```
docker compose -f docker-compose.prod.yml exec web \
  python manage.py pilot_report --city Solingen --format csv \
  --support-log /app/docs/pilot/support-log.csv > pilot-$(date +%F).csv
```

- `--since 2026-11-01` — только бизнесы, зарегистрированные с этой даты.
- `--include-demo` — включить демо и внутренние бизнесы (по умолчанию их нет).
- `--format table` — для быстрого взгляда в терминале.

Колонки `min_to_…` — минуты от регистрации до первого действия; пусто = «ещё не было».
Последняя строка `MEDIAN (N)` — медианы по всем бизнесам отчёта. Колонка `error` заполнена,
если схему бизнеса не удалось прочитать (отчёт при этом не обрывается).

## 3. Журнал обращений (вручную)
Файл `docs/pilot/support-log.csv` (на сервере), по строке на обращение:

```
date,schema,topic,minutes
2026-11-03,baeckerei_meyer,Foto hochladen,5
```

`schema` — из колонки отчёта или из адреса кабинета. Имён и телефонов в журнал не пишем.

## 4. Ошибки
500-е ошибки и исключения — в Sentry (если задан `SENTRY_DSN`); раз в неделю смотреть новые
события по тегу схемы бизнеса.

## 5. Интервью (после первой недели, 10–15 минут)
1. Сколько времени ушло на первую акцию и где вы застряли?
2. Что клиент сделал после того, как увидел акцию (пришёл, отложил, позвонил)?
3. Какое сообщение или письмо от нас было непонятным или лишним?
4. Чего не хватило, чтобы запустить вторую акцию самостоятельно?
5. Порекомендовали бы вы это соседнему бизнесу? Почему?

## 6. Стоп / правим
- Медиана до первой акции > 20 минут → смотрим, на каком шаге застревают, правим ассистент.
- Больше трёх обращений на одну тему → правим этот экран до следующего снимка.
- Сбой писем у любого бизнеса → проверяем Resend и адрес до следующего рабочего дня.
- Ни одного отклика у бизнеса за 14 дней → звоним, разбираем акцию вместе.
