# W8: единый реестр навигации кабинета + подсветка + достижимость + Ctrl+K

Дата 2026-08-05. Контекст: `cabinet-unification-plan-2026-08-05.md §2.2` (решения
Р-6 «палитра — да»); предшественники W7 ✅, W-CL ✅ (classic-ветка снесена — реестр
строится без легаси). Семейство W-v3.

## §1. Проблема (из аудита, всё CONFIRMED)

Навигация описана в 4+ несинхронизированных местах: `sidebar_nav` (хардкод 7 якорей),
`HUB_TABS` (свои литералы), `hub_tiles`/`home_widgets` (свои), карточки лендингов
marketing_home/integrations_home (свои). Подсветка сайдбара работает на 7 из 44
nav-значений (~37 экранов «нигде»); один экран может иметь 4 входа под 3 именами;
сироты (billing/newsletter…) возникали незаметно. W7b залатал точечно; W8 делает
класс ошибок невозможным по конструкции.

## §2. Целевая модель

`apps/core/nav_registry.py` — ОДИН источник правды:

```python
@dataclass(frozen=True)
class NavEntry:
    url_name: str          # reverse-имя (уникальный ключ записи)
    label: str             # gettext_lazy, язык задач
    nav_key: str           # значение context["nav"] целевой страницы
    anchor: str            # якорь сайдбара, к которому относится экран (подсветка!)
    hub: str = ""          # таб-бар какого хаба содержит запись ("" = не таб)
    module_key: str | None = None   # гейт активности (None = ядро)
    advanced: bool = False # ящик «Erweitert» (W12 свяжет с Einfach/Experte)
    search: str = ""       # ключевые слова палитры/поиска меню
    icon: str = ""         # для якорей/плиток
```

Производные (генерируются из реестра, хардкоды удаляются):
1. **`sidebar_nav`** — записи-якоря (anchor == url_name); бейджи как сейчас.
2. **`HUB_TABS`** — заменяется группировкой реестра по `hub` (тег hub_tabs остаётся,
   читает реестр; simple-гейт W-CL сохраняется).
3. **Карта подсветки `nav_key → anchor`** — строится автоматически; `_base_dashboard`
   подсвечивает якорь по `anchor_for(nav)`, а не `nav == nav_key` → чинит ~37 экранов
   одним словарём.
4. **`nav_primary`** (мобайл) — первые 4 якоря (как сейчас).
5. **`hub_tiles`** главной — из записей-якорей (гейты бесплатно).
6. **Поисковый индекс палитры** (§4).

Не входят в реестр: карточки лендингов (W11 решит их судьбу), `orders_view_switch`
(умирает в W10), NavItem/ModuleSpec.nav_items (снос отдельной зачисткой после W8 —
их потребителей уже нет, остались тесты-замки «nav_items == ()»).

## §3. Инкременты

- **W8-1. Реестр + подсветка (ядро).** `nav_registry.py`: перенос ВСЕХ записей
  HUB_TABS + якорей sidebar_nav в NavEntry (значения 1:1 — характеризационный замок
  «hub_tabs/sidebar_nav дают прежний результат» ДО свода); `anchor_for(nav_key)` в
  context-processor → подсветка сайдбара на всех экранах. Замок: каждый литерал
  `"nav": "<x>"` из вьюх (~44) имеет anchor в реестре (парсим grep-снапшотом в тесте
  или явным списком NAV_KEYS).
- **W8-2. Достижимость.** Инвариант-тест: для каждой NavEntry с module_key
  активным — url reverse'ится и запись достижима (якорь или таб хаба, к которому
  ведёт какой-то якорь); плюс обратный: каждая кабинет-вьюха из urls_tenant с
  login_required попадает в реестр или в явный allowlist (эндпоинты действий,
  фрагменты, легаси-страницы W10). Ловит сирот навсегда.
- **W8-3. hub_tiles/nav_primary из реестра** (мелкий свод, паритет-замки).
- **W8-4. Ctrl+K-палитра.** Оверлей в `_base_dashboard` (реюз поля «Search menu…»):
  индекс = реестр (label+search+hub-путь), фильтр на клиенте (JSON в шаблоне,
  ~60 записей — без эндпоинта), Enter → переход, хоткей Ctrl/Cmd+K + кнопка 🔍.
  Данные/настройки НЕ ищем (v2 — после W9, когда настройки структурированы табами).

## §4. Риски/замки

- Свод «байт-в-байт»: рендер hub_tabs до/после идентичен (golden-снапшот HTML на
  3 хаба × (simple|expert)); sidebar_nav — сравнение списков dict.
- i18n:新 msgid не появляются (labels переносятся lazy-строками как есть).
- Не трогаем: HUB_TABS-константу удаляем только после перевода ВСЕХ читателей
  (grep: cabinet.py + тесты); тесты, читающие HUB_TABS напрямую, переводим на реестр.
- Ошибка класса «care»: nav_key, который не отдаёт ни одна вьюха, ловится замком
  W8-1 автоматически.
