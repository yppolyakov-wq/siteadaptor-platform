# T-8.4 «Schnell-Aktion» — мобильный ассистент акции + лимит 5 активных (2026-10-10)

Пункт 2 общего плана `t8-roadmap-2026-10-10.md`. Источник — анализ лёгкой версии
`t8-aktion-start-lite-analysis-2026-10-09.md` §2.1–2.3 и решение владельца Р-5.
Экран «Кто вы?» (регистрация/вход по ссылке) — это T-8.5, здесь не делаем.

## 0. Факты (разведка)

- Создать акцию сегодня = полная форма `promotions:promotion-create` (~25 полей, табы),
  затем отдельная кнопка «Aktivieren» на странице акции (`promotion_transition`).
  С телефона это 2 экрана и много прокрутки.
- Активация идёт тремя путями: кнопка перехода (`promotion_transition`), beat
  `roll_due_promotions` (scheduled → active) и демо-сидер (пишет статус напрямую).
- Фото акции — `images` (FileRef), загрузка `save_product_image(folder="promotions")`;
  удаление `delete_stored_image` удаляет ФАЙЛ → при «Wiederholen» файл надо копировать,
  а не делить ссылку (иначе удаление фото у одной акции ломает другую).
- Часы работы — `Tenant.opening_hours_structured` (`openinghours.normalize`): сегодняшнее
  закрытие известно, если часы заданы.
- QR акции `storefront-promotion-qr` (только active), share-ссылки — `core/share_links.py`.
- Все шесть лёгких демо держат по 6 активных акций.

## 1. Лимит 5 активных акций (Р-5)

Модуль `apps/promotions/limits.py` — одна точка истины:

- `active_limit(tenant) -> int | None` — `settings.LITE_FREE_ACTIVE_PROMOS` (5), если
  тенант на **бесплатной лёгкой ступени**: витрина «Nur Aktionen»
  (`storefront_profile.is_aktionen`), подписка не `active`, тенант не демо. Иначе
  `None` (без лимита): платные тенанты и полная платформа лимит не получают никогда.
  Демо — витрины платформы (`is_demo`), их не ограничиваем.
- `can_activate(promo, tenant)` — сколько активных, кроме этой; `ActivationLimit`.
- `activate(promo, tenant, actor)` — проверка + `PromotionSM.apply(…, "active")`.
- Сообщение: «Mit dem kostenlosen Start sind bis zu 5 Aktionen gleichzeitig aktiv. Mehr
  Aktionen? Schreiben Sie uns: <контакт>». Контакт — `settings.PLATFORM_CONTACT_EMAIL`
  (env, по умолчанию `kontakt@siteadaptor.de`).

Где проверяется (только при переходе в `active`, черновиков сколько угодно):
1. кнопка перехода в кабинете (`promotion_transition`) — отказ с сообщением;
2. ассистент «Veröffentlichen» — акция сохраняется черновиком, экран «Fertig» объясняет;
3. beat `roll_due_promotions` — scheduled при полном лимите остаётся scheduled и
   включится, когда место освободится (тенант резолвится по схеме).

Счётчик «3 von 5 aktiv» — в списке акций и в ассистенте (только у ограниченных).

## 2. Ассистент `/promotions/schnell/` (`promotions:promotion-quick`)

Одна страница, три шага (с JS — по одному на экране телефона, «Weiter/Zurück»; без JS
все три видны подряд — форма работает):

1. **Was?** Фото (`accept="image/*" capture="environment"`), заголовок (подсказки —
   заголовки пресетов архетипа `presets_for`, `<datalist>`), описание (необязательно).
2. **Preis & Dauer.** Новая цена, старая цена (необязательно) **или** «−N %»; срок
   чипами: «Heute bis Ladenschluss» (закрытие из часов; часов нет → 23:59) ·
   «Dieses Wochenende» (до воскресенья 23:59) · «7 Tage» (по умолчанию) · «Eigenes
   Datum»; «Stückzahl» (пусто = без лимита).
3. **Was tun Kund:innen?** Только выполнимые отклики T-8.2 (`response.py`):
   Zurücklegen · Nur zeigen · Anfragen (если модуль заявок) · Online kaufen (если можно
   продавать); по умолчанию — то, что выбрала бы автоматика.

Кнопки: «Veröffentlichen» (создать + активировать через `limits.activate`) и «Als
Entwurf speichern». После — экран **Fertig** `promotions:promotion-quick-done`:
ссылка, QR, «WhatsApp · Telegram · E-Mail · Kopieren», переход к полной форме акции и
«＋ Noch eine Aktion». Флаер — T-8.9 (кнопка появится там).

Создаётся обычная `Promotion` (тип discount, `starts_at=сейчас`), поэтому дальше её
ведёт всё существующее: полная форма, витрина, портал, резерв, аналитика.

## 3. «Wiederholen» и «＋»

- В списке акций у прошлых (ended/archived/paused) — «↻ Wiederholen» → ассистент
  `?von=<pk>`: заголовок/описание/цены/Stückzahl/отклик/рубрика предзаполнены, фото
  переносится КОПИЕЙ файла (скрытое поле `foto_von`; новое фото сильнее), срок
  выбирается заново.
- Список акций: главная кнопка «＋ Neue Aktion» ведёт в ассистент, полная форма
  остаётся рядом («Alle Felder»); на телефоне — плавающая «＋» над таб-баром.
- Под каждой акцией счётчики: просмотры · zurückgelegt · ausgegeben (одним
  annotate, без N+1).
- Палитра Ctrl+K: запись «Schnell-Aktion» (palette_only) — правило X7.

## 4. Замки (до правок)

- лимит: лёгкий бесплатный тенант — 6-я активация отклонена (кнопка/ассистент/beat),
  5-я проходит; платный (`subscription_status="active"`), полная платформа и демо —
  без лимита; черновик и запланированная создаются без ограничений; beat оставляет
  scheduled при полном лимите и включает при освободившемся месте;
- ассистент: создаёт активную акцию с заголовком/ценой/сроком/откликом/фото; срок
  «Heute» = закрытие по часам, без часов — конец дня; «7 Tage»; «Eigenes Datum» в
  прошлом — ошибка; невыполнимый отклик не предлагается; черновик не активируется;
- «Wiederholen»: предзаполнение и копия фото (другой путь файла; удаление у одной
  акции не трогает другую);
- экран Fertig: ссылка/QR/share только у активной; у черновика — объяснение лимита;
- список: счётчики, кнопка «＋ Neue Aktion» ведёт в ассистент.

## 5. Вне объёма

Регистрация и вход по ссылке (T-8.5), флаер (T-8.9), купон (T-8.3), ИИ-подсказки по
фото (T-8.10a), расписание «каждую пятницу 17–19» в ассистенте (сегодня — полной формой
через «Repeat automatically»), платная лёгкая ступень (после пилота).
