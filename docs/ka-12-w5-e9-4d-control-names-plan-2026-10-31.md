# KA-12 W5 · E9.4d — у каждого поля кабинета есть доступное имя (2026-10-31)

## Факты (замер)
Скан шаблонов кабинета: **450** полей (`input/select/textarea`, кроме hidden/checkbox/radio/
кнопок) без доступного имени — ни обёртки `<label>`, ни `label for=id`, ни `aria-label`/`title`.
Подпись, как правило, есть визуально (соседний `<label>` без `for`, `span.stu-lb`, placeholder),
но скринридер её не связывает с полем (WCAG 1.3.1, 3.3.2, 4.1.2). Placeholder именем не считается.

## Что делаем (три прохода + ручная доводка)
1. **Обёртка:** `<div><label>ТЕКСТ</label><control></div>` → `<label class="block"><span …>ТЕКСТ</span>
   <control></label>` (классы подписи переносятся на span — вид тот же; id не нужны, поэтому
   безопасно в циклах) — 170 полей.
2. **Placeholder с `{% trans %}`** → тот же текст в `aria-label` — 133 поля.
3. **Видимая подпись рядом** (`span.stu-lb`, `<p>`) → её текст в `aria-label` — 39 полей.
4. **Ручная доводка** — 108 полей (даты «Von/Bis», часы работы «<день> Von/Bis», ссылки
   readonly, фильтры статуса, поля строки сметы/счёта и т.п.); новых msgid — один («Priorität»).

## Замок (`apps/core/tests/test_control_names.py`)
Храповик: в кабинете безымянных полей **0**; исключение — только с причиной в `BASELINE`.
Невидимое (honeypot `class="hidden"`/`aria-hidden`, инпуты в JS-строках, теги в комментариях)
не считается. Плюс адверсариальные мини-кейсы сканера.

## ECC-прогоны
- Скилл `accessibility` (accname: label > aria-label > title; placeholder — не имя).
- `a11y-architect` на дифф (выборочно: обёртки в grid/flex, качество имён).
- Гейт: ruff, полный pytest (обёртки меняют разметку — проверить замки разметки),
  `template_comments`, `i18n_quickcheck`.
