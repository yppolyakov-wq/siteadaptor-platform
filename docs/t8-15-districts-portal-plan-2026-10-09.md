# T-8.15…T-8.18 — районы Золингена, Gräfrath, портал города, демо вне настоящих порталов

Решение владельца 2026-10-09: «Да, делай всё как указал. Домен пока выбираю, делай пока на
нашем субдомене». Исходная сводка — ответ в сессии T-8 (после концепции городов и тем).

## 0. Разведка (факты из кода)

- `Tenant.district` (CharField 100) существует с первого дня, но **нигде не используется**
  (только админка). В `AggregatorListing` района нет — только `city`.
- `AggregatorPortal` (P2.1) уже умеет хост → портал: своя марка, фильтр `city`/
  `business_type`, свободная ось уточнения (`/<facet>/` — тип бизнеса у городского портала),
  карта, sitemap/robots, аккаунт жителя, Telegram-бот. Создание — `create_portal`
  (портал + строка `Domain(host → public)`; без неё Caddy/django-tenants отдают 404 — T-5).
- Листинг попадает в пул автоматически (`aggregator.tasks.sync_*`, `reconcile_schema`)
  — **признака «демо» нет**. Пять лёгких демо Solingen (T-8.1) с вымышленными адресами
  попали бы в портал города как настоящие (UWG: введение в заблуждение).
- `apply_kit` зовётся только из `seed_demo_tenants` (мастер онбординга кит не применяет) —
  значит пометка «демо» в `apply_kit` не заденет настоящие бизнесы.
- Уже засеянные демо на сервере после деплоя не пересеваются сами → нужна
  data-миграция по замороженному списку слагов китов.
- Изменение города в настройках бизнеса не переносится в листинги (пред-существующий
  пробел) — для района нужен перенос, иначе выбор района не дойдёт до портала.

## 1. T-8.15 — демо не попадают в настоящие порталы

- `Tenant.is_demo` (⚠️ миграция `tenants/0033`, SHARED, + data-миграция по слагам китов).
  `apply_kit` ставит True.
- `AggregatorListing.is_demo` (копия из тенанта в `_tenant_base_defaults`).
- `AggregatorPortal.show_demo` (default **False** — новый портал по умолчанию честный;
  data-миграция: существующим порталам True — сегодня все они демонстрационные, иначе
  `hotels.<base>` опустеет). Миграция `aggregator/0019`.
- `listings_for(..., include_demo=True)`; портал передаёт `portal.show_demo`. Общий
  `/entdecken/` (платформенная витрина) показывает демо, как и раньше.
- Карточка листинга с `is_demo` — бейдж «Demo» (везде, где карточка). Портал, который
  показывает демо, — полоса «Vorschau mit Beispielgeschäften» над выдачей.

## 2. T-8.16 — шестое демо: Gräfrath

Пять официальных Stadtbezirke Золингена: 1 Gräfrath · 2 Wald · 3 Mitte ·
4 Burg/Höhscheid · 5 Ohligs/Aufderhöhe/Merscheid. Демо T-8.1 закрывали 2–5.
Новый кит `LITE_FRISEUR` «Salon am Gräfrather Markt» (`graefrather-markt`, friseur):
визитка + 6 акций (Heute / Diese Woche / Neu bei uns / Auf Bestellung — как у остальных),
фото из фонда (`salon-interior`, `haircut`, `hair-color`, …). Все шесть лёгких китов
получают поле `district`.

## 3. T-8.17 — районы на платформе

- Реестр `apps/core/districts.py`: город → районы (slug, название, алиасы, PLZ-подсказки).
  Только уверенные PLZ: 42651 Mitte · 42653 Gräfrath · 42659 Burg/Höhscheid ·
  42697/42699 Ohligs/Aufderhöhe/Merscheid · 42719 Wald (42655/42657 делятся между
  районами — подсказки нет, владелец выбирает сам). Хранение — slug района.
- Функции: `districts_for(city)`, `normalize(city, value)` (slug / название / алиас →
  slug), `suggest(city, address)` (PLZ из адреса), `label(city, slug)`.
- Настройки бизнеса: поле «Stadtteil» — select районов, когда город известен реестру;
  иначе hidden (инвариант W0: поле в DOM всегда). Пустое значение + PLZ в адресе →
  предзаполнено подсказкой. Сохранение переносит город и район в листинги тенанта.
- `AggregatorListing.district` (в той же миграции `aggregator/0019`).
- Портал: ряд чипов районов (если город портала знает реестр) + страницы
  `/stadtteil/<slug>/` и `/stadtteil/<slug>/<тип>/` (до catch-all `<facet>`);
  чипы типов на странице района ведут внутри района; sitemap += районы.

## 4. T-8.18 — портал Золингена на нашем субдомене

`seed_demo_tenants` при засеве лёгкого кита идемпотентно создаёт портал
`solingen.<base>` (kind=city, city=Solingen, `show_demo=True` — превью для партнёров) +
строку Domain (как `_ensure_hotel_portal`). Переход к запуску: снять «Beispiele zeigen»
в админке портала. Собственный домен — тот же портал, второй хост (позже, когда
владелец выберет имя).

## 5. Замки

- демо-листинг не виден порталу с `show_demo=False`, виден с True и на `/entdecken/`;
- `apply_kit` ставит `is_demo`; data-миграция помечает слаги китов;
- реестр: normalize алиасов/названий, suggest по PLZ, неизвестный город → пусто;
- форма: select при известном городе, hidden иначе; сохранение переносит район в листинги;
- портал: чипы районов, `/stadtteil/<slug>/` фильтрует, неизвестный slug → 404;
- шесть лёгких китов: у каждого свой район, все пять районов покрыты.
