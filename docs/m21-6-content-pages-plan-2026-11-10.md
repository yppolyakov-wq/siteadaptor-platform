# M21.6 — свои страницы сайта («Seiten») + перенос Versand/Zahlung/Über uns

Дата: 2026-11-10. Запрос владельца (haanerteeladen): перенести страницы старого магазина
`/versand/`, `/versand-de/` (Zahlungsarten), `/our-team/` (Über uns) как отдельные страницы
во всю ширину; в админке — управление страницами: создать, изменить, удалить. Проверить с ECC.

## 1. Что есть сейчас
- Своих страниц у бизнеса нет: только системные (`/ueber-uns/`, правовые, `/versand/` —
  способы доставки SHP-5) и блоки страниц `page_blocks`.
- Импорт M21.3 положил тексты Versand/Zahlung **текстовыми блоками** на «Über uns» —
  без картинок, одной стеной текста; `/versand-de/` переадресован на «Über uns».
- «Über uns» показывает `about_text` плоским текстом (картинки старой страницы потеряны).
- Ширина текстовых страниц — настройка `site_defaults.text_width` (narrow|wide|full), у
  магазина не задана (= узко).

## 2. Решение
1. **Модель `core.ContentPage`** (TENANT, миграция `core/0018`, аддитивная): `slug` (уникальный),
   `title` + `title_i18n`, `body` (HTML) + `body_i18n`, `is_published`, `sort_order`.
2. **HTML страницы** — отдельный профиль санитайзера `richtext.sanitize_page()`: allowlist
   описаний + `h2 h3 h4 img figure blockquote`; у `img` только `src alt width height`,
   никаких `style`/`on*`. Санитайз при сохранении И при рендере (как SR-3).
3. **Витрина** `/seite/<slug>/` (`storefront-content-page`), во всю ширину по `text_width`.
   Неопубликованная → 404 (кроме вошедшего члена команды — предпросмотр).
   **Системные slug'и** выводятся на своей системной странице, а не вторым адресом:
   `versand` → `/versand/` (текст над способами доставки), `ueber-uns` → `/ueber-uns/`
   (вместо `about_text`). `/seite/versand/` тогда — 301 на системную.
4. **Меню**: новый тип узла `cpage` (цель = slug), набор целей «Eigene Seiten» в редакторе
   меню/подвала и в Студии; узел гаснет, если страница не опубликована.
5. **Кабинет** `Website › Seiten` (`/dashboard/site/seiten/`): список, «＋ Neue Seite»,
   правка (заголовок, адрес, текст визуальным редактором с заголовком и картинкой по URL,
   «veröffentlicht»), удаление с подтверждением. Права — `view_perms` W/WE, запись в
   `nav_registry`.
6. **Импорт CS-Cart**: страницы `versand`, `zahlung`, `ueber-uns` из HTML старого сайта с
   перезаливкой картинок; создаются только если их ещё нет (правки владельца целы);
   прежние текстовые блоки Versand/Zahlung на «Über uns» снимаются, если не правились;
   `/versand-de/` → `/seite/zahlung/`; ссылка подвала «Versand & Zahlung» → две ссылки;
   `text_width=full`, если не задана.

## 3. Замки (до кода)
- санитайзер страницы режет `<script>`, `onerror`, `javascript:`, `style`; оставляет h2/img;
- витрина: опубликованная 200, неопубликованная 404 анониму / 200 члену команды, системный
  slug — 301, контент системного slug на `/versand/` и `/ueber-uns/`;
- кабинет: создать/изменить/удалить, slug уникален и не из зарезервированных путей,
  анониму — редирект на вход, у каждого экрана право в `view_perms`, вход в `nav_registry`;
- меню: узел `cpage` даёт ссылку только опубликованной странице;
- импорт: создаёт страницы, повтор не перезаписывает правки, снимает свои блоки.

## 4. ECC-прогоны
- скиллы до кода: django-patterns, django-security, django-tdd, accessibility;
- `django-reviewer` + `security-reviewer` (HTML, авторизация, slug) — перед мержем;
- `a11y-architect` — экран кабинета и страница витрины;
- Playwright-стенд: кабинет «Seiten» (создать → открыть на витрине → удалить) и
  страница во всю ширину 1440/390.
