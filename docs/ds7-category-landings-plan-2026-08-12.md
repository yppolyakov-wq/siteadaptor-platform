# План DS-7 «Лендинги направлений + тумблер цен в меню» (2026-08-12)

Запрос владельца: «для каждого направления (еда на свадьбу и т.д.) — отдельные
страницы: описание, галерея, примеры блюд БЕЗ цен, отзывы, в стилистике Fokus —
целевые лендинги по категориям» + «настройка показывать цену в меню или нет» +
«засеять в демо catering, посмотреть где ещё использовать».

## DS-7a Лендинг направления (БЕЗ миграции)

Данные уже есть: `Category.description` (i18n dict, витриной не использовался),
`Category.images`, товары категории, `site.testimonials`, AF-2-форма.

- Роут `/bereich/<slug>/` (tenant urls) → `category_landing`:
  топ-категория active; гейт ДВОЙНОЙ (класс ST-8): включён общий тумблер
  `site_config["category_landings"]` (presence-minimal True; дефолт ВЫКЛ —
  у существующих тенантов описания категорий не должны внезапно рождать
  страницы) И у категории есть контент (description или images) — иначе 404.
- Шаблон Fokus-композиции: split-шапка (имя + описание + CTA primary-действия
  с `?betreff=<имя>` для jobs + фото), галерея (category.images, фолбэк — фото
  товаров), «Beispiele» — товары категории БЕЗ ЦЕН (имя + состав), 2 цитаты
  testimonials, anfrage-банда (гейт jobs) или контакт-CTA. Title/meta из
  категории.
- Плитки направлений (компакт-стиль DS-4b и обычные) ссылаются на лендинг,
  когда тумблер вкл И у категории есть контент; иначе прежний фильтр
  /sortiment/?kategorie= (fail-safe, ничего не ломаем).
- Тумблер в кабинете: чекбокс «Bereichs-Landingpages» в блоке каталога на
  «Pages» (сентинел-гард, targeted-write).

## DS-7b Тумблер цен в меню

`site_config["menu_show_prices"]` (bool, дефолт True; ключ материализуется
только при False — golden целы). `_price_list.html` прячет колонку цены во всех
пяти видах; «ab-цена» плиток направлений тоже уважает ключ. UI: чекбокс
«Preise anzeigen» в панели секции «Товары» Studio + в блоке каталога «Pages»
(оба с сентинелом `mp_present` — чекбокс не прислан ≠ выключить). PAngV-гейт:
скрытие цен доступно ТОЛЬКО при неактивном модуле orders (browse-only меню;
при продаже цена обязательна) — форма не показывает опцию, normalize не
хранит False при активном orders (fail-open к показу цен).

## DS-7c Засев catering + рекомендации

Категории кита получают описания (5-й элемент кортежа, опционально) — 8
направлений с 2–3 фразами «что делаем»; `category_landings` вкл в config_patch;
плитки главной ведут на лендинги. Кандидаты дальше (по спросу владельца):
butcher «Partyservice», bakery «Hochzeitstorten», friseur (направления услуг —
потребует адаптации: категории только у каталога).

## Замки

normalize (тумблеры presence-minimal; PAngV-гейт menu_show_prices при orders) ·
роут (404 при выкл/пустой; 200 с контентом; примеры БЕЗ цен: '€' отсутствует
в блоке Beispiele) · плитки (ссылка на лендинг при вкл, фильтр при выкл) ·
прайс-лист без цен при False · сентинел-гард (чужой POST не роняет ключи) ·
характеризация: без новых ключей всё как было.
