# PH-11 — редизайн городского портала SolingenMarkt по макетам K1/P1/P2 (план, 2026-11-08)

План написан агентом `planner` по утверждённым макетам `docs/design/portal-home-2026-11-07/`:
- `K1_Ueberblick` — главная;
- `P1_Suche` — выдача поиска;
- `P2_Kategorie` — страница раздела.

Макеты утверждены владельцем 08.11, решение: «фильтр сворачиваемый кнопкой, приступай к разработке».

## 0. Рамки

- **Без миграций.** Исключение — §5, вопрос В-3; решено без индекса.
- **Реклама.** Платное размещение — только с пометкой «★ Anzeige», в органические блоки не попадает (UWG § 5a).
- **Срочность только честная.** Никаких фейковых таймеров.
- **Кэшируемый HTML без персональных данных** (P0-1).
- **Всё работает без JS** через GET-формы и ссылки.
- **Новые строки** — через `gettext` во всех пяти `.po`, проверка `scripts/i18n_quickcheck.py`.
- **Рабочий цикл** (CLAUDE.md §5): инкремент → локальный гейт → CI → FF в `main`. Локальный гейт:
  - ruff;
  - pytest по затронутым модулям;
  - `template_comments`;
  - `i18n_quickcheck`;
  - `npm run build:css`.

## 1. Инкременты

### PH-11a — шапка в одну строку на всех страницах портала ✅ 2026-11-08

**Состав строки:** «Kategorien» (открывает мега-меню; без JS — якорь `#kategorien`) · вордмарк · одна GET-форма поиска · Merkzettel · вход.

**Форма поиска:**
- поле «Was» передаёт `q`;
- поле «Wo» передаёт `stadtteil`; районы берутся из реестра `apps/core/districts`, запросов в БД нет;
- поле «Wann» передаёт `datum` со значениями `jetzt` / `heute` / `wochenende`.

**Что сделано:**
- **Параметр `datum=jetzt` = `offen=1`.** Добавлено в `search.parse_filters`. Канон и carry по-прежнему пишут `offen=1`.
- **Скрытые поля формы — через `_header_search`.** Выбранные фильтры выдачи едут в форме скрытыми полями, но без тех, что уже видны в полях «Wo» и «Wann». Иначе дубль имени перетёр бы выбор: `QueryDict.get` берёт последнее значение.
- **Полоса иконок разделов (PH-2) снята.** Навигация по разделам теперь одна — мега-меню.
- **Вторая форма поиска удалена.** Удалены `_portal_search.html` и форма в hero, поэтому форма поиска на странице одна.
- **Переключатель языков** на экранах уже 1536 px переехал в подвал, чтобы освободить место поиску.
- **Телефон.** Поле «Was» стоит отдельной строкой, «Wo» и «Wann» — строкой ниже.

**Тесты:**
- новый файл `test_portal_header_ph11.py` (7 тестов);
- осознанно переписаны `test_portal_menu` (strip снят) и `test_flt_width` (шапка 1392 px).

### PH-11b — выдача и раздел: левая панель фильтров и тулбар (общее для P1 и P2)

**Структура страницы:**
- **Хлебные крошки** с `BreadcrumbList` в JSON-LD.
- **Левая панель фильтров на `lg+`** — своя GET-форма. Поля берутся из общего партиала `_portal_filter_fields.html`, тот же партиал включается в шторку `#flt-drawer`. Состав:
  - Preis;
  - Art;
  - Stadtteil;
  - Verfügbarkeit (`offen`, `verfuegbar`, `datum`);
  - Merkmale;
  - ссылка «Alle Filter zurücksetzen».
- **На экранах `<lg`** остаются пилюли и шторка — поля шторки не меняются (замок `test_flt_districts`).
- **Кнопка «Filter ausblenden / einblenden · N»:**
  - атрибуты `aria-expanded` и `aria-controls`;
  - JS ставит на обёртку `data-flt-collapsed`, выбор запоминается в `localStorage`;
  - без JS панель просто видна;
  - при свёрнутой панели сетка 4 → 5 колонок (`group-data-[flt-collapsed]`).
- **Тулбар:**
  - H1 и «Gefunden: N» (`data-hit-count` остаётся после пилюль — на этот порядок завязан регэксп `test_unified_search`);
  - сортировка (прежняя форма);
  - переключатель «Kacheln / Liste» — только на клиенте, `aria-pressed`;
  - «Karte» = `?ansicht=karte`;
  - пилюли активных фильтров с ✕.
- **Разделитель «Später geöffnet».** При сортировке по умолчанию открытые карточки идут первыми в пределах страницы. Featured остаются сверху с пометкой. При `endet` / `neu` / `preis` порядок задаёт пользователь, разделителя нет.
- **«Mehr laden»** — прежний cursor-переход, оформленный кнопкой, с подписью «24 von N angezeigt».
- **`<details>` «Wie wir sortieren»** (UWG § 5b Abs. 2).

**Новые замки:**
- одинаковый набор полей (`name`) в панели и шторке;
- `aria-*` у кнопки сворачивания;
- разделитель стоит только при сортировке по умолчанию;
- featured выше разделителя.

### PH-11d — главная (`portal_discover.html`)

**d1 — слайдер, quad-карточки, полоса «Anzeigen».**

Слайдер:

- с JS — стрелки, точки и счётчик «1 / N»;
- `aria-roledescription="Karussell"`;
- автопрокрутки нет;

Слайды:

2. Deal (`data-deal-of-day` переходит на слайд).
3. Выходные.
4. Новый бизнес.
5. Региональное.

Слайд без данных не рендерится.

Quad-карточки:
- **Endet heute** — из блока `angebote`;
- **Beliebt diese Woche** — `PortalStat`, см. §2;
- **Neu diese Woche** — блок `neu`; JS на `localStorage` меняет подпись на «N neu seit Ihrem letzten Besuch», cookie не ставится;
- **Am Wochenende** — блок `freizeit`.

Ссылка каждой карточки ведёт на область, которая содержит показанное (инвариант «блок ⊆ ленты»).

Featured — подписанная полоса «★ Anzeige» после quad-карточек.

**d2 — «Das Beste aus jedem Bereich», «Geschäfte, die gerade viel anbieten», «Top-Aktionen».**
- **«Das Beste»:** точка статуса считается по снимку часов. На этот блок переезжает `id="kategorien"`.
- **Снимается:** hero (h1 остаётся заголовком над quad-карточками), быстрые фильтры, плитки разделов, ряды блоков, плитки районов, Branche, `other_portals`.

## 2. Данные новых секций

| Секция | Источник | Новые запросы |
|---|---|---|
| Слайды Deal / Neu | `deal_of_day`, `new_businesses` | 0 |
| Слайды Wochenende / Regional | `Count(filter=…)` в существующем `home_stats` | 0 |
| Endet heute / Neu / Am Wochenende | `home_blocks`, фильтр в Python | 0 |
| Beliebt diese Woche | `PortalStat` за 7 дней, top-4, затем `pk__in` по пулу (демо и скрытое отсекаются) | +2, кэш 15 мин |
| Das Beste | Window `RowNumber` по разделу, топ-6 разделов | +1 |
| Geschäfte | `values("tenant_schema").annotate(Count)` top-6 | +2 |
| Top-Aktionen | `FavoriteListing` за 7 дней, top-2 | +1 |

**Пороги честности:**
- «Beliebt» показывается при ≥ 4 листингах с ≥ 3 просмотрами. Иначе — «Jetzt geöffnet».
- «Top-Aktionen» — только при ≥ 2 акциях с ≥ 2 сохранениями.

Корень портала кэширован: при попадании в кэш новых запросов нет, при холодном рендере — около +6. Потолок числа запросов закрепляется замком.
