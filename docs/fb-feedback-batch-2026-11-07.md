- **FB-15 ✅** — тег `ai_notice` принимает несколько задач и рисует одну плашку; на шаге
  quelle и «Angebot prüfen» по одной. Замок `test_fb15_quelle_step_shows_ai_notice_once`.
- **FB-16 ✅** — входы «Seitenvorlage» из Sortiment/Aktionen сняты; старые адреса → 302 на

- **FB-17 ✅** — статистика и воронка каналов — панели вкладки «Statistics» (раньше висели
  на каждой вкладке). Трактовка: жалоба «статистика во всех вкладках».
- **FB-18 ✅** — подтверждённая причина: при ✏️ → Save фото качается из Telegram; при
  неудаче акция молча уходила без картинки. Теперь ошибка у поля фото (ничего не создано,
  черновик свободен), частичная потеря — предупреждение. Если владелец имел в виду другой
  сценарий (правка готовой акции в Mini App) — нужны шаги для воспроизведения.
- **FB-19 ✅** — поле «Stadt» подсказывает ВСЕ муниципалитеты Германии (решение владельца
  2026-11-07): `static/data/gemeinden_de.json` (10 443 названия из Gemeindeverzeichnis
  Destatis, `scripts/build_gemeinden.py`, © Statistisches Bundesamt) + `static/js/city-suggest.js`
  (грузится один раз, поиск при вводе). Без JS — короткий список (порталы, Bergisches Land,
  крупнейшие города, AT/CH). Сервер пишет официальное написание; короткая форма
  («Leichlingen» → «Leichlingen (Rheinland)») — только при однозначности («Neustadt» — нет).
- **FB-20 ✅** — метки (наклейка на карточке «Neu»/«Beliebt»/…) у акций, услуг, событий и
  номеров: общий реестр `apps/core/labels.py` (товар на нём же), поле `badge` + 4 миграции.
