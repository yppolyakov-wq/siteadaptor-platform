# T-8.29 «Verbindungen sichtbar» + T-8.30 «Mein Laden в Telegram (Mini App)» — план (2026-10-20)

Запрос владельца: «в Telegram неудобно — обсудим варианты»; выбраны вариант A (мобильная
«Mein Laden» = лёгкий кабинет) + C (то же внутри Telegram как Mini App) + макеты на
утверждение. Плюс жалоба: «в кабинете нет настроек своего бота и не видно интеграций».

Макеты: артефакт «Mein Laden — mobil» (4 экрана: Start · Aktion «So sieht man sie»
Website|Stadtportal · Sichtbarkeit & Verbindungen · то же в Telegram).

## 0. Диагноз «не видно интеграций» (разведка, факты с файлами)

1. Быстрый старт и регистрация через бот ставят `site_config["profile"]="aktionen"`
   (`apps/tenants/services.py:202`) → лёгкий кабинет: `sidebar_nav` возвращает 4 пункта
   (`apps/core/modules.py:595-597`), «Einstellungen/Integrationen/Marketing» нет.
2. Модуль `telegram` выключен по умолчанию у ВСЕХ типов (`modules.py:452-462`, `756-762`);
   быстрый старт включает только promotions+publishing (`services.py:156,194-196`) →
   `/dashboard/telegram/` = 404 (`middleware.py:131-141`).
3. Кнопка «Eigener Bot» общего бота ведёт в этот 404 (`platform_bot/menu.py:30-35,138-160`).
4. На «Integrationen» нет карточки своего бота; «Bot verwalten» в уведомлениях — только
   если бот уже есть (`templates/tenant/notifications.html:15-17`).
5. В полном кабинете свой бот спрятан в Marketing → Erweitert (`nav_registry.py:556`).

Важная находка: подключение СВОЕГО бота отключает связь с общим ботом
(`platform_bot/links.py:141-155`) — после этого акции через общий бот и Mini App не работают.

## 1. T-8.29 «Verbindungen sichtbar» (без миграций)

1. Лёгкое меню += «🔌 Verbindungen» → `integrations-home` (мораторий якорей не трогается —
   `LITE_NAV` отдельный).
2. Карточка «Eigener Telegram-Bot» на «Integrationen»: модуль выкл → кнопка «Aktivieren»
   (POST, только владелец, точечная запись `disabled_modules`, путь НЕ под
   `/dashboard/telegram/`); вкл без токена → «Nicht verbunden»; подключён → `@username`.
3. Цель «t» общего бота → `integrations-home` (никогда не 404); текст `own_bot()`.
4. Экран бота: шаги BotFather + предупреждение о связи с общим ботом (зависит от Р-1).
5. «Bot verwalten» в уведомлениях без бота → «Eigenen Bot einrichten →».
Замки: лёгкое меню, 3 состояния карточки, активация (аноним/сотрудник/GET/дважды/только
telegram из списка), цель «t» не 404, мораторий/достижимость, i18n.
Ревью: django + security.

## 2. T-8.30 «Mein Laden в Telegram» (без миграций при токене в кэше)

Вход: кнопка `web_app` общего бота → `https://<base>/tg/app/` → POST initData →
проверка HMAC (ключ = HMAC("WebAppData", токен бота), `auth_date` ≤ 300 с, защита от
повтора) → связь `OwnerTelegramLink` (не заблокирована, нет ограничения Art. 18) →
владелец в схеме бизнеса (`owner_user_pk` или единственный owner; иначе — отказ и вход
письмом) → одноразовый токен 60 с → поддомен `/start/<token>/` (автосабмит) → сессия
`tg_lite` (только лёгкие экраны по белому списку; биллинг/команда/право — никогда).
Несколько бизнесов → выбор. Telegram Web (iframe) — по возможности, с «открыть в окне».
Кнопка меню `setChatMenuButton` в личном чате. Логи — без initData.
Замки: эталонный вектор HMAC и подделки, привязка, одноразовость токена, белый список
сессии, лимиты, Playwright-стенд 390 px с подставным initData.
Ревью: security (обязательно) + django.

## 3. Вопросы владельцу

- Р-1. Подключение своего бота: оставлять связь с общим ботом (акции и Mini App через
  общий, клиенты — в свой)? Рекомендация: да.
- Р-2. Вход через Telegram только в лёгкие экраны (акции, ассистент, товары, «где видно»,
  поделиться); остальное — по письму. Исключение из «вход только по почте» — ок?
  Рекомендация: да.
- Р-3. Срок сессии Mini App: 12 ч? Рекомендация: 12 ч.
- Р-4. «Aktivieren» своего бота — одним нажатием или с подтверждением? Рекомендация:
  с подтверждением, пока действует связь общего бота (Р-1).
- Р-5. Mini App всем владельцам, связанным с общим ботом (и полный кабинет)?
  Рекомендация: всем связанным, лёгкие экраны одинаковы.
