# Definition of Done: новый экран кабинета (X7, план cabinet-cleanup-2026-08-19)

Чеклист приёмки КАЖДОГО нового экрана/входа ЛК. Причина: аудиты 2026-07/08
показали — «каша» растёт не из архитектуры, а из экранов, добавленных мимо
конвенций (сироты, второй хром, EN-строки, свои паттерны «＋»/поиска).

## Обязательное (ловится замками)

1. **Навигация.** Экран описан в `apps/core/nav_registry.py` (запись хаба или
   палитры) ЛИБО осознанно внесён в `EXPECTED_UNLISTED`
   (`apps/core/tests/test_x0_x7_locks.py`) с категорией ([POST]/[302]/[X-волна]).
   Замок `test_every_cabinet_screen_listed_or_consciously_excluded` — красный,
   если забыли.
2. **Якоря сайдбара не трогаем.** Состав/порядок ANCHORS заморожен
   (`test_sidebar_anchor_composition_is_frozen`); новая функция = вкладка или
   подпункт существующего якоря.
3. **Подсветка.** Вьюха отдаёт `nav`, у которого есть якорь в `ANCHOR_BY_NAV`
   (замок W8 «каждый nav-литерал имеет якорь»).
4. **i18n.** Все строки — немецкие msgid + записи в 5 каталогах `locale/*/django.po`
   в том же батче (гейт CI `scripts/i18n_gap.py`).

## Обязательное (проверяется ревью/стендом)

5. **Хром по правилу:** страницы хаба рендерят `{% hub_tabs %}` своего хаба;
   операционные поверхности — хром Verkäufe; никакого третьего варианта.
6. **Конвенции механик:** «＋» открывает форму создания; список — с поиском
   `?q=`, если сущностей может быть >20; Save — targeted-write/сентинелы
   (класс W6/W7a); формы — по паттерну соседей раздела, не новый зоопарк.
7. **Роли:** owner-only экран = префикс в `CabinetOwnerAccessMiddleware` +
   `owner_only=True` в реестре (таб скрыт у сотрудников).
8. **Playwright-смок** для JS/навигационного поведения (уроки: серверные тесты
   такое не видят).

## Процесс

- Изменение состава якорей или EXPECTED_UNLISTED — только осознанной правкой
  замка с записью в build-log (и решением владельца для якорей — мораторий).
