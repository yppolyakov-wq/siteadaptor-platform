# KA-5b · Проход по архетипам «Gastro» (2026-10-23)

> Часть программы `ka-cabinet-audit-program-2026-10-22.md`. Архетипы: cafe, restaurant, catering.
> Метод — как KA-5a: 7 сценариев владельца → путь по коду → что мешает / чего нет / что лишнее.
> Утверждения о деньгах, данных и законе перепроверены вручную (✔). Кода нет, кроме хотфикса KA-H5 (§5).

## 0. Модули по умолчанию

- **cafe / restaurant:** promotions, crm, reviews, **booking** (столы), loyalty, gift, blog, inbox,
  customer_account. Выключены orders (а с ним KDS, Tisch-QR, предзаказ), jobs, finance, analytics.
- **catering:** **jobs** (заявки/сметы), promotions, crm, reviews, gift, blog, inbox, customer_account.
  Выключены booking, orders, loyalty, finance, events.
- **Демо богаче реального нового бизнеса:** киты restaurant и cafe включают orders; конфиг формы
  заявки кейтеринга (`site_config["anfrage"]`) пишет только кит — у нового кейтеринга дата/гости/повод
  в форме не спрашиваются.

## 1. Сценарии

| # | Сценарий | Путь | Главные проблемы |
|---|---|---|---|
| 1 | Бронь столов | Verkäufe → «Öffnungszeiten & Ressourcen» → ресурс + правило на каждый день недели отдельно; сегодня — Tagesplan | **✔ блокер/данные:** ручная бронь (звонок, walk-in) без поля «гостей» → всегда 1 гость, при пуле мест компания из 8 занимает 1 место → овербукинг; нет плана зала/столов; слоты не связаны с часами работы (два источника правды); подпись «Termine» вместо «Reservierungen»; на главной нет «гостей сегодня»; онлайн можно взять весь зал без порога больших групп |
| 2 | Speisekarte | Sortiment → блюдо (вкладка «Kennzeichnung») | **✔ закон:** в PDF-меню `/speisekarte.pdf` нет Zusatzstoffe (поле есть, `catalog/pdf.py` выводит только аллергены); варианты (klein/groß) не видны; порядок по дате создания; Mittagstisch-пресет «daily» включает выходные, Tageskarte по дням нет; тизер наборов скрыт без orders |
| 3 | Заказы / KDS / QR | — | у нового кафе/ресторана выключено целиком; Tisch-QR только Ctrl+K; «Wunschzeit» обещана, не выбирается (KA-5a B4) |
| 4 | Catering | /anfrage/ → карточка заявки → смета → депозит → счёт | **✔ деньги:** счёт из сметы (`jobs.services.quote_to_invoice`) не учитывает скидку владельца (DC-5, `payable_gross`) — в черновике сумма больше согласованной; Anzahlung не упоминается; **✔ без модуля finance кнопка «Rechnung» ведёт на 404** (статус уже «invoiced»); в ручной заявке нет даты/гостей/повода, править их в карточке нельзя; поле «Vehicle» и плейсхолдер «Bad streichen»; смета не подставляет кол-во из гостей; календаря событий нет |
| 5 | Акции | Marketing → Aktionen | Happy-Hour-пресет без временного окна — скидка весь день (окно работает только для услуг); Gutscheine только со Stripe |
| 6 | Сообщения, отзывы | Nachrichten, Bewertungen | бронь стола без услуги не порождает отзыв; оценки заведения нет; Place ID Google только через Ctrl+K |
| 7 | Деньги | — | выручки дня нет без finance; **нет кассы/TSE, чаевых, Z-Bericht** (зал не учитывается; TSE — вопрос юристу KA-1) |

## 2. Лишнее для гастро
Lager, Einkauf, Import, Kollektionen в Sortiment; «Marke & Zustand» в карточке блюда; «Vehicle» в
заявке кейтеринга; «Leistungen», «Karten & Abos» у ресторана; подпись «Termine».

## 3. Не хватает (по важности)
1. Ручная бронь: число гостей, лимит больших групп, подтверждение вручную для групп.
2. Столы и план зала (столы с местами, объединение, ротация), «гостей сегодня» на главной.
3. Слоты из часов работы; «Betriebsferien» на весь сайт (бронь + заказы + акции).
4. Кейтеринг: дата/гости/повод в ручной заявке и правка в карточке, смета «pro Person» от гостей,
   календарь событий, Schlussrechnung с учётом Anzahlung, Ablaufplan/BEO.
5. Tageskarte по дням недели, Mittagstisch без выходных.
6. Временное окно акции для товаров (Happy Hour).
7. Касса/TSE/чаевые — отдельный крупный трек (решение владельца + юрист).

## 5. Хотфикс KA-H5
По правилу программы (деньги/данные/закон): G1 (счёт из сметы = согласованная сумма, без 404),
G2 (поле «гостей» в ручной брони), G3 (Zusatzstoffe в PDF-меню). Отдельным инкрементом по обычному
циклу (planner → замки → ревью → CI → main).
