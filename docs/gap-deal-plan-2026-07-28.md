# «Lücken-Deal» — суперскидка на короткие промежутки между бронями (план)

**Дата:** 2026-07-28 · **Источник:** фидбэк владельца (скрин витринного
календаря): «акция с суперскидкой (настраиваемой), если между бронями 3–4 дня
(настраивается); предлагать автоматически настроить отелю; добавить в
первичные настройки». ⚠️ Миграция `stays/0029` (аддитив).

## Модель (StaySettings)

- `gap_max_nights` PositiveSmallIntegerField(default=0) — 0 = выкл; иначе
  «промежуток до N ночей считается люкой».
- `gap_discount_percent` PositiveSmallIntegerField(default=25, кап 70).

## Движок

- `pricing.gap_discount(unit, arrival, departure, settings)` → (percent,
  label "Lücken-Deal −25 %") | (0, ""): диапазон гостя целиком лежит в
  максимальном свободном отрезке ночей (free>0 из семантики range_available),
  ограниченном С ОБЕИХ сторон полностью занятыми/блокированными ночами
  (леддер: сканируем ±gap_max от диапазона), и длина отрезка ≤ gap_max_nights.
  Передний край «сегодня» границей НЕ считается (иначе всё ближнее дисконтится).
- Интеграция: кандидат в `auto_discount` (сигнатура += unit/departure,
  дефолты None → поведение байт-в-байт; G4-семантика «максимальный процент»)
  — авто-подхват в book_stay/quote/тариф-карточках; label показывается в
  существующей разбивке цены (auto_discount_label).

## Кабинет + автопредложение

- Секция «💥 Lücken-Deal» на units (рядом с Dynamische Preise): тумблер/N
  ночей/%.
- Автопредложение: на Belegungsplan карточка-хинт, когда фича выключена и
  детектор нашёл ≥1 люку в ближайшие 60 дней («Kurze Lücken gefunden —
  Lücken-Rabatt aktivieren?» + one-click enable с дефолтами 3 ночи/25 %).
- «Первичные настройки»: слайд мастера отельного архетипа (offer/payment?) —
  чекбокс «Lücken-Rabatt aktivieren» с дефолтами; вписать в
  `setup_steps`-хендлер stays-архетипов.
- Витрина: месячный календарь помечает ночи внутри активных люк бейджем
  «−25 %» (v2 — если дёшево посчитать в month_availability).

## Тесты

- Детектор: люка между двумя бронями ≤N → скидка; >N → нет; край «сегодня»
  не люка; quantity>1 — люка по СВОБОДНОЙ ёмкости (free>0-отрезок).
- Цена: quote/book_stay консистентны; max(G4, gap) не суммируется.
- Автопредложение: карточка при наличии люк и выключенной фиче; one-click.
