# T-8.10d.1 — подписка портала комбинацией фильтров (план, 2026-11-18)

Фидбэк владельца: подписки «Kategorie: Friseur», «Stadtteil: Mitte», «Merkmal: familienfreundlich»
независимы, письмо — объединение (из Mitte приходит всё). Решения владельца (2026-11-18):
одна подписка = сочетание (И между типами, ИЛИ внутри типа, пустой тип — любой); создаётся
кнопкой «Folgen» на странице с фильтрами (фильтры предзаполняют, правятся до подтверждения);
старые одиночные подписки остаются как есть.

## Что есть (planner)
Вид `query` (T-8.10d) уже хранит набор фильтров (`FollowSubscription.query`, `follow_query.canonical`:
`kat`/`merkmal`/`stadtteil` до 3, `kind`, `q`, `marke`, цена; `offen`/даты не переносятся), письмо
выбирает тем же путём, что «Alle anzeigen» (`follow_query.queryset`), сводка ставит узкие подписки
первыми и не дублирует пункты. Причина объединения у владельца: «Folgen» на выдаче строит одиночную
цель из первой категории или района (`portal_views.py:782-791`), а сочетание прячется в отдельной
ссылке «Benachrichtigen, wenn es so etwas gibt» (`_search_follow.html`).

## Срезы
- **P0 макеты** (правило владельца): одна кнопка на выдаче; панель подтверждения с чипами по типам
  (Kategorie · Stadtteil · Merkmal · Art), частота, честная подсказка о непереносимых фильтрах;
  строка «Ich folge» с подписью «Friseur · Mitte, Burg/Höhscheid · familienfreundlich» и правкой.
- **P1 ядро без UI**: группированная подпись (`follow_query.describe`), `combo_pairs`; замки
  «фильтры страницы → набор», «одно условие → старая цель», «письмо ⊆ Alle anzeigen», DOI-токен.
- **P2 кнопка и панель** (GET-ссылка на `/folgen/?art=suche&…` — кэш публичных страниц цел).
- **P3 правка в «Ich folge»** (на месте; совпадение с другой подпиской — слияние; только при
  доказанном контроле над ящиком).
- **P4 (по решению) «Sofort» для комбинаций** — миграция ограничения `follow_instant_business_only`
  и лимит мгновенных комбинаций.

## Риски
UWG §7/DSGVO — DOI на каждую новую комбинацию; правка расширением — только вошедшему/по токену;
строка в Datenschutz. Старая «Stadtteil: Mitte» продолжит слать весь район (её смысл) — дубли в
одном письме исключены, между письмами — `recently_sent_keys`.
