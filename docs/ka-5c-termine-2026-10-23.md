# KA-5c · Проход по архетипам «Termine» (2026-10-23)

> Часть программы `ka-cabinet-audit-program-2026-10-22.md`. Архетипы: friseur (салон),
> werkstatt (автомастерская). Метод — как KA-5a/5b; утверждения о деньгах/данных перепроверены
> вручную (✔). Кода нет, кроме хотфикса KA-H7 (§5).

## 1. Салон (friseur)

| # | Сценарий | Путь | Главные проблемы |
|---|---|---|---|
| 1 | Утро: записи по мастерам | Verkäufe → Kalender (месяц + Tagesplan) | список, а не колонки по мастерам; **в строке нет названия услуги**; счётчик дня учитывает и отменённые |
| 2 | Запись по телефону | форма «Add booking» под Tagesplan | **✔ нет выбора услуги** → запись без услуги, цена 0 €, длительность 60 по умолчанию; поле заметки читается вьюхой, но в форме его нет |
| 3 | Перенос | поле времени + Move | мастер не меняется; ClosedDate и рабочие часы мастера не проверяются; клиент не получает письмо, напоминание не сбрасывается |
| 4 | Мастера и часы | Öffnungszeiten & Ressourcen | **нет привязки услуги к мастеру/навыков** (онлайн «Bart trimmen» может уйти к колористке); тип по умолчанию «Table», подсказка «Tisch 1»; отпуск одного мастера есть, без предупреждения о записях |
| 5 | Услуги | Sortiment → Leistungen | нет вариантов (короткие/длинные волосы), буфера, минимального срока записи, правил отмены, самостоятельной отмены/переноса клиентом |
| 6 | Клиенты | Kunden, карточка 360 | **✔ клиент без e-mail создаётся заново при каждой записи** — история дробится; напоминания только e-mail за 24 ч; нет счётчика неявок |
| 7 | Деньги | — | нет кассы/TSE, чаевых, закрытия дня; **✔ выручка записи жёстко по 19 %** (снимок ставки DC-8 и §19 игнорируются); **✔ визит по карте (абонементу) записывается в выручку второй раз** |
| 8 | Маркетинг | — | письмо «оцените визит» только для записей с услугой (ручные выпадают); нет напоминания «пора на стрижку» |

## 2. Автомастерская (werkstatt)

| # | Сценарий | Путь | Главные проблемы |
|---|---|---|---|
| 1 | Приёмка машины | `jobs:new` | Kennzeichen/HSN/TSN в кабинете не вводятся (только с публичной формы), нет пробега, FIN, протокола повреждений, фото |
| 2 | Смета → согласие | карточка заявки | смета правится в любом статусе, даже после accepted/invoiced; нет «согласовано по телефону» без письма |
| 3 | Работа → выдача | статусы заявки | нет «in Arbeit»/«abholbereit»/«abgeholt» (можно своими статусами SM-3); оплата заявки не связана со статусом счёта |
| 4 | Счёт | «Rechnung» | без модуля finance счёт остаётся черновиком «Draft» без номера (§14 UStG) — **связано с KA-3 `finance_basic`** |
| 5 | TÜV/сервис | `service_due_date` | **✔ напоминание уходит и по отменённым заказам**; дата на заказе, а не на машине |
| 6 | Деньги | — | **✔ выручка мастерской вообще не попадает в журнал** (`status_effects.py:79` — «через invoice-флоу», а у счёта записи выручки нет) — Ergebnis/DATEV/LTV без мастерской. Отложено ещё в ERP-6 как «отдельное решение» → **вопрос В-1** |

## 3. Лишнее
«Personen» и «Count per person (group course)» у салона; тип ресурса Table/Room и «Tisch 1»; название модуля
«Tische, Termine oder Zimmer» (видно и клиенту на витрине: «Ihren Tisch oder Termin»); сезонные цены
«Hochsaison»; редакторы статусов на странице ресурсов; Lager/Import в Sortiment.

## 4. Не хватает (по важности)
1. Услуга ↔ мастер, колонки по мастерам с перетаскиванием.
2. Выбор услуги в ручной записи (→ H7), заметка.
3. Варианты, буфер, срок записи, правила и сбор за отмену, самостоятельная отмена/перенос.
4. SMS/WhatsApp-напоминания, rebooking по интервалу.
5. Карточка окрашивания, история неявок.
6. Касса/TSE/чаевые/закрытие дня (общий трек с гастро — G-7).
7. Werkstatt: машина как сущность (Kennzeichen/FIN/пробег), протокол приёмки, статусы работ, доска подъёмников.

## 5. Хотфикс KA-H7 (деньги/данные)
- **A** визит по карте не записывается в выручку второй раз (только допы);
- **B** ставка НДС выручки записи — из снимка, §19 учитывается;
- **C** ручная запись с выбором услуги (цена/длительность из услуги) и заметкой;
- **D** напоминание о TÜV/сервисе не уходит по отменённым заказам;
- **E** клиент без e-mail находится по телефону, а не создаётся заново.

## 6. Вопрос владельцу
**В-1. Выручка мастерской/ремесла (заявки) в журнале.** Сейчас её нет вовсе. Варианты: (а) записывать при
выставлении счёта (рекомендую: документ GoBD, сумма = счёт); (б) при «done»; (в) оставить как есть.

## 7. В бэклог KA-11
T-1 мастера и навыки + колонки · T-2 ручная запись/перенос с проверкой часов и письмом клиенту · T-3 правила
услуги (варианты/буфер/отмена) · T-4 напоминания SMS/WhatsApp + rebooking · T-5 машина как сущность и
приёмка · T-6 статусы работ мастерской · T-7 касса (общий с G-7).
