# DL-16 — план реализации пакета v1 (решения владельца 2026-09-02)

**Решения:** пакет v1 целиком · стрелки слайдера при наведении (десктоп; тач — свайп + точки) ·
**Preis-zuerst — дефолт** карточки акции у дил-сборок `deal_*`. Незаданные вопросы §5 анализа
решены рекомендацией: таблица акций — тумблер посетителя (`?ansicht=liste`); A1 «Vorschau»
запланированных — вне v1. Анализ — `dl16-display-variants-analysis-2026-09-02.md`, канвас
«Anzeigeformen». Правила: план → код; каждый инкремент = ветка-коммит(ы) → локальные гейты →
push → CI → FF-merge; паритет «""/дефолт байт-в-байт» замками ДО правок; без DDL-миграций
(choices-only допустимы, прецедент `promotions/0026`).
