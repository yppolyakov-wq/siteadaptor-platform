# FB-27 R6 — блоки «Textseite» и «Kontakt», меню «+ Block» с готовыми строками

Дата: 2026-11-13. Основание — `fb27-seitenaufbau-impl-plan-2026-11-11.md` §A.7, §C (R6);
решения владельца — `fb27-website-pages-ia-plan-2026-11-11.md` («Textseite einbinden»: весь
текст или начало + «Weiterlesen»; готовые строки: Text + Foto · Foto + Text · Drei Karten ·
Text + Kontakt).

## 1. Что есть в коде

- Свои блоки — `siteconfig.REPEATABLE_BLOCKS` (с данными, на любой странице) и
  `PAGE_REF_BLOCKS` (без данных, только на страницах). Данные чистит `_clean_cblock_data`,
  рисует `siteui.render_block` по `CBLOCK_TEMPLATES`.
- Карточка контактов — партиал `storefront/sections/_contact.html` (варианты `style`:
  карточка, `split`, `map_first`, `compact`); на «Über uns» — фикс-строка (`about_contact`).
- Текст страницы — `core.ContentPage` (UUID-ключ, `slug` меняется владельцем),
  вывод — `storefront/_page_body.html` после `sanitize_page`.
- «+ Block» в «Seitenaufbau» — один `<select>` из `site_schema.add_options`.
- Save Студии пересобирает данные блока из полей строки (`_read_cblock_data`) — блок без
  ветки там теряет данные (замок класса `test_cblock_field_roundtrip`).

## 2. Решения

| № | Вопрос | Решение |
|---|---|---|
| B1 | Семья блоков | Оба — в `REPEATABLE_BLOCKS`: работают на главной и на страницах, ширина и ряд — общие оси. |
| B2 | Ссылка на страницу | `data["page"]` = UUID страницы, не slug: смена адреса ничего не ломает и переносить нечего. В normalize — только формат, без запросов. |
| B3 | Режим | `data["mode"] = "teaser"` — начало текста (≈300 знаков, без разметки) + «Weiterlesen»; ключа нет — весь текст. |
| B4 | Сама в себя | Панель не предлагает страницу, на которой стоит блок; `update` с ней отклоняется; рендер дополнительно пропускает (блок мог попасть из Студии или копией). Вложенности нет вовсе: встраивается только текст, без блоков той страницы. |
| B5 | Нет страницы | Удалена или снята с публикации — на сайте блок не выводится; в панели пункт «… (nicht verfügbar)» остаётся выбранным (W0). |
| B6 | «Kontakt» | Данные — только `style` (не-дефолтный); содержимое — из настроек бизнеса, в панели ссылка туда. Фикс-строку «Über uns» не трогаем (перенос — отдельным решением). Ширины — Ganz · ⅔ · ½. |
| B7 | Студия | Скрытые поля строки + ветки `_read_cblock_data` + поля черновика: Save Студии данные не стирает. В библиотеку Студии блоки не добавляем — структура уходит из неё в R8. |
| B8 | Меню «+ Block» | Один `<select>` с тремя `<optgroup>`: «Inhalt», «Listen & Aktionen», «Von anderen Stellen» (Textseite, Kontakt, FAQ, Team, Galerie, Stimmen, формы). Без JS, с клавиатуры и с телефона — штатный селект. |
| B9 | Готовые строки | Операция `add_row`: вторая форма «Fertige Zeile». Пресеты — реестр `ROW_PRESETS` (блоки + ширины, первый с «Neue Zeile»); добавляются в черновик разом. «Text + Kontakt» — на любой странице. |

## 3. Срезы

- **R6a — блоки.** `siteconfig` (типы, подписи, чистка), партиалы витрины, тег выборки
  страницы, приёмники Студии.
- **R6b — панель.** Поля блока в панели (`PANEL_FIELDS` + вид `select`), проверка «сама в
  себя» в `mutate`, сводка строки (название страницы).
- **R6c — меню.** Группы `add_groups`, `ROW_PRESETS`, операция `add_row`.

## 4. Замки (до кода)

- мусор в `page`/`mode`/`style` не попадает в конфиг; пустой блок не роняет страницу;
- весь текст / начало + «Weiterlesen»; чужая разметка в начале не выводится;
- страница не встраивается сама в себя (панель, `update`, рендер), в т. ч. системные
  «Über uns» и «Versand»;
- смена адреса страницы блок не ломает; снятая с публикации не выводится;
- Save Студии не стирает данные обоих блоков (замок класса сам увидит новые типы);
- каждый пресет строки проходит normalize без потерь и встаёт в один ряд;
- `add_row` с неизвестным пресетом — отказ; добавление — через черновик;
- каждый тип из `add_options` входит ровно в одну группу меню;
- golden-конфиги не меняются (ключи только при не-дефолтных значениях).

## 5. ECC-прогоны

- До кода: `django-tdd`, `django-security`, `accessibility`, `e2e-testing` (загружены в сессии).
- После R6a: `security-reviewer` (вывод HTML чужой страницы, ввод ключа).
- После R6c: `django-reviewer`, `a11y-architect` (меню, панель), стенд Playwright 1440/390
  с проверкой витрины.
