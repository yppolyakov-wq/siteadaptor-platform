{% comment %}KA-12 E9.6: общий скрипт хрома кабинета для таблиц и списков. 1) Таблицы `.ui-table-stack`: подпись каждой ячейки берётся из её колонки (data-label) — на телефоне строка становится карточкой «подпись: значение». Явные роли сохраняют семантику таблицы, когда CSS делает ячейки блоками. 2) Списки `[data-kb-list]`: ↓/↑ и j/k — фокус на ссылку соседней строки, Home/End, «/» — фокус в поиск страницы ([data-kb-search]); Enter — нативный у ссылки. Клавиши работают ТОЛЬКО при фокусе внутри списка (WCAG 2.1.4); строки фокус не получают.{% endcomment %}
