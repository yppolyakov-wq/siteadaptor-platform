{% load i18n %}{% comment %}LAY-3b: параметры «типа вывода» одной поверхности. Запрос владельца 2026-09-09: «тип слайдер (сколько карточек, скорость переключения, сколько строк) или тип сетка: сколько колонок; сколько элементов показывать — например их 50, показываем 10, как раз 2 ряда по 5; не задано — показывать все; пагинация — сколько выводить на странице». Вход: `field` — префикс имён полей (тот же, что у селекта пресета: catalog_preset и т.д.), `layout` — текущая раскладка. Пустые поля НЕ сохраняются: «нет ключа» значит «как раньше» (показывать всё, размер страницы по-старому, не крутить). Число элементов задаём РЯДАМИ, а не абсолютным числом: «10 = 2 ряда по 5» остаётся ровным при смене колонок, абсолютное число — нет (рваные ряды DL-11/14/15).{% endcomment %} {% comment %}STU-16a: ось занимает ВСЮ ширину строки.
